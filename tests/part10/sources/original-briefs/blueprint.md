## 一个结构

| 层 | 内容 |
| --- | --- |
| 来源（各线自己的） | 窗口；实时活动（播放、隔空投送、路线、录音）；设备电量；CarPlay 接收；遥控器与语音；脸与身边的设备；agent 会话 |
| 真相层 | 稳定 ID 与组件 ID，名字只用来显示；最后看见、最后读到、采样时间分开；未知就是未知；去重与回滞 |
| 唯一的协调器 | 活动协调器，每块屏一个，按下面的仲裁顺序决定刘海此刻长什么样；状态来自数据，不来自动画回调 |
| 唯一的宿主 | 刘海面板（无刘海的屏用顶部胶囊）；最小、紧凑、短暂提醒、展开、交互五种形状，同一套弹簧（设计规范 v2 的记号） |
| 输入 | 指针与触控板（点一下刘海是启动台，长按是 CarPlay）、键盘、遥控器（声调、拍子、按钮）、声音（出草稿；声纹只作辅助因素） |
| 横穿 | 授权账（一次性、绑定用途和目标）；信号登记表（隐私一栏从它生成）；能耗预算 |

## 刘海此刻听谁的

从上往下，先到先占；上面的让出后，下面的原样回来，不补播。

1. **要你放行的事**：刷脸解锁、Touch ID 确认、agent 审批。独占，其它暂存；只认审批出现后的新动作。
2. **你正在做的事**：指挥手势画到一半、按住说话、拖标题栏到落点小岛。手离开前什么提醒都不进来。
3. **你主动打开的**：刘海那一排、看一眼、展开的详情。普通更新只在原处改数字，不顶掉它。
4. **短暂提醒**：配件连上、电量低、有变化时提醒、卡住时提示。约 4 秒；0.6 秒内合成一句；遇到上面三层就进次区域留个小点。
5. **持续活动**：音乐、CarPlay、录音、隔空投送、路线、agent 在跑。最多三个，两指横扫切换。
6. **什么都没有**：和实体刘海重合，不画、不刷新。

锁屏、切换用户、关掉功能时清掉一切可见内容和输入；解锁后只显示当前状态，加一条“离开期间”摘要。

## 不做的

- 心率、脸红不当解锁依据；健康数据不进放行（Apple 协议限制 HealthKit 用途）。
- 声纹只作辅助因素：脸的分数在门槛附近、或放行高风险的事时补一道随机短语；不单独放行，不顶替手机或手表（NIST SP 800-63B-4 不把它当认证因素）。
- atv-core 的 Verified 不当授权（没验客户端签名），接 agent 前先补好。
- 不往前台窗口盲发回车；不开空对话冒充接管原会话；后端不支持的档位明说，不默默降档。
- AirBattery（AGPLv3）只读不拷；Loupe 的名字、图标、图片不用。
- Aaron 定（2026-10-03）：不走 App Store 分发，Face Data 用途限制不作门槛；**私有 API 能达成目的就大胆用**，用了就登记到隐私一栏第三层，系统更新后失效要有退路。

## 硬要求

做不到就停下来写明卡在哪，不要换一个更容易的东西交差。

1. **七条线都是目标，没有一条是偏航。**窗口、实时活动、电量、CarPlay、指挥模式、刷脸解锁、隐私，进度各记各的。
2. **一个宿主，一个协调器。**所有东西长在已有刘海面板里，经协调器按仲裁顺序出场；不新建浮层、认证窗口、菜单栏小工具，不拿预览窗当成果。
3. **状态来自数据，不来自动画。**结果出来前不打对勾。
4. **未知就是未知。**没读到不写 0%，没跑的场景不写通过，没核的话不上界面和官网，模拟数据不冒充真机。
5. **放行只走授权账。**一次性、绑定用途和目标、可撤销；心率、健康数据、atv-core 的 Verified 不放行，声纹只作辅助因素。
6. **读什么都登记。**新读取点先登记到信号登记表。
7. **能耗写进验收，只做纯赚的改动。**空闲 CPU 和唤醒不高于 1.0.15；已有行为不许变差。
8. **文案照 [copy-guide.md](copy-guide.md)。**收起窗口、收进刘海、看一眼、实时活动、刷脸解锁、指挥模式，一个东西一个名字。
9. **不碰 Aaron 的东西。**不动他的真实窗口；探针只用临时窗口、只在他离开或空闲时跑；不退出他日常用的 WindowShade；
   不提交、不推送、不发布，除非他说。
10. **许可干净。**Glance、Loupe 代码 MIT 带版权声明；AirBattery 只读不拷；Apple 机身素材只用来量，不进仓库。
11. **便宜模型交来的东西要复核。**主模型自己看差异、自己复现数字。
12. **每一步留证据。**改完更新对应文档和 [1.0.16 对照表](releases/v1.0.16-ledger.md)：做了什么、怎么测的、真实结果、还差什么。
