# 成熟度自评：我们在哪、差多远、怎么补

2026-10-15。这一份回答「**提升成熟度**」——不是功能成熟度（那在[功能碾压](dominance.md)），是**作为一件产品、一个工程、一个长期维护的项目的成熟度**。依据：[向生产级成熟演进](production-maturity.md)（出货面）、[竞品深挖](competitive-deep-dive.md)／[更新日志里的 real-world know-how](changelog-knowhow.md)（竞品对照）、本机实测。

## 一、一句话结论（先看这句）

> **我们的工程质量高于多数竞品；我们的出货成熟度低于所有竞品。**

这不是自谦——两边都有本机证据：

- **高于多数竞品**：2631 个本地化键中英齐全 ＋ **12 个禁词 ＋ 固定词汇表 ＋ 388 行设计文法**；**228 个 Swift 测试档 ＋ 215 支 runner**；门禁里连**中文字面量棘轮**都有（`build.sh --check`）；隐私登记连 `CGSession*` 与 `IOHID*` 这种一处调用都登记。
- **低于所有竞品（2026-10-15 现验重写）**：**没有 Developer ID、没有公证**（九份竞品件**全部** `accepted / Notarized Developer ID`，十家里只有我们被 Gatekeeper 拦）；**同一版本号重发到第七次**（「170 个提交 0 次发布」是 10-06 的旧快照，10-14 已发布，但七个包共用一个版本号）；**主程序是整包里唯一没有 hardened runtime 的执行体**；**6.6 MB 符号表随包出货**。

**所以「提升成熟度」的第一优先级不在工程侧，在出货侧**——这也是[北极星](north-star.md)§四 第 1 条。

## 三、成熟度的三个阶段（我们在哪一阶段）

| 阶段 | 判据 | 我们 |
| --- | --- | --- |
| **实验品** | 能跑、功能多、只有作者能用 | 已过 |
| **可交付品** | **别人能装上、能更新、能上报**；有节拍；有回归门槛 | **← 卡在这里**（无公证、0 发布、无崩溃上报） |
| **成熟品** | 上面那些 ＋ **稳定的对外数字**（性能／能效／兼容）＋ 支持面 ＋ 安全披露通道 | 未到 |

**从「可交付品」走到「成熟品」，缺的不是功能，是三类东西**：**出货链路**（签名／公证／节拍）、**对外可核的数字**（性能预算，R44）、**支持面**（反馈、诊断导出、隐私声明、安全披露）。

## 四、这一轮的三个新缺口（已立任务）

| 编号 | 缺口 | 为什么它算成熟度问题 |
| --- | --- | --- |
| **R43** | **`docs/` 没有索引**（85 份顶层 md） | 文档多了之后**找不到就等于没有**——我这一轮就因为 `AGENTS.md` 漏挂而差点让整批工作对新 session 不可见。**成熟项目都有：新人和 agent 都能从一处进来** |
| **R44** | **性能预算没进门禁**（量了，但超了不会红） | 「我们测了」与「我们保证」是两件事。成熟项目会把预算写死并让 CI 拦——**这是 E1 从「记录」升级成「约束」** |
| **R45** | **代码地图没有规范位置**（现在在 `tests/part8/sources/code-map.md`，以及 `docs/handoff/chatgpt-review-2/` 下 part7 与 part8 两个评审包的 `sources/code-map.md`） | 新人／新 agent 找不到「哪段代码负责什么」。应该有一份**在 `docs/` 下、被 `AGENTS.md` 指向**的地图 |

## 五、成熟度提升的顺序（按「不解决就出不了这台机器」排序）

1. **出货链路**：Developer ID ＋ 公证 ＋ 发版列车（[production-maturity](production-maturity.md) B 组 ＋ 本规格的发布流程）。**这一条不在工程侧，只有 Aaron 能决定要不要花那 $99。**
2. **版本号纪律 ＋ 一页清单**（R34 ＋ 已定案的签字流程）——让节拍真能跑起来。
3. **对外可核的数字**：R44 的预算 ＋ E2 的口径对齐 ＋ E1 的例行化。
4. **支持面**：R35 诊断导出 → R36 反馈入口 → R37 隐私声明 → R38 第三方许可 → `SECURITY.md`。
5. **自愈与长会话**：R2／R3／R39。
6. **找得到**：R43 索引 ＋ R45 代码地图（便宜、立刻见效）。
