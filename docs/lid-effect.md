# 合盖效果：相对角度触发、合上和展开都跟手

2026-10-01 下午。Aaron：“尝试一下做反向的，推翻之前的设计决定，连续问我几个问题，背后做好调研工作。”
下面是三轮问答的结论。改合盖效果之前先对照这一页。

## 为什么推翻

- [direction.md](direction.md) 早把它定成“最舍得让出来的”、默认关；README 也只叫它彩蛋。可 10-01 一整天的性能工作
  几乎都压在它身上，还带出三个回归（开盖后效果反复起停、效果卡在屏上不收、合盖时铰链 1 秒读 760 次）。
- 起停用的是**绝对角度**：触发角 95° + 8° = 103°。Aaron 平时的屏幕角度实测 101–104°，正好压在线上，
  于是要么反复起停，要么一直不收；14:29–14:32 盖子没动，全屏录屏却跑了 3 分钟。
- “跟手”意味着合盖全程 60Hz 读铰链、15fps 录屏、主线程上逐帧画。内建屏熄灭那一刻还在画，
  主线程就等 WindowServer（实测 300–600ms）。
- 倾斜用的加速度计一天到晚 62 次/秒在跑，是解锁空闲时最大的常驻开销，可它的值只在合盖效果里用（一处）。

## 定下来的

| 问题 | 答案 |
| --- | --- |
| 合盖效果以后是什么 | **一次性动画**：认出“开始合盖”就播一段固定的合上动画，不再跟着角度一帧一帧走；盖子不动时不录屏 |
| 什么时候算开始、什么时候算结束 | **相对你平时放的角度**：记住静止时的角度，比它低 **15° 以上且还在往下合** 才开始；回到它附近才结束（原定 10°；Aaron 实录的“调角度”一下就挪 12–13°，10° 误触两次，看过回放对比后改 15°） |
| 合到一半停住（比如 60°） | **保持合上的样子，直到盖子打开回来**，再播展开 |
| 合上动画播完之后 | **定格最后一帧，不再画新帧**，看起来和现在一样，直到屏熄 |
| 开盖时 | **播展开动画**（屏亮后取一张新的桌面截图）。Aaron 补充：开盖和合盖一样要有效果，下面三种都播：合到底屏熄后打开（含睡眠醒来）；合到一半停住后往回开；合得太快、合上动画没来得及播，开盖照样播——以“屏真的熄过”为准，不以“合上动画播过”为准。只是微调角度、没触发过的，开合都没有效果 |
| 倾斜（加速度计） | **只在效果进行时开**，效果结束就关 |
| 铰链读数 | **只用推送**（约 10Hz，够判断“开始合”和“回到原位”），去掉 60Hz 精细读、看门狗、加速度计门控；保留不推送机器的兜底轮询 |
| 帕累托规则 | **照旧严格**：除上面这几条明确的产品决定外，不许有可见变化 |
| 怎么测 | **录真实角度序列，离线回放**：慢合、合一半停、停在线附近、快速开盖……回放进触发逻辑做测试，只把最终观感交给 Aaron 看 |
| 先后 | **先重做合盖效果**；“收起窗口 0.5–1.5 秒卡顿”10-01 四次收起都没复现（9–24ms），留着日志，下次卡了再查 |
| 谁来做 | **Claude 全部自己做**，不委派 |

## 还没定、做的时候要回来问的

- 合上 / 展开动画的时长和曲线：先按 [motion-direction.md](motion-direction.md) 的令牌挑（候选 `settle` 0.56s），做出小样再给 Aaron 看。
- 屏熄时收面板那一下（orderOut 在系统重排显示器时等 110–480ms）能不能挪开，先量再说，不在这一版里硬改。

## 第二次拍板（2026-10-01 傍晚，推翻“一次性动画”）

一次性动画试下来，展开那半几乎看不见（屏亮要 0.3 秒以上，动画在人看过去之前就播完了）；改成展开跟角度后，
Aaron 进一步定：**合上也跟手**。下表**取代上表里冲突的行**；没冲突的照旧（15° 相对触发、只用推送、录序列回放测试、Claude 自己做）。

| 问题 | 答案 |
| --- | --- |
| 合上、展开 | **都跟着盖子走**。“一次性动画”作废 |
| 合上的进度 | 从触发点（静止角度 − 15°）到 35° 跟着走（静止角度很低时，终点取触发点再往下 20°），两头 smoothstep |
| 展开的进度 | 从开始展开的角度（合到一半时的最低点，或屏亮时的角度）到合盖前的静止角度 |
| 盖子停住 | **停在哪就是哪，一直跟手**。之前临场加的“停 1 秒自动播完”作废 |
| 录屏 | **保留录屏流**（跟手时桌面要是活的）；进度到 1、盖子不动时定格并降到 1fps |
| 锁屏效果 | **和桌面效果同一套规则**（LidGesture），删掉设置里的“触发角”滑块 |
| 倾斜 | **合盖效果里不用倾斜**，加速度计不再为它开；设置里的倾斜开关一并删掉（再没有别处用它，留着就是一个不起作用的开关） |
| 屏熄 / 屏亮 | 照旧：屏熄前定格不画新帧；屏亮用合上时留下的最后一帧起步，再跟角度展开 |

架构：**进度由 LidGesture 一处算**（桌面效果和锁屏效果都只读它的进度），DuoController 只负责把进度画出来，
不再自己维护 opening / target 之类的状态。
