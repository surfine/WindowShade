## 当前工作区进展

- 窗口浏览预览启动：把获取窗口列表、启动流两处挂起之间的取消检查集中到 `WindowBrowserPreviewStartup`。租约持有启动 Task，关闭/折叠/切换时取消；旧失败不再消耗新预览的重试预算。选择代数同时覆盖 AX 解析期间的 A→B→A 切换，避免旧解析重新发起捕获。
- 设置预览：旧任务失败、首帧等待返回和捕获回调修改共享状态前核对 epoch；只释放自己拥有的 capture。首帧不可用时停掉时钟和流。
- 设置导航：普通入口恢复最近页；再次打开当前页不重建内容、不重置滚动；明确指定页面的入口仍可跳转。设计探针不写最近页偏好。
- 元数据取消：需求增加线程安全执行凭据。关闭面板清除 pending、阻止尚未开始的 IPC；保留已在途槽到回调结算，重新打开时同应用的新请求等待旧任务结束。取消不声称能中断已经进入系统的同步 AX 调用。
- 元数据有界并发：`WindowBrowserMetadataQueue` 允许两个后台应用查询，并为 Dock 保留一个交互位置。按 PID 的 Operation 依赖跨队列保序，包含 scheduler 在 stop/start 时清空的情况；没有用阻塞信号量占住生产执行线程。需求合并、取消与结果发布仍由既有 scheduler/controller 负责。
- 缩略图目标解析：每次视口请求创建独立 `WindowBrowserTargetBatch`，只在串行 AX 解析队列访问。批次按应用实例索引一次枚举，候选仍逐个经过生产身份核验；失效、歧义、缺失或窗口代数改变会重新枚举，歧义仍拒绝。批次随新视口请求替换、面板关闭释放；窗口动作的公开解析入口不能传入缓存。
- 三击输入路径：命中 pending 后立即消费状态并返回 tap；恢复窗口与系统缩放/最小化延后到主队列。AX 命中和几何回退分支也延后系统动作。执行时重新检查功能开关和系统动作是否仍启用。该改动仅移出窗口写操作，命中阶段的同步 AX 与主队列繁忙仍未解决。
- 三击恢复顺序：移除展开后固定等待 140ms 的猜测，接入已有 `verifyRestoredWindow` 成功回调；恢复失败、关闭或验证被新事务替代时不执行系统动作。回调额外拒绝已再次收起、捕获中、恢复中或 Duo 正在准备的新动作；系统动作入口重新核对 AX 窗口 ID。
- 提前三击接线：tap 命中双击后先建立轻量意图，再派发收起；`TitlebarTripleClickIntent` 合并第三下与真实收起完成，早到等待、晚到立即派发、失败/取消不复活、最多执行一次。恢复前核对具体 foldTransactionID。保留已消费连击标记，匹配的第四下及后续点击不绕到 AX fallback；有效期至少覆盖用户的系统双击间隔。派发动作前核对原 AX 元素、ID、角色、PID 和 WindowServer owner，再信任已核验元素，避免排队后按 ID 重新选择目标。仍需真实捕获期间的窗口销毁/重建与连击验收，不声称系统 API 全链路身份已获验证。
- 共用完成等待：从 WindowBrowserAppDelegate 移到 `App/FoldCompletion.swift`，命名改为 foldWaiters。收起入口保存本次 token 快照，展开/清理/转发也按旧 token 取消；回调重入注册的新请求不会被旧操作结算。回滚不再在 forceCleanup 之后重复广播失败。
- 收起验证：`ShadeState.foldTransactionID` 区分同一窗口的多次收起；`FoldVerifier` 保留原有两次重查与最小化补救时序，但每次读取、补救和完成都受当前事务约束。同步 `shade` 返回不再凭 `.folded` 就报告成功；原生高度收起在尺寸验证后明确完成。恢复意图写入失败时及时报告失败，并将 `.folded` 转换移到真正安装状态之后，避免原先非法的 `.folded → .failed`。已验证隐藏的事务不再因源 Space 暂时不活跃而悬挂完成信号，卷帘条展示仍遵守原 Space 规则。
- Duo 资源释放与请求取消：`dispose(job)` 只释放指定且仍为当前的动画；`cancel(job)` 对尚未交给隐藏事务的请求结算失败，使用取消前的 waiter token 快照，避免重入误伤新请求。正常动画结束和 fallback 移交不提前结算失败；`interceptFold` 不再立即报告失败。异步返回按 Job 身份取消，不能按旧窗口 ID 取消新动画。隐藏 watchdog 同时核对 Job、phase 和 hideGeneration；超时时的展开意图转入现有等待隐藏恢复路径。`cancelAll` 按 Job 快照取消，并核对恢复对象的 foldTransactionID。
- 经典卷帘条：辅助动作补齐展开、缩放、关闭，鼠标与辅助动作共用分发入口；未绑定回调时不再假报成功。右侧控制中心间距由 12pt 增至 32pt，保留 28×24pt 点击区域与 4pt 间隔。截图卷帘条的展开动作也改为返回真实分发结果。完整键盘导航与 VoiceOver 真机遍历仍待验收。

维护原则：执行凭据只解决跨队列取消，主线程 scheduler 仍统一管理槽；预览启动助手只解决实际存在的两个挂起点，没有引入通用任务框架。测试使用生产类型，预览竞态用可控 continuation 制造乱序，不以匹配源码字符串作为行为证据。

## AX 成本归因与聚焦窗口回退（2026-09-22）

上一轮修复标题栏输入误抢，属于进展。本轮先实际运行 AX 基准，不根据源码注释推断热点。原有基准将完整 `appWindows` 当作枚举成本，未区分首次与紧邻重复，且 C 字符串格式导致中文应用名丢失；现改用单调时钟、TSV 字符串输出，分列首次/重复完整枚举、原始列表、新建/复用句柄、窗口 ID、桌面小组件过滤与普通属性。
