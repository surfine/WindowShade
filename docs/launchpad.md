# 启动台

把 App 排在主屏幕上，放进文件夹，或从最后一页的 App 资料库里找。

## 打开

- 点菜单里的**启动台**，或按 ⌃⌘L。
- 常显的 Dock 仍在上方，照常能用。
- 搜索是屏幕底部正中一枚玻璃胶囊，落在程序坞上面（iPad 的排法，见 [启动台设计记录](launchpad-design.md) 里
  Aaron 给的 iPadOS 27 参照图）；页码点压在它上面。放底部既照 iPad，也不会跟从顶部中间长出来的刘海打架。
- **负一屏**照 iPad 的排法：左边日期/时钟和当月日历，右边实时活动（音乐、耳机、隔空投送、路线）和四个快捷方式。
  搜索框不在这里——它就是页脚那枚胶囊，负一屏也有同一枚。只展示本机实时数据，不读取日历事件，也不模拟第三方小组件。

## 找应用

- 左右翻页，一页放不下就下一页。也可以按 Page Up / Page Down。
- 用方向键选择，按 Return 打开。App 资料库也能这样用。
- 直接打字就能搜。名字、中文拼音、首字母、小鹤双拼都行（“微信”打 weixin、wx、wwxb 都找得到；双拼至少打两个键）。
- 第一页上 Apple 应用排在前面。
- 实用工具默认收进**其他**文件夹，不铺在第一页。

## 手势

- 主屏幕两指**左右**划：第一页往右是负一屏，最后一页往左是 App 资料库。
- **往上**划、打开着的返回手势、两指**捏合**都撤回：搜索列表 → 文件夹 → 编辑 → 搜索 → 负一屏/资料库 → 收起。
- **从刘海来、回刘海去。** 点一下刘海打开主屏幕时，画面从刘海那一小块长满全屏；在第一页再点一下刘海，收回刘海里。
  把文件交给刘海时，主屏幕只亮能打开它的 App（见 [刘海](notch.md)）。
- **往下**划收起启动台，按系统设置里给 Spotlight 设的快捷键（默认 ⌘空格）把系统的 Spotlight 叫出来，不自己造一个搜索窗口；这个快捷键被关掉时，留在启动台里用它自己的搜索，并轻轻说一声。
- 刘海下拖：把 App 拖到刘海那一块，先恢复它原来收起的卷帘条或侧拉状态，否则才回主屏幕。左右分别是资料库、负一屏，往上撤回，捏合回主屏幕。

## 编辑主屏幕

- 长按图标进入编辑。
- 拖动图标改顺序。
- 把图标悬停到另一个 App 上，建一个文件夹。
- 把图标拖进已有的文件夹。
- 从打开文件夹的边缘把图标拖出来。
- 拖动中按 Esc，恢复拿起前的排列。松手后才保存。
- 点文件夹标题改名。
- **从主屏幕移除**只挪走这个入口。App 没卸载，资料库还在。想要回来就**添加到主屏幕**。

## 最后一页：App 资料库

- 按应用自己声明的分类摆。
- **建议**显示最近用过的 App，**最近添加**按加入应用文件夹的时间排。
- 应用没提供资料，这些组可能不出现。
- 点分类里的大图标直接打开。
- 点小图标组，展开这个分类。
- 搜索会列出所有 App，不只看当前这一页。
- 没有结果时显示“没有找到 App”。
- 排列是 iPadOS 26 那种四列参考（不追求与 iPad 逐像素相同）。

## 把 App 拖到屏幕位置

不在编辑状态时，按住图标直接拖出来，可以放到半屏、四分之一、铺满或侧拉。

目标 App 没有普通窗口，或者不支持调整大小，就不保证能摆到位。

## 保存

排列保存在这台 Mac 上，不通过 iCloud 同步。

## 开发验证

- `bash tests/run-launchpad-tests.sh`（模型、搜索、排列完整性）。
- `bash tests/run-launchpad-view-tests.sh`（需要 macOS 图形会话；验证静止拖拽合并、主屏幕与文件夹边缘翻页、松手停止、关闭取消、连续切换文件夹、扫描与编辑交错、键盘、辅助功能结构、材质回退和异步图像更新）。
- `bash tests/run-launchpad-perf.sh`（无头性能基线：扫描 / 图标 / 每一页与分类的布局逐段计时，**锁屏也能跑**）。
- `prototype/build.sh --stage`，然后
  `PROBE_SHOTS=<绝对目录> bash tests/run-glance-probe.sh --launchpad`
- 探针只修改内存中的排列，并检查用户保存的排列没有变化。

此前的模型、AppKit 和原生探针已覆盖基础流程；本轮新增负一屏和刘海导航的检查记录另见 `.build/launchpad-fidelity/`。真实多指触控仍需手动体验；主屏幕键盘操作（含负一屏）尚未单独覆盖。原来用打开 `Spotlight.app` 的办法在本机因 launchd 失败；现在改为按用户自己的 Spotlight 快捷键，还没在真机上走一遍。
搜索框走过一个来回：底部胶囊（iPad 的样子）→ 顶端平面磨砂（macOS 15 启动台的样子）→ 现在回到**底部玻璃胶囊**
（程序坞上面，Aaron 给的 iPadOS 27 参照图就是这个位置）；负一屏跟着一起按 iPad 排
（`tests/run-launchpad-visual-fixture.sh` 出图核对）。

本功能尚未发布。
