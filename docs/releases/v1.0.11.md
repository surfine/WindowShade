# WindowShade 1.0.11 · 暂时让开，位置还在

[产品官网](https://windowshade.pages.dev/) · [互动考古](https://windowshade.pages.dev/history/) · [English website](https://windowshade.pages.dev/en/)

把窗口卷成一条标题栏，需要时在原处展开。这次发布整理了日常界面、批量折叠路径，也给这个老想法做了一个可以亲手体验的新入口。

## 中文

### 日常界面

- 四页原生 AppKit 设置，统一侧栏与内容区域的背景，分组和权限状态更清楚。
- 卷帘与置顶预览共用纸面边缘、阴影和圆角；修正悬停标题退出、命中区域与缩放后的边界。
- 菜单中的窗口带应用图标；桌面开合效果与手动窗口折叠动画的说明按实际行为区分。

### 折叠与恢复

- 批量操作复用窗口枚举与捕获准备，减少重复 AX 查询；批量折叠跳过多窗同时播放的动画。
- 折叠动画在覆盖层显示前测量源窗口顶部，复用测量结果；自身设置窗口使用 AppKit 的实际内容边界。
- 单窗口截图显式排除阴影，减少截图坐标与窗口尺寸之间的偏移。
- 保留折叠前的恢复记录、隐藏结果检查和恢复验证。性能记录也保留在仓库，未把单机结果宣传为所有应用的速度保证。

### 一个可以操作的历史

- 中英文官网与七章互动长文，从早期共享软件、System 7.5 的偏好、Mac OS 8 的按钮，讲到 Aqua、第三方延续和今天。
- 四个轻量交互展品；通过 Infinite Mac 按需启动 System 7.5、Mac OS 8.0 和 Mac OS X 10.1。
- Classic、Platinum 与早期 Aqua 分别校准外观，重绘、替代字体与原始史料明确区分。
- README 保留真实演示、快捷键、设计笔记、历史发布记录和来源致谢。

### 安装与已知边界

下载下方 **WindowShade-v1.0.11.zip**，解压后将应用移入“应用程序”。需要 **macOS 14+、Apple Silicon**；本包不包含 Intel 二进制。附带 SHA-256 校验文件。

沿用现有 **Apple Development** 签名及 bundle 标识，**尚未公证**。若首次启动被 macOS 阻止，请使用系统“隐私与安全性”里的“仍要打开”。系统可能按安装与权限状态再次要求授权。

自绘工具栏、全屏、Split View、Stage Manager、Adobe 工作区及多显示器组合仍存在兼容边界。此次顶部测量调整有实际案例反馈，但不代表全部应用均已验证。截图里的工具栏按钮不都可直接操作。合盖效果和实验性倾斜依赖机型暴露的传感器。

## English

### Make room. Keep your place.

This release brings a calmer native settings window, shared paper styling for shades and pinned previews, and an illustrated home for the idea behind WindowShade.

- **Native interface:** four AppKit settings pages, clearer permission states, app icons in window menus, and corrected hover-title and hit-test boundaries.
- **Folding:** shared discovery and capture preparation for bulk actions, fewer repeated AX queries, and no overlapping animations during bulk folds. A fold animation measures the source window's top region before its cover appears. Single-window screenshots explicitly exclude shadows.
- **Recovery:** recovery records, hidden-state checks, and restore verification remain in place. Performance findings are documented without promising the same timings for every app.
- **History:** a bilingual product site, seven interactive chapters, four reconstructed exhibits, and three actual old systems supplied on demand by Infinite Mac. Era references, substitute fonts, and original sources are identified.

Download **WindowShade-v1.0.11.zip** below. Requires **macOS 14+ and Apple Silicon**. The arm64 app retains its Apple Development signing identity and bundle identifier; it is **not notarized**. If macOS blocks first launch, use its Privacy & Security “Open Anyway” flow. A SHA-256 checksum is included.

Custom toolbars and advanced window arrangements still have compatibility limits. The crop adjustment has feedback from the reported case, not an all-app certification. Captured toolbar artwork is not fully interactive. Lid and tilt effects depend on available hardware sensors.

## Validation / 验证

- Optimized Swift build and Metal compilation; original Apple Development identity, version 1.0.11 / build 11, arm64.
- Core state and recovery, frame metadata, capture/integration guards, and paper-component regression checks.
- Signed native fixture: animated folding and restore, reverse during preparation, dragged-strip restore position, and synchronous cancellation.
- Packaged zip extracted again and checked for signature, version, and architecture.
- Native settings and component inspection recorded in [design-v1.md](https://github.com/surfine/WindowShade/blob/v1.0.11/docs/design-v1.md); the existing reported toolbar case has user feedback, not a claim of comprehensive third-party-app testing.
- Website build and asset checks, with the previously verified desktop/mobile history interactions retained.
