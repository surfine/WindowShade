# WindowShade 1.0.13 · 窗口浏览的成熟版

[产品官网](https://windowshade.pages.dev/) · [互动考古](https://windowshade.pages.dev/history/) · [English website](https://windowshade.pages.dev/en/)

1.0.12 让窗口浏览上线；1.0.13 把它的调度、所有权、界面与材质都做到可以天天用：面板更紧凑、状态更清楚、截图与实时画面不再抢额度，并新增可预览、可撤销的基本窗口排布。

## 中文

### 界面与手感

- **单窗口面板不再留一大片空白。** 面板尺寸由内容决定：一个窗口约 312×349 pt，两个窗口约 612 pt 宽，六个以内最多三列，之后自动转紧凑列表（宽度仍受上限约束，不占满显示器）。
- **窗口截图与标题优先。** 卡片顶部是真实画面与标题，动作收进一个紧凑的符号操作条：悬停或键盘选中时出现，空间提前预留，出现时不挤动标题。
- **状态不再用 emoji。** 已折叠、置顶预览、预览已暂停、已最小化、应用已隐藏、屏幕外、正在展开各自使用系统符号与中性文字；已折叠且停在屏外是正常状态，不再显示异常警告。
- **原生行为保持原生。** 系统字体与中文回退、系统搜索框、系统菜单、标准按钮与键盘焦点；方向键按真实列数移动，Home/End 跳到首尾，输入法候选优先于面板快捷键。
- **纸面与玻璃共用同一套组件。** 设置预览、Dock 面板与键盘面板用的是同一份视图，不是两套皮肤。

### 材质

- **macOS 26 及以上使用公开的 AppKit Liquid Glass**（`NSGlassEffectView`），控制层是真实玻璃；不支持的系统使用系统原生材质，选择“纸面”或开启“减少透明度”时使用不透明背景，开启“提高对比度”时加粗边线、选中不只靠颜色，开启“减少动态效果”时不做位移与缩放。
- 玻璃只进入操作层，窗口截图与长列表保持普通内容；没有私有图层效果、KVC 或整屏截图伪造。
- 编译条件与运行条件分开处理：构建时探测 SDK 是否带公开玻璃 API，运行时再判断系统版本，最低运行目标仍是 **macOS 14**。

### 排布与撤销（新）

- 窗口卡片右键 → **排布**：左半屏、右半屏、四角、居中、填满可用区域、移到另一显示器，以及**预览**（只画目标位置轮廓）与**撤销上次排布**。
- 执行前重新核对完整窗口身份、读取原位置；写完后读回验证（容差 2 pt），验证通过才登记撤销。用户已经手动移动过窗口时，撤销会被拒绝并说明原因。
- 填满可用区域使用工作区域（不含菜单栏与 Dock），与系统全屏不同，不搬运 Space。

### 稳定性与资源

- 截图任务改为显式记账：每个物理任务有不可复用的编号，只有唯一的调度入口能启动它；被取消但系统仍在执行的截图继续占用并发额度，直到真实完成才归还，取消不再可能让额度永久泄漏，也不会重复启动同一个任务。
- 订阅有明确终态：完成、失败、取消都会通知控制器并释放回调；面板关闭只表示消费者取消，系统任务是否结束单独结算。
- 实时预览只有一个明确挂载点，网格与列表切换只迁移画面不新建流；旧任务的失败、超时、找不到来源都只清理自己的资源；同一窗口每会话最多自动重试两次，权限被拒绝或来源消失时立即停止重试。
- Dock 检测：只有真正包含鼠标的那块屏幕才判断边缘；AX 通知、鼠标回退与延迟复检共用一个“一个在途 + 一个最新位置”的队列；同一个图标放大或移动只更新锚点，不重建窗口列表。
- 空闲时不做任何定时扫描；关闭功能或退出时会释放新增的观察器、截图与预览流，原有折叠、恢复日志与置顶预览不受影响。

### 性能（同一台机器的前后对照）

| 场景 | 1.0.12 基线 | 1.0.13 |
| --- | --- | --- |
| 120 个窗口首次填充与布局 | 200.4 / 248.6 ms（p50/p95） | **17.8 / 19.7 ms** |
| 局部 UI 更新（暖刷新） | — | p95 0.64–1.67 ms（预算 4 ms） |

测量环境：MacBook Air（M5，24 GB）、macOS 27.0、Xcode 26.6、macOS SDK 26.5；数据为确定性测试记录，原始输出与口径见仓库 `docs/window-browser-performance.md`。

### 本次一并修好的问题

- 两个截图任务同时运行、其中一个先完成时，另一个可能被再次启动。
- 面板关闭/缓存失效后，晚到的截图回调可能永远不归还并发额度。
- 卡片与列表行被自己的右键闭包保活，关闭面板后不释放。
- 同一实时画面可能先放进卡片、随后又被放进隐藏的列表详情区。
- 旧窗口的实时预览失败时会释放当前新窗口的预览。
- 键盘面板的搜索框不在顶部、列表曾压住搜索框。

## English

### What changed

- **Compact, content-driven panel.** One window ≈ 312×349 pt, two windows ≈ 612 pt wide, up to three columns, then a compact list. Window thumbnails and titles come first; actions live in a compact symbol bar that appears on hover or keyboard selection without shifting the layout.
- **No emoji status.** Folded, pinned, paused, minimized, app hidden, off-screen and restoring each use a system symbol plus neutral text. Folded-and-off-screen is a normal state, not a warning.
- **Native behaviour.** System fonts, system search field, system menus, standard buttons and keyboard focus; arrow keys follow the real column count and input-method candidates keep priority.
- **Real Liquid Glass on macOS 26+** through the public `NSGlassEffectView`, with native-material and opaque-paper fallbacks for older systems, Reduce Transparency, Increase Contrast and Reduce Motion. Minimum target stays macOS 14.
- **New: arrangement with preview and undo.** Left/right half, corners, centre, fill the work area, move to another display, preview the target outline first, and undo the last arrangement. The full window identity is re-validated, the result is read back and verified, and undo is refused if you have moved the window since.
- **Reworked scheduling and ownership.** Job-based accounting with a single dispatch path, subscriptions that always reach a terminal state, a single live-preview mount point, and Dock detection that shares one in-flight budget with a single latest pointer position.

120 windows now lay out in 17.8 / 19.7 ms (p50/p95) instead of 200.4 / 248.6 ms. Full numbers, screenshots and known gaps live in `docs/window-browser-performance.md` and `docs/window-browser-visual-qa.md`.

## 安装与已知边界

下载下方 **WindowShade-v1.0.13.zip**，解压后将应用移入“应用程序”。需要 **macOS 14+、Apple Silicon**；本包不包含 Intel 二进制，附带 SHA-256 校验文件。

沿用现有 **Apple Development** 签名及 bundle 标识，**尚未公证**。若首次启动被 macOS 阻止，请使用系统“隐私与安全性”里的“仍要打开”。

窗口浏览需要**辅助功能**权限，缩略图与实时画面还需要**屏幕录制**权限。面板是临时窗口：它不替换系统 Dock，也不接管原生 Command-Tab。

尚未实机验证的项目（需要授权的新构建或额外硬件）：真实 Dock 悬停/斜向移动与真实焦点、真实折叠与排布、玻璃折射的整窗截图、1x 与多显示器/120 Hz、WindowServer 能耗与长时间会话内存。仓库内的 `docs/window-browser-visual-qa.md` 列出了逐项手工步骤。
