# WindowShade v1.0.9

## 中文

### 这次更新

这一版把主程序拆成了模块，同时补了一批稳定性和省电改进。

- 折叠更安全：折叠前先记录窗口状态，意外退出后也能找回；离屏救援会验证恢复结果，不再误删记录
- 置顶预览更省电：空闲时自动降频，断流后自动重试恢复
- 折叠截图缓存按用途分开，并设置了内存上限
- 主程序从单个近 9000 行的文件拆成 App/、Capture/、Compatibility/、Overlay/、Recovery/、Window/ 等模块，行为保持不变
- 签名身份改为外部配置，不再出现在仓库里

升级不会重置辅助功能或屏幕录制授权。

## English

### Highlights

This release splits the app into modules and adds a round of stability and battery work.

- Safer folding: window state is recorded before hiding, so a crash no longer strands a window; off-screen rescue verifies what it restores
- Pinned previews use less power: they drop to a lower frame rate while idle and retry after an interruption
- Fold captures use separate caches per purpose with a memory cap
- The near-9000-line main file became focused modules (App/, Capture/, Compatibility/, Overlay/, Recovery/, Window/) with no behavior change
- The signing identity moved to external configuration and is no longer kept in the repository

Upgrading preserves Accessibility and Screen Recording authorization.
