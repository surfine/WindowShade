# WindowShade v1.0.9

## 中文

### 这次更新

里程碑版本：代码完成大规模模块化，同时补充稳定性和性能改进。

- 折叠前先记录状态并验证离屏救援结果
- 置顶预览空闲时自动降频，断流后重试
- 折叠截图缓存按用途分开并设置内存上限
- 主程序拆分为清晰模块，行为保持不变
- 签名身份改为外部配置

升级不会重置辅助功能或屏幕录制授权。

## English

### Highlights

A milestone release with a modularized codebase plus stability and performance work.

- Record fold state before hiding and verify rescue results
- Reduce pinned-preview frame rate while idle and retry after interruptions
- Separate fold-capture caches and cap memory use
- Split the implementation into focused modules without changing behavior
- Move the signing identity to external configuration

Upgrading preserves Accessibility and Screen Recording authorization.
