# WindowShade v1.0.9

## 中文

### 折叠

- 折叠前先记录窗口状态：WindowShade 意外退出或崩溃后，下次启动会把窗口找回来
- 离屏救援会验证恢复结果，不再误删记录
- 折叠截图缓存按用途分开，并设置了内存上限

### 置顶预览

- 空闲时自动降频，断流后自动重试恢复，长时间挂着更省电

升级不会重置辅助功能或屏幕录制授权。

## English

### Folding

- Fold state is recorded before hiding, so if WindowShade quits or crashes, the next launch finds those windows and brings them back
- Off-screen rescue verifies what it restores instead of dropping records
- Fold captures use separate caches per purpose with a memory cap

### Pinned previews

- They drop to a lower frame rate while idle and retry after an interruption, so leaving them on costs less power

Upgrading preserves Accessibility and Screen Recording authorization.
