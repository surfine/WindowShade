# WindowShade v1.0.9

## 中文

### 这次更新

这一版让折叠更省心，也更省电。

- 窗口更安全：折叠前先记录窗口状态，WindowShade 意外退出或崩溃后，下次启动会把窗口找回来；离屏救援会验证恢复结果，不再误删记录
- 更省电：置顶预览空闲时自动降频，断流后自动重试恢复
- 更省内存：折叠截图缓存按用途分开，并设置了内存上限
- 升级不会重置辅助功能或屏幕录制授权

## English

### Highlights

This release makes folding less nerve-racking and easier on the battery.

- Safer windows: fold state is recorded before hiding, so if WindowShade quits or crashes, the next launch finds those windows and brings them back; off-screen rescue verifies what it restores instead of dropping records
- Less power: pinned previews drop to a lower frame rate while idle and retry after an interruption
- Less memory: fold captures use separate caches per purpose with a memory cap

Upgrading preserves Accessibility and Screen Recording authorization.
