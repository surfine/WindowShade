## 二、只有真手才能验的（约 20 分钟，可另找时间）

每条验完在 `docs/product-reshape-spec.md` 对应表格的"通过的样子"后面记一行：日期、设备、结果、录屏／截图位置。

- [ ] **V1 盒盖手感。** 设置里开"桌面开合"，把屏幕从全开慢慢合到约 30°，再快速合到底，再慢慢打开，各两遍。看折进刘海那一下是否跟手、有没有顿挫或跳帧；只有你说"可以"才算过。机器没法替你判断手感。
- [ ] **V5 真触控板。** 内置触控板和外接妙控板各做一遍：三指甩一下（快、慢各三次），卷轴里两指左右拖着走再松手。看落点、速度对不对，跟手时有没有滞后。要真手指，合成事件测不出手感。
- [ ] **R25 两块板子互不打断。** 在 V5 里顺手验：两块板子同时放手指，一块的手势不能打断另一块；故意中断一次手势，下一次照常。要两块真设备和真手指。
- [ ] **V6 妙控鼠标／罗技滚轮。** 本机没有这两种鼠标，要借。妙控鼠标单指左右滑、滚动；罗技带侧键，试滚轮上下、横滚、侧键。看卷轴方向与步长对不对、会不会误触发手势。要真硬件。
- [ ] **V9 插拔外接屏。** "接着两块"已自动验过。你要补：拔掉外接屏再接回、改一次分辨率、接两块同型号的屏。每类看卷帘条、收起记录和展开后的窗口位置是否还在对的那块屏上。要真的插拔线。
- [ ] **R2 关辅助功能要有提示。** App 运行中，在系统设置里把 WindowShade 的辅助功能关掉（要管理员密码）。预期：10 秒内出现说明（刘海或菜单栏），菜单最上面多一行"打开辅助功能…"；重新打开后恢复且不重复打扰。机器拿不到管理员密码，虚拟机里也模拟不成立。
