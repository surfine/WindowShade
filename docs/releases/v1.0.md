# WindowShade v1.0

## 中文

### 这次更新

WindowShade 1.0 首发：把窗口卷起来，只留一条标题栏入口，想用时再展开。

- Control + Command + C 折叠或展开当前窗口
- 双击标题栏折叠，点击卷帘条预览内容
- Control + Command + P 将当前窗口置顶为实时预览
- Control + Command + 1…9 从菜单顺序恢复折叠窗口
- 支持原貌卷帘和标准标题栏两种样式，以及透明度、音效和登录启动

需要辅助功能权限来读取和恢复窗口；原貌卷帘和预览需要屏幕录制权限。

## English

### Highlights

WindowShade 1.0 is the first release: roll a window up into a title-bar entry and open it again when needed.

- Fold or unfold the current window with Control + Command + C
- Double-click a title bar to fold it; click the strip to preview it
- Pin the current window as a live preview with Control + Command + P
- Restore folded windows in menu order with Control + Command + 1…9
- Choose Native or Proxy Title Bar strips, with transparency, sounds, and launch at login

Accessibility is required to read and restore windows. Native strips and previews require Screen Recording access.
