# WindowShade v1.0

## 中文

### 这次更新

首发：把窗口像卷帘一样收起来，只留一条标题栏，想用时再展开。

- Control + Command + C 折叠或展开当前窗口，双击标题栏同样可以
- 点一下卷帘条预览内容；Control + Command + P 把窗口置顶成实时预览
- Control + Command + 1…9 按菜单顺序恢复折叠窗口，Control + Command + 0 整理卷帘条
- 两种卷帘样式（原貌截图 / 标准标题栏），支持透明度、音效与登录启动

需要辅助功能权限来读取和恢复窗口；原貌卷帘和预览需要屏幕录制权限。窗口内容不会离开这台 Mac。

## English

### Highlights

The first release: roll a window up into a title bar entry and open it again when you need it.

- Fold or unfold the current window with Control + Command + C, or by double-clicking its title bar
- Click a strip to preview the window; pin it as a live preview with Control + Command + P
- Restore folded windows in menu order with Control + Command + 1…9, and tidy the strips with Control + Command + 0
- Two strip styles (native capture or proxy title bar), plus transparency, sounds, and launch at login

Accessibility is required to read and restore windows. Native strips and previews require Screen Recording access. Window contents never leave your Mac.
