# WindowShade 1.0.18 · 一装上就是它最好的样子

[产品官网](https://windowshade.aaronlau.me/) · [English website](https://windowshade.aaronlau.me/en/)

已发布（2026-10-18）。

## 中文

### 一句话摘要（appcast 用）

设置里每一页都带一段演示，指到哪一行就演哪一行，侧栏还能搜索；刘海、刘海里的实时活动、文件架、Dock 悬停查看窗口这一版起默认打开（自己改过开关的不动），升级后会告诉你新开了什么。需要 macOS 15 或更新版本。

### 升级前请看这里

- **从 1.0.17 升级照旧**：菜单里「检查更新」一键安装，授权不用重开。
- **这一版起一批功能默认打开。** 新装、和从没动过这些开关的人：用刘海收纳窗口、刘海里的实时活动（正在播放、设备的电量、音量和亮度）、文件架、再点一下 Dock 图标让开、停在 Dock 图标上看窗口，都默认开。**自己开过或关过的不动。** 升级上来会弹一次「这一版新开了这几样」，只列真变了的。
- **从 1.0.16 及以前升级**：还是要手动下载一次（换证书那一步在 1.0.17），装好后重新打开辅助功能和屏幕录制；装好会引导你。
- **需要 macOS 15 或更新版本**（Apple Silicon）。
- **第一次下载的人拿到的是 DMG 安装包**：把 WindowShade 拖进「应用程序」就好；更新还是走菜单里的「检查更新」。

### 新增

- **设置里每一页顶上都有一段演示。** 指到哪一行，就演那一行说的那件事：手做什么、屏幕上发生什么，都画出来。八个页面都有；关着的开关演「关着」的样子；开了「减少动态效果」就停在关键帧。
- **设置侧栏能搜索。** 打字或打拼音都行，结果按页面分组，点一下跳过去闪两下。
- **欢迎窗口重做。** 先看你把窗口双击成一条卷帘条，再换你亲手试一下；然后是授权（屏幕录制可选）；最后再看四样：收进刘海、停在 Dock 图标上看窗口、两指排窗口、菜单栏在哪。
- **停在 Dock 图标上的窗口预览卡，左上角有红黄绿。** 关窗、最小化、全屏，和窗口左上角一样。窗口浏览面板里也能用 ⌘W 关窗、⌘M 最小化、⌃⌘F 全屏。
- **新的 App 图标。**
- **启动不再弹系统的授权框。** 要授权只在欢迎窗口里点「去授权」时弹。

### 改进与修复

- **设置窗口打开时提到最前面**，不再藏在别的窗口后面。
- **启动台开着时，平滑滚轮一次翻一页**（含文件夹）；标题栏上的滚轮手势也认得出平滑滚轮了。
- **「正在播放」跳完一首或点过暂停后，画面立刻对上**，不用等它慢慢滑回来。
- **调度中心认得更稳**；菜单栏图标重建时不再闪一下。
- **偶发收起卡住时按真实状态收尾**，窗口不会凭空消失。
- 刘海页「日程」一行的开关贴齐右边；刘海里第二件活动中途改方向不再错位；窗口浏览页英文说明放不下时换短句；繁体词条重新生成时不再丢手工加过的。

## English

### One-line summary (for the appcast)

Every Settings page now carries a short demo that acts out the row you point at, and the sidebar searches (typing or pinyin). The notch, Live Activities in the notch, the file shelf, and Dock window previews are on by default this release (your own choices stay); after updating, a note tells you what's new. Requires macOS 15 or later.

### Before you update

- **From 1.0.17: one click**, as always. Permissions stay on.
- **A batch of features turns on by default.** For new installs and for anyone who never touched these switches: tucking windows into the notch, Live Activities in the notch (Now Playing, device battery, volume and brightness), the file shelf, click-the-Dock-icon-again to make way, and hovering the Dock icon to see windows. **If you set any of these yourself, nothing changes.** After updating, a one-time note lists what actually turned on.
- **From 1.0.16 or earlier**: still one manual download (the certificate change was in 1.0.17); re-enable Accessibility and Screen Recording after installing.
- **Requires macOS 15 or later** (Apple Silicon).
- **First downloads now come as a DMG**: drag WindowShade into Applications. Updates still go through Check for Updates in the menu.

### New

- **Every Settings page has a demo band.** Point at a row and it acts that row out — what your hand does, what happens on screen. All eight pages have it; a switched-off setting shows its "off" look; Reduce Motion shows key frames.
- **The Settings sidebar searches.** Type words or pinyin; results group by page, and clicking jumps there with a flash.
- **The welcome window is new.** Watch a window roll up into a bar, then try it yourself; then permissions (Screen Recording optional); then four more things to see.
- **Dock window previews have traffic lights** — close, minimize, full screen — top-left, like real windows. In the window browser panel, ⌘W, ⌘M, and ⌃⌘F work too.
- **A new app icon.**
- **Launching no longer pops the system permission dialog.** Prompts now appear only when you click Grant in the welcome window.

### Improvements and fixes

- **The Settings window comes to the front** when opened, instead of hiding behind other windows.
- **Launchpad with smooth scrolling now pages per tick** (folders too); title-bar wheel gestures recognize smooth scroll wheels.
- **Now Playing snaps to the right track right away** after a skip or pause, instead of gliding back.
- **Mission Control is recognized more reliably**; the menu bar icon no longer blinks when rebuilt.
- **When a roll-up stalls, the window settles to its real state** instead of vanishing.
- The Calendar row's switch aligns right on the notch page; the second Live Activity no longer misplaces when it changes direction mid-animation; overlong English subtitles on the window browser page swap to short phrases; Traditional Chinese entries keep hand-added lines when regenerated.
