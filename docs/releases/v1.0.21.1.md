## 中文

### 一句话摘要（appcast 用）

台前调度下的三处边界修好了：在别的桌面收起窗口不会把你带走、不能最小化的窗口收起时换到另一侧停靠、副屏上的卷帘条被系统挪位后展开仍回到原处。另外，卡住的 App 只要窗口服务器能证明已经藏好，收起就算做成；分屏把手认得出系统自己的左右、上下半屏。

### 这一版改了什么

台前调度与多桌面：

- **在别的桌面收起，不带走你。** 窗口在另一张桌面时收起不再借「隐藏整个 App」（那会让系统换桌面找继承人）；兜底回位守的是「收起那一刻你在看的那张桌面」。
- **当前桌面看不到卷帘条时，会说一句它去了哪。** 例如「已收起到桌面 2」，编号和调度中心一致。刘海开着时出在刘海上，刘海不在时退回菜单栏标题。
- **不能最小化的窗口，收起时换到另一侧。** 台前调度只看守左侧侧条边缘，缩进侧条失败时改停到右边缘，系统不会把它拽回来。
- **副屏上被系统挪过的卷帘条，展开回到原处。** 台前调度会把贴边的辅助窗往里挪（实测 164 点）；系统自己的挪动不再被当成你拖动，展开不再横跳。
- **卡住的 App：** 窗口服务器已经证明停到屏外、或透明度落到 0.05 以下，这次收起算做成，不再弹「收起状态未确认」。其余情况仍保留恢复入口。

分屏：

- **认得出系统的左右、上下半屏。** 系统自己留的那道空档通常 8–10 点，以前 6 点容差认不出来，把手不出现；现在认到 12 点，缝落在空档正中。

手感与外观：

- 提示浮窗终点图标、文件架个数的弹一下，起始缩放从 1.22 / 1.28 收到 1.12；阻尼比不变，仍在 Mac 的上限内。
- 拖窗口到刘海时，落点小岛接上当时的拖动速度，位置和速度都连续。
- 卷轴概览的玻璃不再叠一层：内容放进玻璃里。
- 侧拉那一圈边框和它的挖空蒙版改成连续曲率角，和系统窗口一样。
- 次要字统一到 11 点、次要白统一到 0.6；教学台面圆角与岛同心。
- 菜单栏 OSD 那个位置的提示浮窗，增强对比度时边线 1 点、用 `labelColor`。

权限：

- 打开「隐私与安全性」里还没允许的那一栏时，清单下多一张可拖的卡片：写清在清单里打开哪一项，没有的话把 WindowShade 拖进去。允许了就自己收起。

## English

### Summary (for appcast)

Three Stage Manager edge cases are fixed: rolling up a window that lives on another desktop no longer takes you there, a window that refuses to minimize tucks away past the other edge, and a strip nudged by the system on a second display comes back where it was. Also, a stalled app's roll-up counts as done once WindowServer can prove the window is out of sight, and the split handle now recognizes the system's own halves.

### What changed

Stage Manager and desktops:

- Rolling up a window on another desktop no longer hides the whole app (which made macOS switch spaces to find an heir). The fallback return guard protects the desktop you were looking at, not the window's own.
- When no strip is visible on the current desktop, it says where the window went, using Mission Control's own numbering.
- A window that refuses to minimize flips to the other edge, where Stage Manager does not guard.
- A strip nudged inwards by the system on a second display expands back to where the window was folded.
- A stalled app's roll-up counts as done when WindowServer proves the window is parked off screen or fully transparent; everything else still keeps a recovery entry.

Split view:

- The divider now recognizes the system's left/right and top/bottom halves, whose own gutter is wider than the previous 6-point tolerance.

Feel and appearance:

- Smaller bounce on the HUD endpoint and the file-shelf count (1.12 instead of 1.22 / 1.28), same damping.
- The drop island carries the drag velocity.
- The scroll-strip glass no longer has a second layer behind it.
- The Slide Over ring uses the same continuous corners as system windows.
- Secondary type unified at 11 pt, secondary white at 0.6; the teaching stage radius is concentric with the island.

Permissions:

- Opening a privacy pane that is not yet allowed shows a draggable card under the list, saying which row to turn on and letting you drag the app in if it is missing.
