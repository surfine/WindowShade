## 一、发布 1.0.18（约 10 分钟）

截图统一放 `.build/release-acceptance-2026-10-18/phase1/`，按 `场景-顺序.png` 命名；说不清就记 inconclusive，别猜成 PASS。

### 准备

- [ ] 1. 屏幕已解锁，终端跑 `lsappinfo front`。预期：前台不是 loginwindow。
- [ ] 2. 证据目录里 Phase 0／2／3 都是 pass。预期：Phase 0 只有第 6 项 FAIL（清单还没写 build 18，发布日第 13 步补上）；Phase 3 有定时检查一条 inconclusive 是预期的（发布日第 20 步你点一次看）；其余有 fail 就先停。

### 从 1.0.17 升级与 OOBE（约 4 分钟）

- [ ] 3. 在装着 1.0.17 的机器上，按住 Option 点菜单栏「检查更新…」，指向本地清单（控制端备好）。预期：**一键安装**，装完授权不重开。截图 `update-1.png`。
- [ ] 4. 装完第一次打开。预期：弹一次「这一版新开了这几样」（N1），只列真变了的（没动过开关的人有刘海、实时活动、文件架、Dock 两样）；点「在设置里改…」能到那一页。截图 `n1-1.png`。
- [ ] 5. N1 关掉后再启动。预期：不再弹（只弹一次）。

### 默认值翻开（约 2 分钟）

- [ ] 6. 不动任何开关，朝刘海甩一下标题栏。预期：窗口收进刘海，刘海里列得出来；点一下放回。
- [ ] 7. 播一首歌（Music 或 Spotify）。预期：刘海出现「正在播放」，歌曲信息对。
- [ ] 8. 连着 AirPods 或妙控鼠标看一眼。预期：「设备的电量」在刘海出现。
- [ ] 9. 拖一个文件到屏幕边缘松手。预期：出现文件架。
- [ ] 10. 再点一下最前面 App 的 Dock 图标。预期：这个 App 让开；再点一次回来。
- [ ] 11. 指针停在别的 App 的 Dock 图标上。预期：翻出它的窗口预览；预览卡左上角有红黄绿，点红灯关掉一扇。

### 新界面各看一眼（约 2 分钟）

- [ ] 12. 设置 → 效果页：指到「收起窗口时的动画」那一行。预期：顶上的演示带演这一行说的那件事；指别的行换别的演示；关着的开关演「关着」。截图 `explainer-1.png`。
- [ ] 13. 八个设置页各指一行。预期：每页都有演示带，演的和行说的对得上。
- [ ] 14. 设置侧栏搜索框打「liuhai」。预期：搜出刘海那几行，点一下跳过去闪两下。截图 `search-1.png`。
- [ ] 15. 菜单「欢迎使用 WindowShade…」。预期：A1 先演再让你亲手双击试一下；A2 只等辅助功能；T 四段自己走。
- [ ] 16. 系统设置里开着「减少动态效果」再打开设置。预期：演示停在关键帧，不动。
