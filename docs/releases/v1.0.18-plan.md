# 1.0.18 计划（Aaron 拍板，2026-10-17 晚）

一周内发；机器验收过了就发，直接全推（不走 beta、不分批）。WindowShade 2 这一版不碰。设计稿以 [首次打开 1.0.17 小样](../design-drafts/首次打开%201.0.17%20小样.html) 第 4 版（私有页 https://claude.ai/artifact/R2h7LCy9eQFF1GgH6kHF8u ，提交 943853c）为定稿；稿末「1.0.18 工作单」是实现清单。

## 范围

1. **默认值**：刘海主功能、刘海实时活动、Dock 悬停看窗口、文件架＋点 Dock 隐藏默认开；新装和没动过开关的老用户都开（`ReleaseDefaults` 加 `ownerDecided`）。
2. **OOBE**：三页（A1 看一遍再试一下、A2 辅助功能＋屏幕录制一起问、T 再看四样），升级用户 U1（再打开一次这两项）＋ N1（这一版新开了这几样，只看一次）；启动时不再带 prompt 弹系统框。
3. **整个设置的动画讲解**：共用 `SettingsExplainer`（帧数据纯逻辑＋CALayer 视图＋行接入），八页全做（效果、卷帘、刘海、手势、窗口浏览、快捷键、隐私、高级与实验），欢迎窗口共用同一套。
4. **升级路径修正**：手动从旧版装上来也能看到 U1；启动时系统框与欢迎窗口不再同时出现（并入 2）。
5. **Apple silicon 性能**：`--hitch` 卡顿表进门禁（只报不挡，证据落盘），先量热点，只改有前后数字、行为不变的地方。
6. **1.0.17 遗留小修**：R24 剩的英文长说明、「日程」开关对齐、`short-hant.py` 漏项、NotchLeaseHostTests H11 两条既有失败、设置窗口总在最前（已在基线 be34203）。
