# WindowShade 1.0.21 · Intel 实验版与岛的系统级对齐

[产品官网](https://windowshade.aaronlau.me/) · [English website](https://windowshade.aaronlau.me/en/)

已发布（2026-11-09）。自动更新先走测试频道：`defaults write com.windowshade.prototype WindowShadeUpdateChannel beta` 之后，菜单里「检查更新」才看得到。用一天后去掉频道标记，才对所有人显示。

## 中文

### 一句话摘要（appcast 用）

1.0.21 首次提供 Intel 实验版（单独下载包，Rosetta 冒烟，未在真 Intel Mac 上测过），同时把刘海的转场弹簧与展开几何对齐 macOS 27.3 系统灵动岛：六种动作状态各有自己的弹簧，录音和「等你」的编程会话更弹，收合更快。需要 macOS 15 或更新版本。

### 升级前请看这里

- **Apple Silicon 用户**：这一版先走测试频道。执行 `defaults write com.windowshade.prototype WindowShadeUpdateChannel beta` 之后，菜单里「检查更新」才会看到；用一天确认没问题，再去掉频道标记重发清单，所有人才会收到。
- **Intel 用户**：这是实验版，单独下载 `-intel` 包；刷脸解锁、声纹和合盖桌面效果在 Intel 上关闭。没有真 Intel Mac 实测，遇到问题请开 issue。Intel 的更新清单同样先走测试频道。
- **需要 macOS 15 或更新版本。**

### 新增

- **Intel 实验版。** 独立 zip 与 `appcast-intel.xml`，Homebrew cask 按架构分流；首次运行会先暖 Rosetta 再计时自检。

### 改进

- **岛的转场弹簧对齐 macOS 27.3 系统岛。**
  - listening／prompt（认证、录音、等你的会话）：`0.408 / 0.27`，更有回应感。
  - thinking／response／transient：`0.3571 / 0.75`，和系统内容态一致。
  - 收合 `.hidden`：`0.3 / 0.8`，更快、更收。
- **没有内容的展开岛用系统宽。** 刘海屏 408、外接屏 371；有窗口格或活动卡时仍按内容排版。
- **活动自己的弹簧。** 录音和「等你」的编程会话的紧凑两耳用 prompt 弹簧；音乐、计时器、下载等仍用内容弹簧，排序与三件上限不变。
- **中途反向更顺。** 形变按五轴接力，连续改目标不会先停一下再跳。

### 已知

- Intel 版没有真机测试，仅 Rosetta 冒烟与 x86_64 交叉编译通过。
- 岛的新弹簧与 408 宽度没有 PROLED 真机视觉验收，模型与构建验证通过。

## English

### Summary (for appcast)

1.0.21 adds an experimental Intel build (a separate download, smoked under Rosetta, not tried on a real Intel Mac) and aligns the notch’s transition springs and expanded geometry with the macOS 27.3 system island: each of the six motion states has its own spring, recording and a coding session that’s waiting on you feel more responsive, and collapsing is quicker. Requires macOS 15 or later.

### Before you upgrade

- **Apple Silicon:** this build goes out on the beta channel first. After `defaults write com.windowshade.prototype WindowShadeUpdateChannel beta`, Check for Updates can see it. Once it has been used for a day, the channel tag comes off and everyone else gets it.
- **Intel:** this is an experiment. Download the `-intel` package on its own. Face unlock, voiceprint and the lid-close desktop effect are off. It has not been tried on a real Intel Mac; if something goes wrong, please open an issue. The Intel feed is on the beta channel for this first publish too.
- **Requires macOS 15 or later.**

### New

- **Experimental Intel build.** Its own zip and `appcast-intel.xml`. The Homebrew cask picks the zip for the Mac’s architecture. The first launch warms up Rosetta before the timed self-check.

### Improvements

- **Notch transition springs match the macOS 27.3 system island.**
  - listening / prompt (authentication, recording, a session waiting on you): `0.408 / 0.27`, more responsive.
  - thinking / response / transient: `0.3571 / 0.75`, the same as the system’s content states.
  - collapsing `.hidden`: `0.3 / 0.8`, quicker and tighter.
- **An empty expanded island uses the system width.** 408 on a notched display, 371 on an external display. Windows and activity cards still lay out from their content.
- **Activities bring their own spring.** Recording, and a coding session that’s waiting on you, use the prompt spring on the compact ears. Music, timers, downloads and the rest stay on the content spring. Order and the three-item cap are unchanged.
- **Reversing mid-transition is smoother.** The morph retargets on five axes, so a new target doesn’t stop and then jump.

### Known

- The Intel build has no real-hardware test, only a Rosetta smoke test and an x86_64 cross-compile.
- The new springs and the 408 width have no visual check on a PROLED Mac. Model and build checks passed.
