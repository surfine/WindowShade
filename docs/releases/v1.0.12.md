# WindowShade 1.0.12 · 悬停 Dock 图标，看清每个窗口

[产品官网](https://windowshade.pages.dev/) · [互动考古](https://windowshade.pages.dev/history/) · [English website](https://windowshade.pages.dev/en/)

窗口浏览是这个版本的主角：鼠标停在 Dock 图标上就能看清那个应用的所有窗口，也可以从菜单或自设快捷键打开一个能搜索的面板。

## 中文

### 窗口浏览（新）

- 鼠标停在 Dock 的应用图标上，弹出该应用的真实窗口面板；移开即收起。
- 两种布局：缩略图卡片，或紧凑列表（右侧显示选中项的较大预览）。顶部分段控件随时切换，也能搜索应用名或窗口标题。
- 菜单里的“选择窗口…”或你自设的快捷键打开键盘面板，搜索框可以直接输入。
- 卡片直接给出动作：打开 / 展开、折叠、置顶预览、关闭、最小化（按窗口实际能力显示）。
- Dock 入口默认关闭，可在**设置 → 窗口浏览**打开；同一页还能录制独立快捷键、按应用排除、查看权限状态。

### 目标身份与安全边界

- 每个动作都绑定你选中的那个窗口的完整身份（应用实例 + 原窗口 ID + 会话代数），执行前重新核对；确认不了就拒绝执行，不会拿标题、列表位置或当前焦点去猜另一个窗口。
- 折叠与展开复用原有的折叠事务、恢复验证与恢复日志：没有第二套简化的离屏隐藏逻辑，也没有改动恢复记录。
- 异步结果一律核对请求代数与所有者：换到别的窗口再换回来、面板关闭后才返回的截图、旧面板释放新镜像、恢复验证失败、视频流在关闭之后才启动，都会被丢弃。

### 缩略图与实时画面

- 先出标题和已有缓存，再按需补图。截图只针对目标窗口（单窗捕获）；失败时用应用图标加说明，不会退回整屏截图裁切。
- 普通窗口的实时预览默认关闭。开启后，选中项停 0.4 秒才起一路流，临时面板最多新增一路；该窗口已有置顶预览时复用它的镜像。

### 本次一并修好的界面问题

- 搜索框被窗口列表压住。
- 分段控件已经切到“列表”，内容却还是缩略图网格。

### 安装与已知边界

下载下方 **WindowShade-v1.0.12.zip**，解压后将应用移入“应用程序”。需要 **macOS 14+、Apple Silicon**；本包不包含 Intel 二进制，附带 SHA-256 校验文件。

沿用现有 **Apple Development** 签名及 bundle 标识，**尚未公证**。若首次启动被 macOS 阻止，请使用系统“隐私与安全性”里的“仍要打开”。

窗口浏览需要**辅助功能**权限，缩略图与实时画面还需要**屏幕录制**权限。面板是临时窗口：它不替换系统 Dock，也不接管原生 Command-Tab。

本次未跑、仍需在真实会话里确认的边界：对第三方窗口实际执行折叠 / 展开 / 置顶 / 关闭的端到端流程，锁屏与唤醒，运行中撤销权限，多 Space 与 Mission Control，全屏应用，VoiceOver 朗读顺序，无响应应用，长列表滚动的内存峰值，以及 Dock 自动隐藏或放大等组合。

## English

### Hover a Dock icon, see every window

- Hovering an app icon in the Dock opens a panel of that app's real windows; moving away closes it.
- Two layouts: thumbnail cards, or compact rows with a larger preview of the selection on the right. The segmented control switches at any time, and the search field matches app names and window titles.
- **Choose window…** in the menu, or your own hot key, opens the same panel in keyboard mode with the search field focused.
- Each card carries explicit actions: open / unfold, fold, pin preview, close, minimize — shown according to what that window actually supports.
- The Dock entry is off by default. Enable it in **Settings → Window browser**, where you can also record a hot key, exclude apps, and check permission state.

### Identity and safety

- Every action is bound to the full identity of the window you selected (application instance, original window ID, session generation) and re-validated before it runs. When the target cannot be confirmed, the action is refused rather than guessed from a title, a list position, or the current focus.
- Folding and unfolding reuse the existing fold transaction, restore verification, and recovery journal. No second off-screen hiding path was added, and the recovery records are untouched.
- Every async result checks the request generation and owner: switching A → B → A, a snapshot arriving after the panel closed, an old panel releasing the new mirror, a failed restore verification, or a stream starting after close are all discarded.

### Thumbnails and live preview

- Titles and cached images render first; images fill in on demand. Capture is single-window only, and a failure falls back to the app icon plus a note instead of cropping a full-screen shot.
- Live preview for ordinary windows is off by default. When enabled, a stream starts only after the selection rests for 0.4 s, at most one new stream per temporary panel, and a window that already has a pinned preview reuses its mirror.

### Interface fixes in this release

- The search field was overlapped by the window list.
- The 列表 segmented control highlighted, but the content stayed a thumbnail grid.

### Install and known limits

Download **WindowShade-v1.0.12.zip** below, unzip it, and move the app to Applications. Requires **macOS 14+ and Apple Silicon**; the zip is arm64 only and ships with a SHA-256 checksum.

The app keeps its existing **Apple Development** signing identity and bundle identifier; it is **not notarized**. If macOS blocks the first launch, use its Privacy & Security “Open Anyway” flow.

Window browsing needs **Accessibility**; thumbnails and live preview also need **Screen Recording**. The panel is temporary: it does not replace the system Dock or take over the native Command-Tab.

Not yet verified in a real session: end-to-end fold / unfold / pin / close against third-party windows, lock and wake, revoking permissions while running, multiple Spaces and Mission Control, full-screen apps, VoiceOver reading order, unresponsive apps, memory peaks while scrolling long lists, and Dock auto-hide or magnification combinations.
