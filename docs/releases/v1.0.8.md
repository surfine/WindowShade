# WindowShade v1.0.8

## 中文

### 这次更新

整体提速与稳定性加固。

- 折叠和标题栏双击更快
- 置顶预览更省资源并按需降频
- 修复折叠截图缓存竞态
- 像素分析、窗口救援和状态校正移到后台
- 日志自动轮转

## English

### Highlights

Speed and stability improvements.

- Faster folding and title-bar double-click
- Lower resource use for pinned previews with adaptive frame rate
- Fixed a fold-capture cache race
- Moved pixel analysis, rescue, and reconciliation off the main thread
- Added log rotation
