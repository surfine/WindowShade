# WindowShade 1.0.17 · 更稳，也终于通过了 Apple 公证

> 草稿（2026-10-17），发布日前由 Aaron 定稿。「已发布」一句、下载大小与 SHA-256 等发布日才有的数字写在文末 TODO。

## 中文

### 一句话摘要（appcast 用）

这一版换了签名证书并通过 Apple 公证，从 1.0.16 升级要手动下载一次、重新打开两项授权；另外让收起更稳，设置里多了导出诊断信息、导出／导入设置，也多了 7 个捷径动作。需要 macOS 15 或更新版本。

### 从 1.0.16 升级，请先看这里

- **这一版要手动下载一次。** 签名证书换了，菜单里的“检查更新”会弹出提示并带你去下载页。装好之后，更新又回到菜单里点一下。
- **装好后重新打开两项授权。** 系统把新签名当作新的 App，请在“系统设置 → 隐私与安全性”里重新打开辅助功能和屏幕录制。
- **安装包已通过 Apple 公证。** 第一次打开不用再手动放行。
- **需要 macOS 15 或更新版本**（Apple Silicon）。还在 macOS 14 的人继续用 1.0.16。

### 新增

- **设置 → 高级 → 关于。** 导出诊断信息（只存在你的电脑上，不会上传）、导出设置、导入设置、报告问题。导入前会先留一份备份。
- **7 个捷径动作。** 在“快捷指令”、聚焦搜索和 Siri 里就能用。
- **音量和亮度可以“改回用系统的提示”。** 打开后，WindowShade 只旁听、不拦按键，系统的提示照常出现，刘海里也跟着显示。
- **快捷键没反应时会告诉你原因。** 开着“安全输入”的时候，或别的窗口管理工具占用了同一个组合，刘海里会说一句。
- **辅助功能中途被关掉，会提醒你。**
- **关于里能看到第三方许可。**

### 改进与修复

- **关掉卷帘条更合理。** 计算器、App Store 这类只有一扇窗的工具，关掉卷帘条就退出；微信、QQ 等聊天类不会退出；其余只关窗口。
- **不能收起的窗口会直接说“这个窗口不能收起”**，不再先动一下再弹回来。
- **窗口在别处被关掉后，对应的卷帘条会自己消失。**
- **窗口浏览里，App 自己关掉的窗口不再留在面板里。**
- **启动台里文件夹开着时打字，第一个字不再被吞。**
- **睡醒或辅助功能晚一步授权后，快捷键、滚动和中键会自己恢复。** 事件通道静默停掉时，每 5 秒体检一次并重开。
- **“锁定程序坞到某块屏”按显示器本身认屏**，换接口、重新插拔后不再认错。
- **更省电。** 电量相关的两项后台刷新交给系统调度；两个轮询计时器放宽了一点点；镜像圆角只处理需要处理的几行。
- **清理更干净。** 改过的系统设置能还原，两处越积越多的残留不再增长。
- **没下好的文件不再被当成“下好了”。**
- **macOS 27 起，设置里按系统的新名字称呼“隐私”那一栏。**
- **刘海关着时，启动台快捷键没反应**（1.0.16 就有），现在照常打开。
- **Dock 菜单关掉后，回到同一个图标看不到窗口预览**，现在会重新出现。
- **台前调度开着时，同一个 App 的第二扇窗口收不起**，现在能收。已知局限：展开其中一扇，同 App 的另一扇会一起回到台前。

## English

### One-line summary (for the appcast)

This release switches to a new signing certificate and is notarized by Apple, so updating from 1.0.16 means one manual download and turning the two permissions back on. It also makes rolling up steadier and adds diagnostics export, settings export and import, and 7 Shortcuts actions. Requires macOS 15 or later.

### Updating from 1.0.16 — read this first

- **Download this one by hand.** The signing certificate changed, so Check for Updates shows a notice and takes you to the download page. After that, updates are one click in the menu again.
- **Turn the two permissions back on.** macOS treats the new signature as a new app. In System Settings → Privacy & Security, reopen Accessibility and Screen Recording.
- **Notarized by Apple.** The first launch needs no override.
- **Requires macOS 15 or later** (Apple Silicon). If you’re still on macOS 14, stay on 1.0.16.

### New

- **Settings → Advanced → About.** Export diagnostics (kept on your Mac, never uploaded), export settings, import settings, and report a problem. Import makes a backup first.
- **7 Shortcuts actions**, available in Shortcuts, Spotlight and Siri.
- **“Use the system’s volume and brightness display”** option. When it’s on, WindowShade only listens: the keys go through, the system shows its own display, and the notch follows along.
- **A note when a shortcut does nothing.** With Secure Input on, or when another window manager holds the same combination, the notch says so.
- **A warning if Accessibility is turned off while the app is running.**
- **Third-party licenses are visible in About.**

### Improved and fixed

- **Closing a roll-up bar makes more sense.** Single-window tools such as Calculator and the App Store quit; chat apps like WeChat and QQ never quit; everything else just closes the window.
- **Windows that can’t be rolled up say so right away**, instead of moving and snapping back.
- **A roll-up bar disappears on its own** when its window is closed somewhere else.
- **Window Browser no longer lists windows an app closed itself.**
- **Launchpad no longer swallows the first letter** you type while a folder is open.
- **Shortcuts, scrolling and middle-click recover on their own** after wake or when Accessibility is granted late. If the event channel stops silently, it’s checked every 5 seconds and reopened.
- **“Lock the Dock to a display” now recognizes the display itself**, so replugging cables no longer picks the wrong one.
- **Lighter on battery.** Two battery refreshes run on the system’s background scheduler, two polling timers have a little slack, and mirror rounding touches only the rows that need it.
- **Cleaner cleanup.** Changed system settings can be restored, and two leftovers that kept piling up no longer do.
- **Unfinished downloads aren’t counted as finished.**
- **On macOS 27, Settings uses the system’s new name** for the Privacy section.
- **Launchpad didn’t open when the notch is off** (since 1.0.16); it now opens as usual.
- **Dock window preview didn’t reappear** when you came back to the same icon after a Dock menu closed; it does now.
- **A second window of the same app couldn’t be rolled up with Stage Manager on**; it can now. Known limitation: unrolling one brings its sibling back to the stage.
