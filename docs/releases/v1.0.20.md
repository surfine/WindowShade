# WindowShade 1.0.20 · 功能边界与窗口修复

[产品官网](https://windowshade.aaronlau.me/) · [English website](https://windowshade.aaronlau.me/en/)

已发布（2026-11-02）。本包于 2026-11-03 重发（build 20），下载包包含功能开关关闭后的收尾修复；已经装了首次 1.0.20 的人不会收到自动更新。

## 中文

### 一句话摘要（appcast 用）

设置里新增「功能」页：核心的卷帘、看一眼、带到每张桌面始终开启，刘海、窗口浏览、启动台、画中画等 8 个功能可以整块开关，关掉后菜单、快捷键和后台工作一起停；新装只默认打开常用的几项，升级用户保持原样。另修好 macOS 26 双击缩放、收起后闪一下桌面、窗口退最小化带 Dock 动画等问题。需要 macOS 15 或更新版本。

### 升级前请看这里

- **从 1.0.19 升级照旧**：菜单里「检查更新」一键安装，授权不用重开。
- **你的功能不会变。** 第一次打开这一版时，8 个功能的总闸按你现在的使用情况迁移；之前关着的仍然关着，开着的仍然开着。
- **新装只默认打开常用的几项。** 其余在 设置 → 功能 里打开，随时能改。
- **需要 macOS 15 或更新版本**（Apple Silicon）。

### 新增

- **设置 → 功能。** 8 个功能各一行开关：刘海、窗口浏览、启动台、画中画、手势与输入、认你与锁屏、遥控与指挥、画面效果。关掉一个，它的菜单项、快捷键、监听、计时器和后台读取一起停；打开就恢复。
- **新装引导结束后打开功能页。** 第一次装的人看完引导会直接看到这些开关，挑这次要用的；之后不再自动弹。
- **按住卷帘条切桌面，窗口跟过去。** 原窗口跟着到新桌面；系统内部符号不可用时静默回退，窗口留在原桌面。

### 改进与修复

- **刘海按这台 Mac 的真实尺寸。** 紧凑两耳的高度跟真实开孔一致；外接屏上的隐形刘海也沿用内建屏的宽高，不再用估算值。
- **macOS 26 双击标题栏不再先放大。** 第二次按下和松开一起拦；窗口不会在卷帘条出现前被系统缩放。
- **藏好后卷帘条直接出现。** 不再从全透明淡入 0.34 秒，不会先露出桌面。
- **窗口藏不起来时先停到屏幕角落。** 只留 1 像素，不再一退最小化就播 Dock 缩进动画；可见判定要求至少露出 8×8 点。
- **收起途中被最小化不再让卷帘条消失。** 过期的收起回调会作废，不会把系统的最小化当成用户唤回。
- **删掉设置里选不到的两种收起方式。** 旧偏好值自动回落到「跟原来一样」。
- **崩溃恢复认得角落停车。** 强退后原窗口仍能回到原处。
- **功能开关关闭后的收尾。** 关画面效果不再把设置窗口一起关掉，收起动画也真的停；关手势与输入后遥控和手柄不再残留；关认你与锁屏不再改写刷脸开关、也不再枚举摄像头；关刘海时面板真的拆掉，并停掉教学相关的只读钩子；CarPlay 和刷脸也看模块总闸。
- **设置页和欢迎窗口恢复正常。** 画面效果关着时，设置里的手势、刘海等页不再空白，欢迎窗口也能重新打开。
- **悬停恢复展开。** 指针停在刘海上，里面有窗口或实时活动时重新展开那一排。
- **全屏时仍认得真刘海。** 全屏菜单栏收起、顶部安全区变成 0 时，不再把内建屏当成无刘海屏去画一颗圆形灵动岛。
- **欢迎窗口双击标题栏不再闪退。** 辅助功能在非主线程做命中测试时会读到 `isFlipped`；相关实现改成 nonisolated，不再触发主线隔离断言。

## English

### Summary (for appcast)

Settings gains a Features page: the core fold, glance and carry-to-every-desktop stay on, while eight features — notch, window browsing, Launchpad, Picture in Picture, gestures and input, recognition and lock, remote and conductor, visual effects — can be switched off as a block, taking their menus, shortcuts and background work with them. Existing installs keep their current setup; fresh installs start with the common ones on. Also fixes macOS 26 double-click zoom, a desktop flash after folding, and the Dock minimize animation. Requires macOS 15 or later.

### Before you upgrade

- Upgrading from 1.0.19 is the usual one-click update; permissions stay granted.
- Your features do not change: the eight switches are seeded from what you already use.
- Fresh installs start with the common features on; the rest are one switch away in Settings → Features.
- Requires macOS 15 or later on Apple Silicon.

### New

- **Settings → Features.** Eight switches. Turning one off stops its menu items, shortcuts, monitors, timers and background reads; turning it on brings them back.
- **Fresh installs open the Features page after onboarding**, once.
- **Hold the strip, switch desktops, and the window follows.** Falls back silently if the system symbol is unavailable.

### Fixes

- The compact ears now match the Mac's real notch height, and the virtual notch on external displays reuses the built-in screen's width and height.
- macOS 26 no longer zooms the window before the strip appears; both the second press and its release are intercepted.
- The strip appears immediately after the window is verified hidden, with no fade that reveals the desktop.
- Windows that cannot be moved off-screen park in a screen corner with one pixel visible instead of minimizing and playing the Dock animation; visibility requires at least 8×8 points.
- A minimize during folding no longer discards the strip; expired callbacks are dropped.
- Two unreachable collapse styles were removed; old preference values fall back to the default.
- Crash recovery now recognizes corner-parked windows.
- **Teardown behind the switches.** Turning off Visual effects no longer closes Settings and stops the fold animation; turning off Gestures & input stops the remote and gamepad; turning off Recognition & lock no longer rewrites the face-unlock switch or enumerates cameras; turning off the notch removes its panels and teaching hooks; CarPlay and face unlock also respect the module switch.
- **Settings and the welcome window work again** when Visual effects is off.
- **Hover to expand is back:** resting the pointer on the notch opens the row when it holds windows or live activities.
- **The real notch is still detected in full screen**, so the built-in display no longer falls back to a round Dynamic Island when the menu bar is hidden.
- **Double-clicking the welcome window's title bar no longer crashes.** Accessibility hit testing can call `isFlipped` off the main thread; those overrides are now nonisolated.
