认你、指挥页与露出

接《刘海里的编程会话》的另外三件：锁屏上认你的那颗刘海、走进会话以后的指挥页、以及这些表面怎么从预览旗标走到设置里的正常开关。动效令牌都在上一张稿的 §4.6.1 表里，这里不再新增弹簧。

①

锁屏上的「认你」

对上《从锁屏到窗口》第 2–4 步。系统锁屏是主角：时钟、头像、密码框一个都不遮。刘海只在两耳和一道矮下巴里说话。

规则

  • 长在刘海里，不另开窗。今天的工程样式是一块 320×60 的独立浮窗（FaceScanStatusController，.floating），违反 face-unlock 硬要求第 1 条。换成刘海宿主里的一个活动。
  • 左耳一圈在转，右耳两枚点：脸、手机。点从空心变实心，哪一样还差一眼就看得出；差的那一样用虚线琥珀圈，不只靠颜色。
  • 只用耳朵和一道下巴。需要一句话时（没认出、口罩、3 次），刘海往下长 26 pt 写一行，停在时钟上方，不碰头像和密码框。
  • 结果不由动画决定。对勾只在真的认出之后出现；脸和手机或手表都对，才在系统密码框里代填（D11 已解冻，Aaron 10-29）。分数在门槛附近时念一句随机短语补一道（声纹，只加不减）。系统没确认解锁，桌面不展开。
  • 一天几十次，不加戏。耳朵用 calm 长出、settle 收回，不回弹；对勾是淡入，不用 pop。
  • 补光圈和刘海共存。补光贴屏幕四边亮一圈，顶边那一段在菜单栏位置变弱，刘海保持纯黑。亮起用淡入，不用弹簧（亮度没有动量）。
  • 减少动态效果：转圈改为慢速，两枚点直接换状态，下巴原处淡入。
②

指挥页

走进那一排里的一个会话就是指挥模式。画进 10-19 定案：语音在这台 Mac 上识别、Claude 先只读、遥控器的播放键和返回键落到这一页。指挥页是刘海展开的一页，不是新窗口。

一页四块，从上到下

  • 头：返回那一排的箭头、项目 · 助手、右边 Codex / Claude（只读） 切换。Claude 在回答时切换变灰，写「这一轮结束后再切换」。
  • 下一轮：模型和程度两组。正在跑的那一档实心，下一轮要用的那一档描边，一眼分清「这一轮」和「下一轮」。
  • 转写：最近几行。Claude 只读时，被拒的工具用琥珀色单列一行，不藏。
  • 草稿：按住说话 → 松手出草稿 → 采用草稿 → 发送。在跑时发送键叫 补进本轮。不自动发送。
  • 遥控提示只在 iPhone 连着时出现，一行：播放键 = 发送，返回 = 收起。
  • 落档：手机上画的声调先在右耳亮一下（「三声 · high」），再落到「程度」那一格的描边上。来源只说一次，不在页面里重复。
  • 动效：走进会话用 expand，返回那一排用 calm 缩回那一格（从哪来回哪去）；档位描边换格用 calm，速度连续。
③

露出：预览旗标 → 默认关的开关

今天全部 WS2 表面都藏在 WindowShade.Preview.WS2 后面，要用 defaults write 打开。分两段走：先把验过的表面挪进设置，做成默认关的开关；旗标只留给没验过的。

第一段 · 现在

预览旗标

一个总旗标，开了以后所有 WS2 表面都出现。适合 Aaron 自测，不适合给别人。

defaults write com.windowshade.prototype WindowShade.Preview.WS2 -bool YES

第二段 · 每个表面验过一个

设置里的开关，默认关

表面过了下表的门槛，就从旗标里搬出来，变成设置里一行默认关的开关；旗标后面只剩还没过的。没有「一次全放开」。

放在哪

  • 设置 → 指挥模式（这一页今天已经在旗标后面存在）：三行。编程会话（在刘海里看 Claude Code 和 Codex，带 连接 按钮）、指挥模式（要先在遥控模式里打开）、提示音。
  • 设置 → 隐私：刷脸解锁（实验），带「实验」标签；打开前先走录脸。
  • 设置 → 高级 → 实验 · 离开就锁：1.0.17 起就在这里（Aaron 10-17 拍板），不动。
  • 还在旗标后面的表面，设置里不出现，不放灰掉的占位行。

代填密码与声纹辅助（D11）没有（10-29 解冻）攻击矩阵五种都有实测；帧率与耗电不比 1.0.15 差；Touch ID 保护的密码会话真机走通全部跟刷脸解锁（实验）同一个开关，默认关

每个门槛都要有证据：build.sh --check 退出 0、对应探针、文案过 copy-guide、新读取点登记进隐私页、减少动态效果有替代姿态。缺一项就留在旗标后面。
