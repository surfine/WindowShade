刘海里的编程会话

Claude Code 和 Codex 的会话在刘海里只有三种样子：在跑、等你、完成。等你的那一个会从右耳的琥珀点长成审批卡；放行或超时，它沿原路缩回那个点。下面这颗刘海用的是真弹簧，可以随时点别的状态把它中途改道。

紧凑四态

编程会话是实时活动的一种，和正在播放、番茄钟并排，按《实时活动晋级》的权重 95 排。左耳是会话符号（完成提醒时换成对勾），状态只换右耳。符号加不超过 8 个字。

状态左耳右耳（够宽）右耳（菜单栏挤，< 54 pt）会不会自己展开
在跑终端或 App 的图标转圈 + 项目名，最长 64 pt 截断只留转圈不会；有别的活动时只是三个之一
等你同上琥珀点 + 等你只留琥珀点唯一会主动展开的：先在右耳亮 0.6 s，再长成审批卡；带提示音（全 App 一个「提示音」开关）

③

审批卡

换掉今天 380×105 的工程卡。和 WS2CommandReviewView 同构：同一份请求、同一个一次性绑定、同一个 2 分钟期限，只换皮。卡上只写四件事：哪个助手、哪个项目、要做什么、风险。

规则

  • 从右耳的琥珀点长出来。卡的内容以那个点为原点放大；收回时缩回同一个点。放行之后琥珀点换成转圈，原地继续。
  • 普通（读文件、跑测试、改项目里的文件）：允许一次 是主按钮，旁边 去看看 跳到那扇终端。
  • 高风险（推送、删除、联网、改项目外的文件、关安全设置）：主按钮换成 用 Touch ID 允许，带 touchid 符号；风险一行用 exclamationmark.triangle 加一句原因，不只靠颜色。
  • 没有「总是允许」。键盘快捷键不能放行；卡出现后 0.5 s 内的点按不算（防正在点别处的手）。
  • 右上角是剩余时间 1:52，等宽数字，不画进度环（不制造催促感）。
  • 2 分钟没人管：卡缩回右耳，只留琥珀点，问题交回终端原来的提示；这不是拒绝。
  • 被挂起（锁屏上认你、CarPlay 全屏这类更高层的租约；音量键不挂起审批卡）：卡让位，回来时直接淡回原样，不重播长出来的动画。挂起不是取消，期限照走。
④

中途改道：位置和速度都连续

每个新动效都过这一关：动画走到 40% 时换目标。下图是模拟器里刘海宽度的真实记录（你点「40% 时改道」或任何中途换状态，这里就更新）。对照线是时长动画在同一时刻重新开始的样子：速度当场归零，曲线上有个折角。

弹簧改道（刘海宽度） 弹簧速度 对照：时长动画重来（不用） 竖虚线 = 改道的那一刻

刘海外框本来就是真弹簧：NotchCanvasView.Spring 按 Motion.notchSpring(for:)（App/Motion.swift:112）把形状映到令牌，换目标时接着当前位置和速度走。新表面接这一条，不用 NSAnimationContext 的时长动画。要补的两处：Notch.swift:6037 的格子位移现在是「calm 的 response 当时长 + ease-out」，改成真弹簧；审批卡内容层的缩放原点（琥珀点）作为参数传进来。FoldSpring（Effects/FoldDriver.swift:39，只有临界阻尼）只给合盖与锁屏覆盖，刘海不用它。
