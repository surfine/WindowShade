1.0.18 新表面

五样东西，都是别家已经有、我们缺的“公认范畴”。Dock 预览卡上指过去就有红黄绿，和窗口自己的标题栏一样；设置左上角能搜，打“隐藏”也找得到“收起”；正在播放卡拖完进度不再弹回去；下载回来的 DMG 有一扇排好的窗口，拖一下就装好；两项权限在首次打开、官网和 README 里说同一句话。

画板按 pt 原尺寸画，窄屏等比缩小。顶上能切画板里的语言、浅深色和减少动态效果。会动的画板用同一套逐帧数据（每帧写弹簧令牌名，时间由弹簧现算），点帧名能停在那一帧。起点：prototype/WindowBrowser/WindowBrowserCardView.swift、Effects/DuoSettingsWindow.swift、Core/NowPlayingCardLogic.swift、docs/competitive-packaging.md、site/scripts/content.mjs、三份 README。

一句话结论

  • 1红黄绿只是给已有的三个动作换个位置。关闭、最小化、进入全屏早就在“更多”里，能力判断也只在 WindowBrowserActionPolicy.preflight 一处。这次只加一组按钮，读同一份 WindowBrowserActionItem，不新增动作，也不新增确认框。
  • 2设置搜索不另建一份目录。所有页在打开设置时已经建好（rebuildAllPages），挂了讲解牌的行就是索引。同义词表从 copy-guide 的“不要用”那一列来，一份词表两处用。
  • 3正在播放：跳完之后 1.5 秒内信自己。松手那一刻起在本地按 1 倍速往前走；播放器报的旧位置不理，报对了就交还。1.5 秒后还对不上，按 calm 滑回播放器报的位置，不弹字。
  • 4DMG 只给官网下载，Sparkle 照旧用 ZIP。一张背景两种外观通用：图标那一带用中灰，黑字白字对比都在 4.5 以上；背景里不写字，三种语言都不用另做。
  • 5权限一句话：辅助功能（必需）找到、移动和收起窗口；屏幕录制（可选）给看一眼和窗口浏览实时画面，不开也能用。九个地方照第 5 节的表换。

要 Aaron 定的五件事

“选择窗口…”面板里，⌘W 改成关掉选中的那扇？

现在 ⌘W 关的是面板本身（WindowBrowserPanel.performClose）。按窗口切换里 ⌘W 已经是“关掉选中的那扇”（WindowSwitcher.swift:295）。

推荐：改。⌘W 关选中的窗口，⌘M 最小化，⌃⌘F 进入全屏，Esc 关面板。同一个键在两个面板里做同一件事。

绿灯只做“进入全屏”，不做系统那种停一下弹出的排布菜单？

系统标题栏的绿灯停一下会弹出“左半屏 / 右半屏 / 铺满”。我们的卡片很小，弹菜单会盖住旁边的卡片。

推荐：只进入全屏。排布已经有落点小岛、右键菜单和“排布与撤销”。

设置搜索也认英文名？

中文界面里打 “notch”“glance” 也能找到刘海、看一眼。从别的工具搬来的人常记英文名。

推荐：认。索引 = 当前语言 + 英文 + 同义词（三种语言都认），结果用当前语言显示。

1.5 秒后播放器还对不上，就滑回它报的位置？

多半是播放器拒绝了跳转（直播流、广告、某些网页播放器）。另一种做法是一直信自己直到换歌，代价是条和真实声音对不上。

推荐：滑回，用 calm，不弹字。读屏念一次新的“已播 / 剩余”。

DMG 背景：一张图两种外观通用，图标那一带用中灰 #6C7686，图里不写字？

Finder 的图标名字浅色外观是黑字、深色外观是白字，背景图本身不跟着换。

推荐：这样做，图里只画卷帘和箭头。发版前在这台 Mac 上浅深两种外观各开一次 DMG 截图验收。

  2. 2尺寸照 macOS：直径 14 pt，间距 6 pt，三颗一组 54 pt。实现时用 NSWindow.standardWindowButton(_:for:) 拿系统自己的按钮，尺寸、深浅色、增强对比度都随系统；数字以本机实测为准，不写死。命中区每颗 20 × 20，连成一条，不留缝。
  3. 3什么时候出现：和操作条同时。指针进卡片或键盘选中时出现（actionBarShouldShow），淡入 0.18 s、淡出 0.10 s（fade），不缩放、不回弹：一天看几十上百次。指针进到三颗任意一颗上，三颗一起露出 ×、−、全屏符号，和系统标题栏一样。
  4. 4防误点：出现满 0.18 s 才接受点按。面板是指针从 Dock 往上走时弹出来的，按钮离进入路径最远（左上），再加这一道，指针扫过时不会点到关闭。
  5. 5和操作条共处：左边是窗口本身的事，右边是 WindowShade 的事。右上角那条照旧（收起或展开、置顶预览、新建窗口、更多），“更多”菜单里仍然有关闭、最小化、进入全屏，同一份 items。卡片窄到放不下两组时，操作条先从尾巴上收，最后只剩“更多”（现有 fitActions）；红黄绿不收。
  6. 6点了之后：关闭成功，这张卡淡出（0.10 s），后面的卡用 settle 挪过来，面板宽度同一根弹簧变窄，面板始终对着 Dock 图标居中。最小化：卡片留着，下面出现“已最小化”。进入全屏：窗口去了新的桌面，面板收起。

状态（放大 2 倍）

键盘和读屏

Dock 面板从来不是 key window（WindowBrowserActionButton 的注释写着），键盘到不了那里。键盘的路是菜单里的“选择窗口…”：同一套卡片，方向键选中一张，选中就露出红黄绿。⌘W 关闭，⌘M 最小化，⌃⌘F 进入全屏，Esc 关面板（第 1 个问题）。悬停提示把快捷键写在名字后面，和现在“新建窗口 ⌘N”一样（macShortcut(for:)）。

VoiceOver：三颗是卡片这一组里的三个按钮，排在操作条前面，名字用现有标题“关闭窗口 / 最小化 / 进入全屏”，不能点时帮助里念原因（如“这个窗口不能全屏”）。卡片上的自定动作照旧，读屏的人不必找按钮。完成后只念一句结果（WindowBrowserAccessibilityAnnouncement），如“关闭窗口完成：季度计划.pdf”。

关闭要不要我们再问一次

不问。照现在的 preflight 和 performClose：按的是那扇窗口自己的关闭按钮，有没保存的内容 App 自己会问。我们不另加确认框，也不加撤销。

App 弹了保存确认框时，窗口还在，结果是“窗口仍在，可能有保存确认框”。这时把那扇窗口带到前面、面板收起，让人看见那个确认框，不让它躲在后面。关闭按钮用系统红，最小化黄、全屏绿，颜色之外还有 × − 符号，不只靠颜色。

不能做时（缺辅助功能、窗口不支持、正在进行别的操作）那一颗变灰、位置不空出来，悬停提示写原因。已经最小化的窗口，黄灯是灰的（现在“更多”里这一项是直接藏掉，按钮组里改为置灰，避免三颗位置跳动）。

画板里的搜索框是真的：点进去打字试试，比如“隐藏”“灵动岛”“minimize”“缝”“缩略”“taskbar”。↑↓ 选，Return 跳过去，Esc 先清空、再按离开搜索框。

  1. 1放在侧栏顶上，和系统设置同一个位置。⌘F 把焦点放进去并全选已有的字；侧栏收起时 ⌘F 先展开侧栏。占位字只写“搜索”。
  2. 2打一个字就出结果，不等。索引只有一百多行，逐字筛选。结果替换侧栏原来的页列表：第一行是行名（命中的字标出来），第二行是“页 › 匹配到的选项”，靠同义词找到的写“卷帘 · 就是你说的“隐藏””（侧栏只有 184 宽，一行放得下）。最多 30 条，按名字开头 → 名字里有 → 同义词 → 选项 → 副标题 → 页名排。
  3. 3键盘：焦点一直在搜索框里。↑↓ 在结果里走（不离开输入），Return 打开，Esc 第一次清空、第二次离开搜索框回到侧栏。和 Spotlight、窗口浏览里的搜索框一个习惯。
  4. 4选中之后四件事一起做：侧栏不变（结果还在，好接着试下一个）；右边换到那一页（页切换照旧淡入）；那一行滚到内容区上三分之一处（calm，减少动态效果时直接到）；那一行亮一下（填充强调色 18%，停 0.6 s 再 1.1 s 淡掉），讲解带像点住那一行一样演它（发 .click(row)）。命中的是分段控件里的某一段，那一段描一圈，讲解带演那一段。
  5. 5没找到：“没有找到“xyz””，下面一行“换个说法试试，比如“收起”“刘海””。不给空白，不给“0 个结果”。
  6. 6读屏：搜索框名字“搜索设置”；结果变了念“3 个结果”（只在停止打字 0.5 s 后念一次）；结果行念“收起后的样子，卷帘页”。

进索引的

  • 页名（侧栏里的那一个字或两个字）。
  • 每一行的行名、副标题（就是 SettingsText 的 shown）。
  • 分段控件、弹出菜单里的每个选项名（“缩略图”“宽”“列表”）。
  • 分组小标题（“专注与输入”这类）只用来排序，不单独出结果。
  • 同时进英文名和简体源句（第 3 个问题），中文界面打英文也找得到。
  • 拼音首字母和全拼，复用启动台的匹配（Core/LaunchpadModel.swift）：“sq”找到“收起”。

不进索引的

  • ⓘ 气泡里的长说明、讲解带的说明句：太长，搜什么都会命中，结果变得没用。
  • 预览旗标藏着的 WindowShade 2 页和行（WS2Preview.visibleSections 之外的）：搜得到却打不开更糟。已经开着而露出来的照常进。
  • 隐私页里那张“读到的”长表：它有自己的页内筛选。

同义词（从 copy-guide 的“不要用”那一列来）

左边三列是用户可能打的说法，右边是它在产品里的名字。三种语言的说法都认，结果用当前界面语言显示。copy-guide 加一行“不要用”，这里跟着多一条；不另维护。

时间线（按比例画；横轴是墙上时间，纵轴是播放位置）

  1. 1松手那一刻就开始在本地走。本地时间线 = 目标秒数、松手时刻、1 倍速（暂停时 0 倍）。条和“已播 / 剩余”都读它。
  2. 21.5 秒防抖窗口：这期间播放器报的位置，跟本地差 1 秒以上就不理（它还在报跳之前的旧位置）；差 1 秒以内算“对上了”，立刻交还播放器，窗口提前结束。每次新的松手或暂停都重新数 1.5 秒。每次松手都真的发出跳转，不合并。
  3. 31.5 秒到了还没对上：播放器多半拒绝了这次跳转。条用 calm 滑到播放器报的位置，时间字跟着换，不弹提示（第 4 个问题）。读屏念一次“已播 1 分 16 秒，剩余 3 分 4 秒”。
  4. 4暂停 / 播放同一条规矩。点下去本地立刻变 0 倍或 1 倍，封面缩到 0.9（settle），图标立刻换；播放器还报“在播”的那半秒不理。
  5. 5换掉现在的 1.0 s 保持。现在 NowPlayingScrub.holdAfterRelease 只把条钉在目标上 1 秒，期间时间字照常读播放器、条之后会跳回旧位置再跳回来（切到“现在”、选 1.3 s 或 2.4 s 能看到）。新做法把“钉住”换成“本地往前走”，时间字和条读同一条时间线。

  1. 1核心两句，到处一样：辅助功能（必需）：找到、移动和收起窗口。屏幕录制（可选）：看一眼和窗口浏览里的实时画面要用，不开也能用。

  4. 4繁体：“必要 / 選用”是 Apple 台湾的说法（不写“必需 / 可選”）；引号用「」。英文：权限名照系统设置大写（Accessibility、Screen Recording），标签 Required / Optional，正文 sentence case。
  5. 5“屏幕录制只是系统起的名字，画面不会离开这台 Mac”保留，只放在官网 FAQ 和 README 那一段，App 里不放（A2 那一页已有隐私小字）。
