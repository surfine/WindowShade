    规则

    数字取 MacBook Air 15 英寸：刘海 185 × 33.5，底角 10.71。弹簧只用已有令牌（response 秒 / 阻尼比 ζ）。

    形状：两耳，不往下鼓

    • 每只耳朵 76，总宽 185 + 2 × 76 = 337；高 = 刘海高 33.5，不往下鼓，没有额头。底角 island.hug 10.71。
    • 两耳对称，像灵动岛：右耳要放条，左耳跟着一样宽。
    • 比 34 宽，按令牌 §5.1 S3 不画肩，顶角直角；肩在长出的前 24 点里收到 0，同一根弹簧。
    • 两耳只在按键后亮 1.2 秒，点击穿透，菜单栏照常能点。
    • 长出 pop 0.30 / 0.75；收回 calm 0.34 / 1.0。

    左耳：一个会变的符号

    • 离外沿 14；喇叭身子不动，声波往右长。
    • 音量：0 → speaker.fill；≤ ⅓ → wave.1；≤ ⅔ → wave.2；以上 → wave.3；静音一律 speaker.slash.fill。
    • 输出是 AirPods / 耳机时换成 airpodspro / airpods / airpodsmax / headphones；静音仍是带斜线的喇叭（一个意思一个符号）。
    • 亮度：< 50% sun.min.fill，否则 sun.max.fill。键盘灯：0 熄灭、< 50% light.min、否则 light.max。符号名都在这台 Mac 上核对过。

    右耳：一根条，不写数

    • 条长 54、高 6，胶囊；离刘海 8，离外沿 14。轨道白 0.22（增强对比度 0.45），填充白 1.0。
    • 不写百分比：系统的提示和灵动岛都不写；细调时数字是 23.4% 这种，读起来比条难。读屏念数。
    • 条的变化用 pop，按住时一格接一格，连成一条扫动。
    • 步长照系统：一下 1/16（6.25%，条上 3.4 点）；按着 ⌥⇧ 是 1/64（0.84 点）。

    到头了再按：拉长再弹回

    • 100% 再按 +：条往外沿拉长；0% 再按 −：往刘海那侧拉长。数值不变、不再写。
    • 拉长量用橡皮筋 rubberband c = 0.55，最多 8 点；同时条变细到 5；符号顺着挪 ¼。
    • 弹回用 pop。按住时每次连发再顶一下，一直顶着，松手才弹回。
    • 减少动态效果：不拉长，条的那一头亮一下（白 0.6 → 1，0.25 秒）。

    多久出、多久收

    • 按下就出，不等数值回来（到头了数值不会变）。
    • 按住：系统“按键重复”连发（默认先等约 0.38 秒，之后约每 0.09 秒一下），每一下都把收回时间往后推。
    • 最后一下之后 1.2 秒收（Motion.Hold.level，现值 Notch.swift:2611）：内容先淡出 0.10，停 0.04，再沿 calm 收形状。
    • 内容在形状走到四成后淡入 0.18（C01）。减少动态效果：形状直接到位，内容交叉淡化 0.25。

    和别的住户谁让谁

    • 音量亮度是你手上正在按的，记在交互层：放行 > 交互 > 你打开的 > 短暂提醒 > 持续活动 > 什么都没有。
    • 放行（刷脸解锁、等你批准）在上：不拦键，系统的提示出来。
    • 你打开的不被换页：正在播放大卡里，控制那一排换成滑条；那一排展开时，上沿两耳换成符号和条，形状不动。1.2 秒后换回，不重播进场。
    • 短暂提醒正在说：变成一个点并消耗掉，不回来补说。
    • 持续活动（正在播放、番茄钟的紧凑两耳）：耳朵从 34 长到 76、换内容，收回后原样回来。

    只认按键，不认数值

    真的按了音量、静音、亮度、键盘灯键才出。AirPods 个性化音量、自适应音量、别的 App 或控制中心改了音量、自动亮度和原彩都不出（沿用 Core/NotchLevelGate.swift 的 0.6 秒窗口）。舞台下“没按键”那一行三个按钮可以试：数值变了，刘海不动。

    藏起系统的提示：什么时候拦键

    一句话：拦键 = 能写 且 看得见 且 没有别的主人。拦下来的键由我们照系统的步长写回，再画两耳；三者缺一，就不拦，按键原样交给系统。监听只订阅系统按键这一类事件（CGEvent.tapCreate，掩码只有 NX_SYSDEFINED，子类型 8），打字的键收不到。

    情况拦不拦谁写看得见为什么
    已允许、版本核对过、扬声器或耳机能调拦我们只有刘海能写、看得见。
    原生全屏（看片最常见的那一下）拦我们只有刘海顶上本来是黑边，两耳融进去。前提：面板此刻在这张全屏桌面上真的可见（isOnActiveSpace 且未被遮挡）；查不到就按下一行处理。现状是全屏里不出，改成出。
    调度中心不拦系统只有系统它盖在所有窗口上，我们不能保证画在它上面。看不见就不拦，免得按了没反应。
    锁屏、登录窗口、屏保不拦系统只有系统锁屏归系统。解锁后下一下按键再接管。
    刷脸解锁中、等你批准不拦系统只有系统放行在交互之上，不分它的刘海。
    输出不能调音量：HDMI / DP 显示器、部分 USB 声卡、多输出设备不拦系统只有系统拦了键就失灵（Atoll 的坑：键被吞、写不进、没有任何反馈）。系统会画它自己的“不能调”。
    亮度要调的是外接屏（⌃ + 亮度键、合盖只用外接屏）不拦系统只有系统我们只写内建屏。不做 DDC。
    读不到键盘灯（没有背光、接口不在）不拦系统只有系统能写才拦。
    按着 ⌥、⇧ 或 ⌃（不是 ⌥⇧）不拦系统只有系统系统给这些组合另有用处，比如 ⌥ + 音量键打开声音设置。只有 ⌥⇧ 细调由我们接。
    Alcove、MediaMate 在运行不拦对方对方的让位（现状 foreignHUDIsRunning）。
    没允许辅助功能不拦（只旁听）系统两个都在拦不了。设置那一行写“系统的提示也会出现”，不弹窗。
    这个 macOS 版本没核对过不拦（只旁听）系统两个都在不说话、不弹窗；ⓘ 里写一句。核对过的版本列在代码里，真机按 20 次、系统提示 0 次出现才加进去。
    写进去读回来不对这一下已拦 → 原样补发系统两个都在把这一下标上记号补发给系统，监听认出记号放行；这一类键本次开机不再拦。
    监听被系统暂停（回调超时、用户输入）暂停期间不拦系统两个都在收到 tapDisabledBy… 立刻重新打开。回调里只分类和查缓存，写入放到后面的队列。
    WindowShade 崩溃或被强制退出不拦系统只有系统监听跟着进程一起没了，下一下就是系统的提示。我们没动过任何系统进程。

    不冻结 OSDUIHelper

    Atoll 除了拦键，还对系统画提示的进程 OSDUIHelper 发 SIGSTOP。我们不这样做，两个理由：

    一、macOS 26 起音量提示改由控制中心画，冻 OSDUIHelper 已经挡不住（Atoll 自己的更新记录在 26.6 上实测）。二、只要 App 在冻住期间崩溃或被强制退出，OSDUIHelper 就一直冻着，系统所有的音量、亮度、键盘灯提示（包括外接屏那些我们根本没接的）都消失，直到重启或手动解冻。

    所以只拦键，不向任何系统进程发信号，不 killall，不 launchctl kickstart。

    不取的，和为什么

    • 冻结 OSDUIHelper：26 上挡不住，崩溃后永久冻住，见上。
    • 按电平变色、发光、分贝样式：系统提示和灵动岛都是黑底白条；颜色留给活动的语气点。
    • 中央方块、竖条、圆环三种替代样式、速度三档：一个东西一种样子，不加设置。
    • 百分比：见右耳那一节。
    • DDC 外接屏亮度：要另一条硬件通道，写坏了屏幕设置收不回来；交给系统和专门的 App。
    • 自带提示音、3D AirPods 动画：版权资源，也不像系统。
    • ⌘ + 亮度键改成键盘灯：抢了用户可能已经在用的组合；不为一件小事造新键。

    允许的那一路

    1. 没允许时只在设置这一行说，不弹窗，不在刘海里提。
    2. 点“允许…”：调系统的辅助功能询问，并打开“隐私与安全性 › 辅助功能”。
    3. 设置窗口在前台时每 1 秒查一次是否已允许，最多 2 分钟；App 回到前台再查一次。不在后台轮询。
    4. 允许了就马上装监听，不用重开，副标题换回“按音量、亮度键时显示”。装不上才写“重新打开后生效”。
    5. 之后被撤销：监听失效，立刻退回只旁听、两个都在，副标题回到“系统的提示也会出现”。

    权限与隐私

    读什么、写什么、什么时候

    • 按键：音量 +/−、静音、亮度 +/−、键盘灯 +/− 的按下和松开（键码 0、1、7、2、3、21、22）；别的系统按键原样放行，不记。

    • 只在内存里，不发送，不写运行记录。
