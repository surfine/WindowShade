# O／A 系列准入清單

依據：[重塑執行規格](product-reshape-spec.md) §2 的 O 系列（對手對標，點名 Thaw、LaunchNext、DockDoor、tendedero 等，規格明寫「全部待准入」）與 §1.7 末的 A 系列（AI Agent／vibe coding，「全部待准入」）。每一條都要 Aaron 給一個結論：**收**、**不收**或**以後再說**。建議欄只依規格原文：§0.1 的四條已定案（扩展面只做最小切口、錄屏是增強、診斷純本地、發布由 Aaron 點頭）、§0.3 的「隊列只置換、不增長」與冻结区、以及規格自己寫明的風險與依賴。規格只明寫「建議排進下一批」的才標**收**；沒有這樣寫的，依 §0.3 預設為**以後再說**。代價欄的 S／M／L 取自規格原文，規格沒量的一律標 `?`。
