# 竞品调研：DockDoor / DockMate / Swish / WindowMizer / Alcove

更新于 2026-10-05。Wins 单独写在 [竞品调研：Wins](competitive-analysis.md)，各家分数与依据在
[每个领域的分数](scorecard.md)。这一份补上 Aaron 9/27 深夜点名的另外四家，以及 10 月 5 日纳入追赶的 Alcove。

功能清单只取各家自己的页面、仓库和商店页，没有下载试用；取不到一手来源的照写"取不到"，不靠二手描述补。

## 结论

- **DockDoor**：免费开源，Dock 悬停预览 + 完整的按窗口切换（Alt-Tab 替代）+ 调度中心增强 + Dock 锁定。
  它的长处是"预览里的动作足够多"和"预览、切换面板的样子可选"。我们补上它有的三个窗口动作
  （进入全屏 / 让开这个 App / 退出 App），不跟"整个替换 Dock"（那是它另卖的 Pro）和预览里嵌日历。
- **Swish**：$16 买断，30 个手势，在标题栏上双指滑就能吸附。它比我们先做成一件事：**拖分屏那条缝，两边一起变**
  ——我们的分屏把手（Split View）9/28 才做完，功能对上了，但要承认它先有。它的 WASD / IJKL / Dvorak 键位
  9/29 补上了，Dock 图标上的滑动也有了（默认关）；它在 Magic Mouse 上也能滑，我们还没在 Magic Mouse 上验证过。
  冲突是真实的：标题栏上的双指滑两边都想要。
- **WindowMizer 6**：$15–25，只支持 Apple 芯片、macOS 15.3 以上。它**不是原地收起**：双击标题栏把真窗口送进程序坞，
  原位置留一条假标题条，恢复时再送回来。我们是真的原地收起，这一格我们领先；但它有 14 天试用、4.5 星评价和稳定节奏，
  还有一样我们没有的：缩成半透明的小图。原来说这一样做不到是错的，9/28 夜里定了要做。
- **DockMate**：macEnhance 出品（做 cDock、MacForge 的那家），$14.99 起、一周试用，macOS 10.14 以上，
  最新 0.8.7 停在 2021-03-12。Dock 悬停预览、停在小图上看大图、点一下或滚一下就能聚焦 / 最小化 / 放大 / 关闭 / 开新窗口，
  另嵌日历（一键入会）和正在播放。窗口这一块我们都有且更多（“开新窗口”9/29 补上了）；它有、我们不做的是日历和音乐小组件。

## DockDoor

免费、开源（仓库 ejbills/DockDoor），官网 dockdoor.net，2026-09-28 读取。免费版明确说没有付费墙；另有一个 $20 的
DockDoor Pro，是把整个 Dock 换掉（弹簧放大、文件夹扇开、文件托盘、材质、每块屏一个 Dock），和窗口管理是两件事。

| 它有什么 | 我们对应 |
| --- | --- |
| 悬停 Dock 图标出实时预览，预览里 20+ 个动作 | 有窗口浏览；动作原本 7 个 + 排布子菜单，9/28 补到 10 个，9/29 加了新建窗口 |
| 完整的按窗口切换（Alt-Tab 替代，可换布局） | 有按窗口切换（⌥Tab / ⌘Tab 可选），收着的、最小化的窗口都在列表里 |
| 增强系统 ⌘Tab：切换面板里直接关窗、退出 App | 有（面板里 W 关、Q 退、数字跳、Esc 取消） |
| 锁定 Dock 在哪块屏 | 有（Dock 锁定） |
| 切换面板里显示日程 | 没有，也不打算做：和"让窗口让开"不是一件事 |
| 预览、切换面板多种布局可选 | 有列表和卡片两种；布局样式没有做成可选项 |
| 100% 本地、无遥测、开源 | 同样是本地、不开网络；我们的源码还没开源 |

## Swish

$16 一次性，或 Setapp 订阅，macOS 12 以上，Intel 与 Apple 芯片都支持；官网 highlyopinionated.co/swish，
2026-09-28 读取。官网自述 30 个手势，评分 4.9/5。

| 它有什么 | 我们对应 |
| --- | --- |
| 标题栏双指滑动吸附（不用拖到屏幕边） | 同一套做法：标题栏手势，左 / 右半屏、拐角、三分、网格 |
| 2×2、3×2、3×3 网格 | 有 3×2 与 3×3（含固定尺寸窗口的"做不到就说一声"） |
| 拖分屏那条缝，两边一起变 | 有分屏把手（9/28 完成，还多了甩一边进侧拉） |
| 捏合关窗、下滑最小化、张开放全屏 | 关窗 / 最小化不做手势（容易误触），全屏可由铺满屏幕代替 |
| 按屏幕的物理位置把窗口移到另一块屏 | 有 ⌃⌘N 移到另一块屏幕 / 移到上一块屏幕，上下摆的屏也对 |
| 支持 Spaces | 有：带到每张桌面、侧拉把手每张桌面都在 |
| 箭头 / WASD / IJKL / Dvorak 键位预设 | 有：更多排法里的“方向键换成字母”（WASD / IJKL / HJKL，⌃⌥ 加字母），和“用 Rectangle 的快捷键”并排；Dvorak 按键在键盘上的位置对上（,AOE 那一簇），不另设一格。Swish 的居中键（X 或 ⌫）没做 |
| Magic Mouse 上也能滑 | 没在真机上验证过 Magic Mouse |
| Dock、菜单栏上的手势 | Dock 图标上两指上下滑：有，默认关（往上是这个 App 的所有窗口，往下是让开这个 App），没在真机上走过。菜单栏手势不做：刘海上两指往上推是全部收进刘海、往下拉是拿回来，方向正好和 Swish 反着，同一条菜单栏两种意思只会记混 |
| 每个手势单独开关、带教程 | 有：每个动作都能改键、能关；教学做在刘海上的小动画里 |

**冲突**：Swish 默认占着标题栏上的双指上滑（最大化 / 全屏）、下滑（最小化）、左右滑（半屏）。我们占的是同一块地方。
现在的做法是检测到它在跑就说一次（见 [标题栏手势](gestures.md)），没有强行抢。

## WindowMizer 6

$15–25 买断（按授权档和升级路径），只支持 Apple 芯片、macOS 15.3 以上；官网 windowmizer.com，2026-09-28 读取。
最新 6.2.8（2026-09-15）。激活和试用需要联网。

| 它有什么 | 我们对应 |
| --- | --- |
| 双击标题栏"卷起"，原位置留一条标题条 | 有，而且是**真窗口留在原处**，不是最小化再加一条假的 |
| 再双击标题条恢复 | 有：点一下卷帘条就展开 |
| 留着标题条、能看出是哪个窗口 | 有：卷帘条带图标和窗口名 |
| 多显示器 | 有，还多了换屏排回、移到另一块屏幕 |
| 悬停自动展开 | 有（看一眼），而且给的是实时画面不是快照 |
| 缩成一张小图（thumbnail），可半透明 | 没有，要做。原来写“别的 App 的窗口改不了透明度”是错的：小图是我们自己画的面板，半透明、排成网格、浮在最前都行，还能放实时画面。9/28 夜里定了要做，先做小样（见[新方向](direction.md)） |
| 小窗沿屏幕边自动排好、带 App 图标 | 有：整理卷帘条（⌃⌘0），卷帘条带图标和窗口名 |
| 藏起桌面图标、换纯色或照片 | 不做：和窗口无关 |
| 按 App 调标题栏高度 | 自动认标题栏高度，统一工具栏的窗口放宽 |
| 试用、正式发布、评分 | 我们没有试用版，也还没正式发布 |

## DockMate

macEnhance 出品，官网 [macenhance.com/dockmate](https://www.macenhance.com/dockmate.html)，2026-09-28 读取。
$14.99 起，一周试用，macOS 10.14 以上，原生支持 Apple 芯片；最新 0.8.7（2021-03-12），之后没有更新。
（9/28 白天这一节曾写成“取不到一手资料”，是找错了域名，已更正。）

| 它有什么 | 我们对应 |
| --- | --- |
| 指针停在 Dock 图标上看这个 App 的窗口 | 有：窗口浏览（Dock 悬停），实时画面 |
| 停在小图上看这扇窗的大图 | 有：大图预览；卷帘条、刘海格子上还能原位原尺寸看一眼 |
| 点一下聚焦，点一下或滚一下最小化、放大、关闭 | 有：激活、最小化、铺满屏幕、关闭、进入全屏、让开这个 App、退出 App、收起、置顶；滚轮没有接这些动作 |
| 开新窗口 | 有：窗口浏览菜单里的“新建窗口”（标着 ⌘N），按那个 App 菜单里标题是新建窗口的那一项；找不到这一项就不按。还没在真机上走过 |
| 调出这个 App 的所有窗口（App Exposé）、隐藏开关 | 有：点三下刘海是这个 App 的所有窗口；让开这个 App |
| 日历：当天日程、一键入会（Zoom、Google Meet） | 不做：和“让窗口让开”不是一件事 |
| 正在播放：封面、播放 / 暂停、切歌 | 不做 |
| 预览的大小、位置、悬停延迟可调 | 没做成可调：出现的时机和大小是固定的 |

## Alcove

Henrik Ruscon 的菜单栏工具，官网 [tryalcove.com](https://tryalcove.com)，2026-10-05 读取。下载页写 macOS 15、v1.7.7。
FAQ 写一次买断、最多 3 台同时使用、72 小时试用、14 天内可退、依赖私有 API、不收集资料。价格的 $14.99 只见转述，FAQ 没写数字，这里不采用。
开发者仓库 [v1.7.0 说明](https://github.com/henrikruscon/alcove-releases/releases/tag/v1.7.0)（2026-04-05）列了 duo、没有刘海时的 pill、波形改成对齐 iOS、AirPods Max、Lossless / Dolby Atmos、日历引导、无障碍引导。日历、锁屏小组件、模拟刘海只见二手页，标未核实。

刘海这一格以它为最强的别家。它强在一颗黑胶囊的连续变形；我们强在把窗口收进同一颗岛。不复制它的私有实现。

| 它有什么 | 我们对应 |
| --- | --- |
| 播放、通知、音量、亮度收在一颗会变形的胶囊里 | 同一颗刘海。紧凑左右耳是正在进行的那一件，展开是它的放大；两件同时露面时分开再合并 |
| v1.7.0 的 duo | 不照它的像素。对的是一颗岛分开、再合并，半路可以改方向 |
| 没有刘海时用 pill | 外接屏顶部正中的胶囊。不画假刘海 |
| 音量、亮度提示（v1.7.0 写了亮度页动画和 HUD 切换） | 先用合成事件驱动同一颗岛。真实系统按键和隐私登记分开做。它或同类 HUD 在跑就让位 |
| 锁屏小组件、日历、天气 | 未核实，不追 |
| 把窗口收进刘海 | 一手材料里没有。这是我们多出来的 |
