# 设置里的“隐私”一栏：接手者必读

2026-10-03。照 Loupe 的做法，把 WindowShade 读的每一样原样摊开：**现在读到的值、为什么读、去了哪里**，能关的给开关。
Newlearner 这样的人推荐一个要辅助功能和屏幕录制的工具之前，最想看的就是这一页；它也满足 v4 规格“按用途申请、数据不出本机”的要求。

- 设计稿（可交互）：[WindowShade 读到的](https://claude.ai/artifact/3SXfR2wyxHBGiBBEHxvjRA)
- 来由：[integration-loupe-glance.md](integration-loupe-glance.md) 第二步
- 刷脸解锁上线后要加的几行：照 [face-unlock.md](face-unlock.md)

## 长什么样

“隐私”一栏替换设置里的“权限与启动”。页头现在只有第一句：“WindowShade 读到的每一样都列在这里。”
第二句“除了检查更新，都不离开这台 Mac。”要等 P2（nettop 实测）核过才能上；代码里留了开关常量 `WS2PrivacyCopy.showsNetworkPromise`，默认关。
页头下一行写“打开这一页时读的 · HH:mm”，旁边是“再读一次”：打开这一页读一次，关掉就不再读，没有定时器。
下面分三组加“去了哪里”，三组的标题是“不用问就能读的”（系统给每个 App 都开着）、“你同意后才读的”（系统会先问你）、
“用了系统没公开的方法的”（Apple 没写进文档，系统更新后可能失效）。每行：名字 + 一行原因 + 要授权时的标签（要“辅助功能”）+ 右边的原值或“已授权/去授权”；
点开是同样三件事：读到的、为什么、去了哪里，能关的行在里面放原来那个开关（实时活动、桌面开合、浏览器下载、登录时自动启动、自动检查更新）。
还没接通的行（planned）默认不显示；刷脸解锁实验打开后，随身设备是否在场、脸部特征与比对结果、解锁凭据这三行才出现。

| 组 | 行 |
| --- | --- |
| 不用问就能读的 | 屏幕和刘海的形状、是否锁屏、配件电量、哪个 App 在录音 |
| 你同意后才读的 | 窗口的标题、位置和大小（辅助功能）、按了哪个键（辅助功能，只看键位）、窗口的画面（屏幕录制）、摄像头（眨眼和转头）、正在播放的歌（自动化） |
| 用了系统没公开的方法的 | 刘海的精确轮廓、别的桌面和已最小化的窗口的画面、屏幕开合的角度、机身的倾斜 |
| 去了哪里 | 联网卡片写明 windowshade.aaronlau.me（不通时改问 GitHub，关掉“自动检查更新”就不自己联网检查）；本机卡片列设置、恢复记录、运行记录，带“在访达中显示”；下面是这一组的各行 |

逐行的“为什么读”“代码里用的”“开关”见设计稿的规格表。“显示技术细节”默认藏着，打开后每行多一行接口名；
这是 copy-guide“实现不进界面”的唯一例外，Aaron 不同意就删。

## 硬要求

做不到就停下来写明卡在哪，不要换一个更容易的东西交差。

1. **先修日志，再上页面。**代码已改（`fe92cd1`）：运行记录写到 `~/Library/Logs/WindowShade/`（`Support/Diagnostics.swift` + `SecureLogFile.swift`），
   文件夹 0700、文件 0600、逐级 `O_NOFOLLOW` 校验；写窗口标题的 `wlog` 换成 `[redacted]`；开发用的 `WINDOWSHADE_LOG_PATH` 保留。
   旧版留下的 `/tmp/windowshade.log`：新版首次写日志时清一次（`Diagnostics.swift` 的 `LegacyLogCleanup`，只删当前用户自己的普通文件，符号链接、别人的文件、目录一律不动，做过一次就记下）。
   还差：新版在本机跑出日志后用另一个账户实测读不到。
2. **清单从代码里来，不手写。**每个读取点在一张登记表里登记（借 Loupe 的 `SignalProvider` 和三层 `Sensitivity`，带 MIT 版权声明）。
   加构建检查：代码里出现名单上的接口（`AXUIElementCopyAttributeValue`、`CGEvent.tapCreate`、`SCShareableContent`、`AVCaptureDevice`、
   `NSAppleScript`/`osascript`、`IOServiceMatching`、`CGSessionCopyCurrentDictionary`、`bezelPath`、`SLS*`/`CGS*`、`URLSession` 等）却没登记，就失败。
   页面和官网都从这张表生成。
3. **只写核过的。**每一句承诺都在下面的核对表里有证据；没核过的句子不上页面，也不进发布说明和官网。
4. **打开这一页才读。**不加轮询、不常驻；空闲 CPU 和唤醒次数照 [performance.md](performance.md) 第七节测，不许变差。
5. **不新开窗口，不复制开关。**两项授权和“登录时自动启动”并进“隐私”；每个开关仍是原来那一个（实时活动、桌面开合、自动检查更新……）。
   改了栏目名，欢迎窗口、菜单、README、官网里提到“权限与启动”的地方一起改。
6. **文案照 [copy-guide.md](copy-guide.md)。**一个东西一个名字；值写原值（“妙控鼠标 82%”），不写“读取设备信息”。
7. **刷脸解锁的那几行跟着它一起上。**蓝牙、人脸特征、存的密码，功能开着才出现，不提前承诺。
8. **每一步都能装上、能试、能撤回。**先给 Aaron 能装的构建；Loupe 的名字、图标、图片不能用。
