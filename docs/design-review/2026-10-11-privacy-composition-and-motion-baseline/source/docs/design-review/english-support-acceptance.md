# WindowShade 2 英语支持

2026-10-11 用户要求英语支持，纳入当前完整设计接管目标。中文继续受 copy-guide 固定词汇约束；英文用自然、简短的动作与状态文案，统一一个概念一个名称。与动效共同验证，不能依赖中文字宽。

现有入口 `prototype/Core/WSL10n.swift`：锁保护的进程语言，默认中文；英文资源在 `Resources/Localization/en.lproj`，目前只由代码显式设为英语。`Localizable.xcstrings` 有206键，构建检查键/中英文/源句/占位符并编译资源；它证明这些键齐全，不证明全产品覆盖。部分设置已接入口，但隐私页等仍直接写中文。先沿用入口，不另造翻译系统。

交付应覆盖菜单、设置、欢迎流程、刘海与窗口浏览、错误/空状态/权限说明、提示与辅助功能标签；用户资料、文件名、系统提供的App名称保留原值。数字、日期、时间与复数按语义处理，字符串插值不能靠拼接中文语序。选择规则需要一致，并对打包后实际资源路径检查；未明确的默认语言与切换方式在最小贯通样件时具体定案。

先完成一条真实生产表面的中英文贯通，检验长英文、窄宽、浅深色、换内容及减少动态效果。后续批量迁移按表面交付，检查漏译与退回中文的真实原因；不把单纯206键check0写成“英语已支持”。当前QA合成资料不写用户持久语言偏好，不触发真实权限/网络/产品启动。

迁移边界：`WS2SettingsCopy.short` 以中文源句选短副标题，`symbol(for:)` 以显示名称查图标（Preferences与DuoSettingsWindow都调用）。若先翻译显示名称再套这两个表，会丢失现有缩写与图标选择。本地化必须在语义身份或已选文案之后进行，逐项保持原功能/图标，不用英文显示字符串作为路由身份。

先沿README既有英文用词：收起/展开用 Roll up / Unroll，置顶/取消置顶用 Pin / Unpin，看一眼用 Glance，窗口浏览用 Window browsing，卷帘条首次解释为 rolled-up window bar。名称定案时再对照全部菜单、设置与官网，避免另外造 Shade/Collapse/Fold 三套同义动作。隐私说明要译出读什么、为何、去哪里，权限名沿macOS官方英文，不扩充尚未验证的联网承诺。

实现注意：`WS2PrivacyData.rows/groups` 当前是静态let，若在初始化时按当前语言翻译，后来切换语言不会自然重建；需要明确启动时定语言/重新启动生效或显式重建策略。语言读取不得藏进所有静态copy初始化，避免QA在构造纯视图时意外读取标准偏好。当前只记录约束，尚未改变语言默认或持久偏好。
