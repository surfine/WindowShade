## 一句话

**专注时，聊天收进刘海、刘海里走着倒计时；休息时，整个桌面收进刘海，看看远处；碰一下就回来。**
番茄钟没有自己的窗口，用的全是 WindowShade 已有的东西：刘海、实时活动、收进刘海、全部收进刘海。

## 从 Tomato Ritual 取什么

| 它的做法 | 我们 |
| --- | --- |
| 休息时多屏毛玻璃幕布 + 呼吸光环，Esc 随时退出 | **全部收进刘海**：桌面一下子空了，刘海里一圈慢慢呼吸的光环；按任意键或点一下，窗口原样回来。不另造幕布 |
| 按截止时间计时，睡眠、合盖后不漂 | 照做：记截止时刻，不累加 tick |
| 锁屏、离开时自动暂停 | 专注暂停；休息照走 |
| 菜单栏安静、迷你 HUD、桌面小组件 | 刘海就是这三样 |
| 全局快捷键（开始暂停、重置、跳过） | 只设一个：开始 / 暂停（默认不设键，可录制） |
| 白噪音、热力图、导出 CSV、任务名、长休息 | **不做**。音乐已经是实时活动；只记“今天第几个” |

## 怎么用

| 时刻 | 刘海 | 规则 |
| --- | --- | --- |
| 开始 | 刘海展开那一排的末尾有一个 `timer` 按钮；启动台负一屏也有一张卡片；或按快捷键 | 一按就开始，不弹设置 |
| 专注中 | 紧凑：左边一圈番茄红的进度环，右边 **18 分**；最后一分钟变成 **0:42** | 每分钟更新一次，最后一分钟每秒更新；进度环用 Core Animation 从现在动到截止时刻，CPU 不逐帧算 |
| 停在刘海上 | 展开：大字 **18:42**，下面“今天第 3 个”，三个圆按钮 `pause.fill` `forward.end.fill` `stop.fill` | 暂停、跳过、结束 |
| 专注结束 | 短暂提醒：`cup.and.saucer` **休息 5 分钟**；轻提示音，触控板轻震 | 自动进入休息，少按一下 |
| 休息 | 桌面全部收进刘海；刘海展开成一圈呼吸的光环加 **看看远处 · 4 分** | 按任意键、点一下或 Esc：窗口原样回来，休息照走（变回紧凑的绿色环） |
| 休息结束 | 短暂提醒：**休息好了** + 按钮 `play.fill` **再来一个** | 不自动开下一个；窗口要是还收着就放回 |
| 锁屏、睡眠 | — | 专注暂停（截止时刻顺延）；休息照走；回来时只显示现状 |

## 和 WindowShade 的结合

- **专注时把聊天收进刘海**（一个开关，默认开）：开始专注时，名单里 App 的窗口收进刘海；休息时它们回来，正好看消息；
  下一个专注开始时再收。名单和刷脸解锁的“私人 App”是同一份（预设聊天、邮件），在一处改。
- **休息 = 全部收进刘海**：这个动作已经有了，番茄钟只是在休息开始时调用它，结束或碰一下时放回。
- **实时活动**：番茄钟是一种持续活动，和音乐、录音并排，最多三个，两指横扫切换。用户自己开的计时，排在录音之后、隔空投送之前。
- **遥控器和手柄**：焦点导航能走到 `timer` 按钮；按 × 或环中心开始。
- **刷脸解锁的离开**：离开时专注已经暂停；回来时“离开期间”摘要里写“番茄钟暂停在 12 分”。

## 设置（只有两项）

| 项 | 选项 |
| --- | --- |
| 专注时长 | 25 分钟（休息 5）/ 50 分钟（休息 10） |
| 专注时把聊天收进刘海 | 开 / 关 |

在“实时活动”那一栏里，不另开一栏。快捷键在“快捷键”栏，默认空着。

## 不做

白噪音、统计图、导出、任务名、长休息、全屏幕布、桌面小组件、菜单栏图标、通知中心横幅（刘海已经说了）。

## 能耗

专注时，紧凑态一分钟醒一次；休息时呼吸光环用 Core Animation 的循环动画，不占主线程；没开番茄钟时零开销。
记录只有一个数字：“今天完成几个”，过零点清零。不用新权限。

## 文案

番茄钟 / 专注 / 休息 / 跳过 / 结束 / 再来一个 / 看看远处 / 休息好了 / 今天第 3 个。数字用“18 分”，最后一分钟用“0:42”。

## 做的顺序

| 步 | 做什么 | 谁 |
| --- | --- | --- |
| T1 | 纯逻辑：截止时刻计时器（开始、暂停、继续、跳过、结束、锁屏暂停、睡眠校正）、今天计数 | DeepSeek |
| T2 | 刘海里的番茄钟活动：紧凑、展开、提醒、休息光环 | DeepSeek 写，主模型复核动效 |
| T3 | 接“收进刘海”“全部收进刘海”和私人 App 名单 | 主模型 |
| T4 | 设置两项 + 快捷键；启动台负一屏卡片 | DeepSeek |
