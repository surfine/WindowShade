# 文案规则（产品与官网共用）

写给第一次用的人看。目标不是"显得专业"，而是让人一眼知道这是干什么的、点下去会发生什么。
每条新文案都按这份规则写；改文案时先问"用户会怎么理解这句话"，而不是"我们是怎么实现的"。

## 六条规则

1. **说用户遇到的事，不说我们怎么做的。** 权限、材质、层、几何、`pt`、bundle ID、内部状态名
   都不进用户界面。用户看到的是"窗口收起来了""画面暂时看不到"，不是"折叠事务已完成验证"。
2. **一个东西只有一个名字。** 同一个动作、同一个表面，全产品（应用菜单、设置、面板、官网）
   用同一个词。出现第二种说法就是缺陷，不是风格。
3. **一句话一件事。** 主句先说结果，条件跟在后面。不要三层从句、不要括号里再塞括号。
4. **术语先用日常说法，再给名字。** "收起窗口（卷帘）"可以；直接丢"卷帘条/原貌卷帘/材质"
   不行。非用不可的术语第一次出现时用一句大白话解释。
5. **删掉不改变理解的词。** 形容词、修饰语、"支持多种方式"这类空话一律删。奥卡姆剃刀：
   能少一个词就不多一个词，能少一句话就不多一句。
6. **不承诺做不到的事。** 不写"永远""保证""完全"，不写我们没验证过的数字。

## 固定词汇（全产品统一，改文案时照这个来）

| 概念 | 用词 | 不要用 |
| --- | --- | --- |
| 把窗口收进标题条的动作 | **收起窗口 / 展开窗口**（动词：收起、展开） | 折叠、卷起、卷成、collapse |
| 收起后留在屏幕上的那条 | **卷帘条** | 标题条、细杠、strip |
| 把窗口固定在最前面 | **置顶 / 取消置顶** | 钉住、pin、悬浮 |
| 停在 Dock 图标上翻出该应用的窗口 | **窗口浏览**（功能名） | 窗口选择面板、Dock 悬停面板 |
| 菜单里打开该面板的动作 | **选择窗口…** | 打开窗口浏览器 |
| 只读的大图 | **大图预览** | Quick Look 预览、Space 预览 |
| 指针停在卷帘条上，下方出现预览卡片、移开收回 | **看一眼** | 偷看、peek、悬停展开、临时展开 |
| 看一眼拿不到实时画面时的提示 | **收起时的画面**（收起的窗口）/ **不是实时画面**（带到每张桌面的窗口） | 快照、缓存画面、过期截图 |
| 让窗口留在原处、别的桌面也能看一眼 | **带到每张桌面 / 不再带到每张桌面** | 跨桌面、随身、跟随、pin to all spaces |
| 在标题栏或卷帘条上两指滑动、张合或滚动滚轮 | **标题栏手势**；动作沿用 **收起窗口 / 展开窗口 / 左半屏 / 右半屏 / 铺满屏幕 / 撤销上次排布** | 触控板手势、触摸板手势、手势操作、最大化、吸附 |
| ⌃⌘↓ / ⌃⌘↑：沿“卷帘条 ⇄ 原来大小 ⇄ 铺满屏幕”走一格 | **变大一级 / 变小一级** | 最大化、最小化、放大、缩小 |
| 已在三分之一的窗口再往那边推，到相邻的显示器上 | **移到左边的屏幕 / 移到右边的屏幕** | 跨屏、甩到副屏、下一个显示器 |
| 占屏幕宽度的三分之一、三分之二 | **左三分之一 / 左三分之二 / 右三分之一 / 右三分之二** | 1/3、2/3、三等分 |
| 拖着标题栏快速甩出去松手 | **甩一下标题栏** | 抛窗口、flick、快速拖拽 |
| 窗口外观两种选择 | **跟原来一样 / 统一标题栏** | 原貌卷帘、标准标题栏 |
| 外观跟随系统 | **跟随系统外观** | 系统玻璃、原生材质 |
| 用户碰到的问题 | 说现象：**画面暂时看不到** | 说原因：材质回退、权限缺失 |

## 改前改后（真实例子）

| 改前 | 改后 | 为什么 |
| --- | --- | --- |
| 双击标题栏以折叠 | 双击标题栏收起窗口 | 用户不认识"折叠"，认识"收起" |
| 卷帘样式：原貌卷帘 / 标准标题栏 | 收起后的样子：跟原来一样 / 统一标题栏 | 两个选项名都要求用户先懂行话 |
| 每行一个 bundle ID。被排除的应用不会出现在 Dock 面板与窗口选择面板中。 | 一行一个应用标识。这里列出的应用不会出现在窗口浏览面板里。 | bundle ID 是给开发者看的；功能只有一个名字 |
| 目标无法确认：PID 复用 | 没能确认是哪一扇窗口 | PID 复用是实现细节 |
| 操作超时，底层事务可能仍在执行 | 操作超时，可能还在进行 | 删掉用户无法判断的部分 |
| 一个窗口约 312 × 236 pt | 只占一张卡片那么大 | pt 对网页读者没有意义 |
| 跟随系统（macOS 26 及以上使用真实系统玻璃） | 跟随系统外观 | 用户不需要知道我们调了哪个 API |

## 写完之后自检

- 第一次用的人读完这句话，知道点下去会发生什么吗？
- 这句话里有没有只有我们才懂的词？
- 同一个东西，别处是不是叫了另一个名字？
- 删掉一个词、删掉半句话，意思还在吗？在就删。
