# 文案规则（产品与官网共用）

写给第一次用的人看。目标不是"显得专业"，而是让人一眼知道这是干什么的、点下去会发生什么。
每条新文案都按这份规则写；改文案时先问"用户会怎么理解这句话"，而不是"我们是怎么实现的"。

## 七条规则

1. **说用户遇到的事，不说我们怎么做的。** 权限、材质、层、几何、`pt`、bundle ID、内部状态名
   都不进用户界面。用户看到的是"窗口收起来了""画面暂时看不到"，不是"折叠事务已完成验证"。
2. **一个东西只有一个名字。** 同一个动作、同一个表面，全产品（应用菜单、设置、面板、官网）
   用同一个词。出现第二种说法就是缺陷，不是风格。
3. **一句话一件事。** 主句先说结果，条件跟在后面。不要三层从句、不要括号里再塞括号。
4. **术语先用日常说法，再给名字。** "收起窗口（卷帘）"可以；直接丢"卷帘条/原貌卷帘/材质"
   不行。非用不可的术语第一次出现时用一句大白话解释。
5. **删掉不改变理解的词。** 形容词、修饰语、"支持多种方式"这类空话一律删。奥卡姆剃刀：
   能少一个词就不多一个词，能少一句话就不多一句。
6. **不承诺做不到的事。** 不写"永远""保证""完全"，不写我们没验证过的数字。
7. **一个符号能说清，就不写一句话。**（Aaron 2026-10-03：“整个 app 多用 SF Symbols，不要大段大段文字。”）设置每一行前面放一个 SF Symbol 加名字；副标题最多一行（约 16 个字），说不完就不说，细节放进 `info.circle` 的小气泡或一段会动的示意。刘海里是“符号 + 不超过 8 个字的主句”，数字放副句。菜单项带符号。符号对照见 design-system.md §4.11。

## 固定词汇（全产品统一，改文案时照这个来）

| 概念 | 用词 | 不要用 |
| --- | --- | --- |
| 把窗口收进标题条的动作 | **收起窗口 / 展开窗口**（动词：收起、展开） | 折叠、卷起、卷成、collapse |
| 收起后留在屏幕上的那条 | **卷帘条** | 标题条、细杠、strip |
| 设置里选“缩略图”后，收起时窗口在原处缩成的那张小图 | **缩略图**；动作仍叫 **收起窗口 / 展开窗口**，排整齐叫 **整理缩略图**，设置项叫 **收起后的样子** | 小窗、小图、占位窗口、thumbnail |
| 把窗口固定在最前面 | **置顶 / 取消置顶** | 钉住、pin、悬浮 |
| 一下让开所有置顶的窗口、再按一下按原来的前后顺序放回（老板键） | **暂时取消全部置顶 / 恢复全部置顶** | 暂停置顶、隐藏置顶、老板键 |
| 妙控键盘、鼠标、触控板等连上或电量低时刘海里那一句 | 主句说事：**「妙控鼠标已连接」「妙控鼠标电量低」**；电量放副标题：**「电量 82%」「还剩 10%，记得充电」**（可更换电池的写「记得换电池」）；读不到写「电量暂时读不到」，不写 0%；几台一起连上写「3 个设备已连接」 | 电池电量、剩余电量、还能用 N 分钟、正在充电（读不到可靠的充电状态时）、蓝牙设备已配对 |
| 设备的名字 | **妙控鼠标 / 妙控键盘 / 妙控板**；认不出型号写「蓝牙配件」 | Magic Mouse、巧控滑鼠、鼠标 2 代、不认识的型号冒充别的名字 |
| 关掉安全相关的设置前，在刘海里用指纹确认这一件事 | **用 Touch ID 确认**；刘海里那一行直接写要做的事（「关闭自动检查更新」），没确认时写「没有确认，……仍然开着」 | 验证身份、授权、认证成功、安全验证 |
| 停在 Dock 图标上翻出该应用的窗口 | **窗口浏览**（功能名） | 窗口选择面板、Dock 悬停面板 |
| 菜单里打开该面板的动作 | **选择窗口…** | 打开窗口浏览器 |
| 只读的大图 | **大图预览** | Quick Look 预览、Space 预览 |
| 指针停在卷帘条上，或停在卷轴边上那一条（停在屏幕外那一列露出的一条）上，或停在刘海那一排的某一格上，出现预览卡片、移开收回 | **看一眼** | 偷看、peek、悬停展开、临时展开 |
| 看一眼拿不到实时画面时的提示 | **收起时的画面**（收起的窗口）/ **不是实时画面**（带到每张桌面的窗口、卷轴边上那一条；刘海那一排里已最小化的窗口、已隐藏的 App、侧拉的窗口也用这个） | 快照、缓存画面、过期截图 |
| 让窗口留在原处、别的桌面也能看一眼 | **带到每张桌面 / 不再带到每张桌面** | 跨桌面、随身、跟随、pin to all spaces |
| 在标题栏或卷帘条上两指滑动、张合或滚动滚轮 | **标题栏手势**；动作沿用 **收起窗口 / 展开窗口 / 左半屏 / 右半屏 / 铺满屏幕 / 撤销上次排布** | 触控板手势、触摸板手势、手势操作、最大化、吸附 |
| ⌃⌘↓ / ⌃⌘↑：沿“卷帘条 ⇄ 原来大小 ⇄ 铺满屏幕”走一格 | **变大一级 / 变小一级** | 最大化、最小化、放大、缩小 |
| 已在三分之一的窗口再往那边推，到相邻的显示器上 | **移到左边的屏幕 / 移到右边的屏幕** | 跨屏、甩到副屏、下一个显示器 |
| 占屏幕宽度的三分之一、三分之二 | **左三分之一 / 中间三分之一 / 右三分之一 / 左三分之二 / 右三分之二** | 1/3、2/3、三等分 |
| 上半或下半一行里的格子（网格） | **左上三分之二、左下六分之一、中上六分之一……**（位置 + 占多宽） | 网格单元、3×2、sixth |
| 按各自要的地方把一块屏上的窗口一次排好（两指张开、⌃⌘M） | **魔法平铺** | 自动平铺、智能布局、auto tile |
| 放不下时窗口一列挨一列接到屏幕外、左右滑过去（niri 的卷动平铺） | **卷轴**；动作：**这一列宽一档 / 这一列窄一档** | 卷动平铺、无限画布、scrolling、strip、滚动工作区 |
| 把整条卷轴缩小铺在这块屏上，点哪扇就把它那列滑出来 | **卷轴概览** | 概述、总览、overview、Exposé、调度中心 |
| 欢迎窗口第二步问的来处 | 问句 **你之前常用哪个？**；设置项 **之前常用**；三个选项 **Windows / iPad / 一直用 Mac** | 来源、背景、迁移自、老用户类型 |
| 按住 ⌥（或 ⌘）连按 Tab 一扇扇挑窗口 | **按窗口切换** | Cmd-Tab Plus、窗口切换器、Alt-Tab |
| 提示里画的键帽和读屏念的键名 | 键帽照实物：符号在上、小字在下（⌃ / control、⌘ / command）；读屏念 **Control、Command、Option、Shift**，不念符号 | Ctrl、Cmd、Alt（Windows 访客那句里说他原来的键时除外） |
| 这块屏上的窗口一下全收进刘海 / 放回 | **全部收进刘海** | 隐藏全部、最小化全部、显示桌面 |
| 当前窗口换到另一块显示器 | **移到另一块屏幕**；反方向是 **移到上一块屏幕** | 移到另一显示器、跨屏、下一个显示器 |
| 整个宽度的上一半、下一半 | **上半屏 / 下半屏** | 顶部一半、Top Half |
| Rectangle 的 Larger / Smaller（四边各 30 点），和“变大一级 / 变小一级”不是一回事 | **大一点 / 小一点** | 放大、缩小、Make Larger |
| 左右不动、上下占满 / 大小不变放到正中 | **高度占满 / 居中** | 最大化高度、Maximize Height |
| 换成 Rectangle 那一套快捷键 | **用 Rectangle 的快捷键**；按钮 **换上**；这一组叫 **更多排法** | 导入 Rectangle、迁移、兼容模式 |
| 首次打开时的动画引导；菜单里随时能再打开 | 窗口和菜单都叫 **欢迎使用 WindowShade…**（菜单项带省略号）；按钮 **继续 / 上一步 / 跳过 / 开始使用**，没授权时 **稍后再说** | 使用说明、新手教程、Onboarding、导览 |

| 侧拉窗口外面那一圈、角上改大小的那段弧 | 只在说明里叫 **玻璃边框 / 把手**；界面上不起名字，要提就说看得见的样子：**窗口外面那一圈 / 角上那段弧** | 边框、grabber、resize handle |
| 排好的窗口之间、和屏幕边之间的空隙 | **窗口之间留缝**；几档：**不留 / 窄 / 宽** | 间距、gap、边距 |
| 点 Dock 上最前面那个 App 的图标把它藏起来 | **让开这个 App** | Dock 反转、最小化、隐藏窗口 |
| 拖着标题栏到刘海时垂下的那一块 | **落点小岛**；五格：**左半屏 / 铺满屏幕 / 收进刘海 / 魔法平铺 / 右半屏** | 分屏岛、Snap Island、布局面板 |

| 刘海一排里系统最小化的窗口、⌘H 隐藏的 App | **已最小化 / 已隐藏**；点一下是**还原** | 最小化窗口仓、隐藏区 |
| 刘海一排里别的桌面上的窗口 | 格子上写**桌面 3 / 全屏**（和调度中心的叫法一致）；点一下是**去** | 其他空间、Space 3、跨桌面窗口、远程窗口 |
| 把文件交给刘海后挑 App | **用哪个 App 打开“文件名”** | 打开方式、Open With |

| 拖着标题栏快速甩出去松手 | **甩一下标题栏** | 抛窗口、flick、快速拖拽 |

## 改前改后（真实例子）

| 改前 | 改后 | 为什么 |
| --- | --- | --- |
| 双击标题栏以折叠 | 双击标题栏收起窗口 | 用户不认识"折叠"，认识"收起" |
| 卷帘样式：原貌卷帘 / 标准标题栏 | 收起后的样子：跟原来一样 / 统一标题栏 | 两个选项名都要求用户先懂行话 |
| 每行一个 bundle ID。被排除的应用不会出现在 Dock 面板与窗口选择面板中。 | 一行一个应用标识。这里列出的应用不会出现在窗口浏览面板里。 | bundle ID 是给开发者看的；功能只有一个名字 |
| 目标无法确认：PID 复用 | 没能确认是哪一扇窗口 | PID 复用是实现细节 |
| 操作超时，底层事务可能仍在执行 | 操作超时，可能还在进行 | 删掉用户无法判断的部分 |
| 一个窗口约 312 × 236 pt | 只占一张卡片那么大 | pt 对网页读者没有意义 |
| 跟随系统（macOS 26 及以上使用真实系统玻璃） | 跟随系统外观 | 用户不需要知道我们调了哪个 API |

## 写完之后自检

- 第一次用的人读完这句话，知道点下去会发生什么吗？
- 这句话里有没有只有我们才懂的词？
- 同一个东西，别处是不是叫了另一个名字？
- 删掉一个词、删掉半句话，意思还在吗？在就删。
