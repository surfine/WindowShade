## 準備

1. 建構簽名隔離版：`cd prototype && ./build.sh --stage`，產物 `.build/duo-validation/WindowShade.app`。
2. 確認機器空著（探針在有人操作時會自停）；效果依當前設定。
3. 記錄中繼資料：原始碼／建置 SHA、系統 build、機型、顯示器像素／縮放／刷新率、電池或接電、低電量模式、熱狀態。
4. 若無硬體計數器，該格記 `not_available`，**不填零**。

## 建議數值與比較方法（審計建議，非已取得結果）

1. 熱輸入回呼 P99 ≤ 1ms；同時檢查無界操作與正確性，不只看平均數。
2. 「無活動消費者」空閒場景可先以單核平均 CPU ≤ 0.5% 為調優目標，不是通用承諾；同時報整段 CPU-seconds。
3. 若宣告 60fps，動態可見段另設門檻（例：平均 ≥58fps、幀間隔 P95 ≤20ms），並分別統計新源幀率。
4. 每項改動做交錯 A／B、多個重複樣本；改進小於量測噪聲時記「不確定」，不宣稱省電百分比。
5. Time Profiler／System Trace／Metal 分別回答不同問題；功耗看 WindowServer、相機與相關服務。
6. 分開觀察 CPU、GPU、記憶體頻寬與整機能量；比較一次操作的**能量**，不只比耗時。
