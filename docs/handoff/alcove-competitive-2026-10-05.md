# Alcove 竞品分析 · 刘海这一格 · 2026-10-05

来源：[tryalcove.com/changelog](https://tryalcove.com/changelog)（页面为前端渲染，正文以官方 release 仓为准）、[henrikruscon/alcove-releases](https://github.com/henrikruscon/alcove-releases)（46 个 release，最新公开 **1.7.2 / 2026-04-07**）、[tryalcove.com/faqs](https://tryalcove.com/faqs)（Updated June 2026）。对照本仓 [blueprint.md](../blueprint.md)、[design-grammar.md](../design-grammar.md)（已写：学一颗岛分开再合并、音量亮度长在岛上；不学锁屏小组件、假刘海、私有绘制与代码；界面不叫灵动岛）。

## 一句话

Alcove 把「Mac 上的灵动岛日常」做成了可卖的产品：媒体、音量亮度、日历、配件电量、锁屏小组件、无刘海胶囊，每周打磨。WindowShade 的蓝图更大（窗口住处 + 放行 + 指挥 + CarPlay），但**刘海作为一天上百次的习惯表面**，目前技不如人——认账是为了改过，不是为了认输。

## Alcove 在卖什么

| 层 | 内容（从 changelog 归纳） |
| --- | --- |
| 定位 | Dynamic Island for Mac；一次买断、72h 试用、3 设备、依赖私有 API「as is」 |
| 每日岛 | Now Playing（多源、波形、Lossless/Atmos、跳/划/循环）、音量与亮度 HUD（替换/协同系统 HUD）、多 live activity、悬停展开、横滑/中键切换 |
| 日程天气 | 展开日历、QuickPeek、入会、Fantastical / Notion Calendar、空日天气 |
| 配件 | AirPods / HomePod / 输出设备列表、低电提醒、连接态 |
| 锁屏 | Now Playing / Focus / Weather / Battery / Connectivity / Calendar 小组件（文法明确不学这一块） |
| 显示形态 | 有刘海对齐硬件；无刘海 pill（1.7）；可强制 simulated notch；Duo mode；Neo / Studio Display / BetterDisplay |
| 工程习惯 | 短周期热修 stutter / CPU / crash；权限与无障碍 onboarding；全屏 / Mission Control 隐藏 |

版本弧：**1.0–1.2** HUD + 媒体 + AirPods → **1.3** 锁屏小组件 → **1.4** 日历 live activity → **1.5** 多活动 → **1.6** 展开日历与生态适配 → **1.7** duo / pill / 音频格式 / a11y onboarding。

## 对照：他们领先 / 我们领先 / 文法禁止抄

### 他们领先（认账）

1. **媒体岛完成度**：曲目、封面、波形、多源、跳转手势、格式徽标——changelog 里最大一块是 music/HUD/calendar。
2. **音量 / 亮度就是岛的呼吸**：跟手滑杆、设备符号、外接屏与 BetterDisplay、防 spam——我们稿上要对齐，产品还没收完。
3. **日历作为持续活动**：展开月历、第三方日历、入会——我们仲裁表有「持续活动」，日历不是主线。
4. **无刘海形态已出货**：pill + simulated notch 开关；我们胶囊五态仍是对照账未收项。
5. **发布节奏像消费品**：周更修 stutter / energy；用户感知「岛稳」。
6. **锁屏小组件矩阵**（我们故意不跟）：他们在锁态仍有品牌存在感。

### 我们领先或独有（别妄自菲薄）

1. **窗口三种住处**：卷帘条 / 边 / 刘海，看一眼、放回、侧拉分屏——Alcove 不做窗口管理。
2. **六层仲裁 + 放行独占**：刷脸、审批、指挥手势压一切——他们是资讯岛，不是放行岛。
3. **启动台从刘海长出**：短按刘海是入口，不是只展开 Now Playing。
4. **隐私与信号登记**：读什么摊开；私有 API 有退路叙事。
5. **蓝图深度**：指挥、CarPlay 接收、离开就锁、agent 在岛里批准——Alcove changelog 不见这些。

### 文法已划的边界（抄了就输）

- 不学锁屏小组件、假刘海、私有绘制与代码。
- 界面不叫「灵动岛」。
- 刘海纯黑贴硬件；无刘海用胶囊，不画假缺口（除非 Aaron 改准入）。

## 全方位超越：改过自新路线

原则：**在他们最强的格子上达到「不丢人」；在窗口 × 放行 × 一入口上做成他们碰不到的系统。** 不要用第二套浮窗去模仿 Alcove。

60 天落地排期（含新增 **A6 下一场会议**、八镜验收与工程门槛）见 [alcove-land-plan-2026-10-05.md](alcove-land-plan-2026-10-05.md)；A1–A5 / B1–B5 编号含义不变。

### A. 必须追上的共用体验（30–60 天）

| 优先级 | 动作 | 验收 |
| --- | --- | --- |
| A1 | **胶囊五态 + `island.hug`** 走完对照账 | 无刘海屏 / Neo 上五种呈现可演示；肩不画 |
| A2 | **音量与亮度长在同一颗岛** | 跟系统键；跟手；外接屏不崩；与媒体/提醒仲裁正确 |
| A3 | **持续活动：横滑切换 + 最多三** | 与蓝图一致；手感不卡（对照 Alcove cycle stutter 教训） |
| A4 | **媒体最小可用岛** | 封面 + 曲名 + 播放/暂停/下一首；波形可后置；不追求 Spotify 全家桶 |
| A5 | **动效与能耗验收成习惯** | 悬停 `dwell.hoverExpand`；无 stutter；空闲能耗有数字；120Hz 真机跑一次 |

### B. 用独门武功拉开（并行）

| 优先级 | 动作 | 为什么 Alcove 跟不上 |
| --- | --- | --- |
| B1 | **一扇窗三个住处闭环** | 收起→岛/条/边→看一眼→放回，同一套弹簧 |
| B2 | **放行独占可演示** | 刷脸 / 审批出现时资讯全部挂起，让出后不补播 |
| B3 | **短按启动台、长按 CarPlay（或指挥）** | 刘海是入口，不是装饰条 |
| B4 | **卡住时开口 + 离开就锁** | 叙事是「要你放行的事只问一次」 |
| B5 | **隐私一栏可核** | 卖信任，不卖波形选项 |

### C. 明确不打的仗

- 不堆锁屏小组件矩阵。
- 不默认画假刘海讨好无缺口屏（pill 即可）。
- 不追波形样式选项、专辑 glare、十种 widget 皮肤。
- 不把产品文案改成「灵动岛」。

### D. 产品与发布纪律（向对方学方法，不学表面）

1. **刘海专项周更**：媒体 / HUD / 日历 stutter 一类问题单独看板，避免只堆窗口大功能。
2. **真机片：同一颗岛一天**——悬停、音量、提醒、放行、收窗进岛、启动台，六镜连贯；概念片五处 wow 里至少三处是真机。
3. **对外一句话**：看不见的东西都在刘海里，碰一下就回来；要你放行的事，只在刘海里问你一次。——用这句话压过「Dynamic Island for Mac」。

## 风险

- 私有 API 双方共有；Alcove FAQ 已写「as is」。我们要更早摊开登记与失效退路。
- 若只补媒体不补窗口闭环，会变成较差的 Alcove。
- 若只做窗口不做岛日常，用户仍会装 Alcove 当「岛」，我们变后台工具。

## 结论

Alcove 赢在**频率、完成度、消费品节奏**；我们赢在**系统野心与窗口/放行独门**。迎头赶上 = A 档不丢人 + B 档做成系统；改过自新 = 承认胶囊未收、媒体岛半成品、发布不像对方勤，然后按 A1–A5 收口，而不是再开一扇窗。
