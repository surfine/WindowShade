# 菜单栏菜单：从 24 项收到 10 项左右

2026-10-03。Aaron：“菜单栏的菜单也是，不可无节制扩张。”设计稿：[看与指挥](https://claude.ai/artifact/9mbRLt1QGpsKLKip991Xe3)。

## 现在（截图，24 项）

屏幕开合角度、当前窗口（标题）、收起当前窗口、整理卷帘条、✓双击标题栏收起窗口、置顶当前窗口、带到每张桌面、侧拉当前窗口、
画中画当前窗口、魔法平铺、移到另一块屏幕、收进刘海、全部收进刘海、启动台、实时活动、验证 Touch ID…、锁屏开合效果、
检测面部动作 ▸、选择窗口…、欢迎使用 WindowShade…、设置…、关于 WindowShade、检查更新…、退出 WindowShade。
收着窗口时，下面还多一段“已收起的窗口”。

问题有三个：

- 开发用的三项混在里面：屏幕开合角度、验证 Touch ID…、检测面部动作；
- 两个开关放在了菜单里：双击标题栏收起窗口、锁屏开合效果；
- 对当前窗口的动作排成一长串，常用的和少用的一样显眼。

## 规则

1. **菜单只放两种东西**：对当前窗口做的事，以及进 App 的门。开关进设置，开发用的进开发菜单。
2. **常用的平铺，少用的收进一个子菜单。**一级菜单不超过 12 项（不算“已收起的窗口”那一段）。
3. **每项都带 SF Symbol**，名字照 copy-guide；快捷键照现在的。
4. **正在进行的事才出现**：番茄钟、指挥模式、编程会话在进行时，顶上多一行状态，点它进刘海对应的展开；结束了就消失。
5. **新功能不默认进菜单。**要加一项，得先拿掉一项，或者证明它比现有某一项更常用。

## 拿掉的去哪儿

| 原来的项 | 去哪儿 |
| --- | --- |
| 屏幕开合角度、验证 Touch ID…、检测面部动作 | **开发版**里，按住 ⌥ 才出现的“开发”子菜单；发布版里没有 |
| 双击标题栏收起窗口 | 设置 → 卷帘（已有这一行） |
| 锁屏开合效果 | 设置 → 刷脸解锁那一栏（开了刷脸解锁就一起开） |
| 实时活动 | 刘海本身就是入口；设置里有开关 |
| 欢迎使用 WindowShade… | 设置 → 通用最上面；菜单里按住 ⌥ 也能看到 |
| 关于、检查更新… | 按住 ⌥ 出现；设置 → 通用里也有 |
| “收起当前窗口”“置顶当前窗口”…… | 标题行已经说了是哪扇窗，名字去掉“当前窗口”，短一半 |

## 验收

- 发布版一级菜单常驻项 ≤ 12；开发用的项在发布版里看不到。
- 每个功能仍然至少有一个入口：快捷键、刘海、设置或菜单，不能有功能因为挪出菜单而找不到。
- 读屏念出来的名字和看到的一样；子菜单“排列”有符号和快捷键。
- 现有和菜单有关的测试（包括 `StandardMenu` 的“已收起的窗口”分段）改成新结构后照样通过。
