## 一整套体验

| 时刻 | 用户看到的 | 出路 |
| --- | --- | --- |
| 录脸（一次） | 刘海展开成取景框，转头一圈，九个方向依次亮起；可再录几种样子 | 太暗先补光；没对准刻度不亮 |
| 工作中 | 刘海和实体刘海重合，什么都不画 | — |
| 合上 | 桌面朝刘海折进去（开了刷脸解锁，合盖效果一起开） | 合到一半停在一半 |
| 开盖·认你 | 系统锁屏是主角；刘海左边一圈在转，右边两枚小点：脸、手机。暗时屏幕四周亮一圈补光 | 戴口罩直接说“用 Touch ID”；摄像头被挡就不出现 |
| 认出你 | 两样都对：对勾，密码一个点一个点填进去 | 没认出 / 手机不在：说清缺哪样，交回系统 |
| 打开 | 系统确认解锁后，桌面从刘海展开 | 系统没确认就不展开 |
| 回来了 | 紧凑的“离开期间”摘要，每项能点过去 | 不补播 |
| 有人偷看 | 看到第二张脸：私人窗口（按 App 标，预设聊天、邮件、钱包）收进刘海 | 本人一看回来就还原 |
| 找窗口 / 看一眼 / 过去 | 指针停到刘海，展开一排看不见的窗口；停一下看大图；点一下才过去 | 已有，见 notch.md |
| 离开 | 手机和手表都走远、或一段时间看不到你：刘海倒数 10 秒，碰一下就取消，倒数完才锁 | 误锁率实测 |

声纹是辅助因素（Aaron 2026-10-03 补定）：脸的分数落在门槛附近时，刘海请你说一句随机短语补一道；放行高风险的事也可以要它。它只加不减，不单独放行，不顶替手机或手表；随机短语加活体，挡录音重放。私有 API 能达成目的就用，不走 App Store，Face Data 用途限制不作门槛。

触发：开盖或唤醒、刚锁屏、在锁屏上按空格。连续 3 次失败，这次锁屏只用 Touch ID 或密码。
摄像头只在停手 30 秒后才看，每秒 2 帧，推理在 ANE 上。只认本机账户的主人。

## 硬要求

做不到就停下来说明卡在哪，不要换一个更容易的东西交差。

1. **只有一个刘海宿主。**录脸、认你、补光、倒数、偷看提示、窗口那一排，全部长在已有的刘海面板里（`App/Notch*.swift`）。
   不新建认证窗口、不另起浮层、不拿普通预览窗当成果。
2. **两样都对才代打密码。**ArcFace 特征比对（ANE）+ 严格活体 + 注视 + 手机或手表的蓝牙因素，全部通过才在锁屏上输入密码。
   动画对勾、信号强、名字对得上，都不算通过。
3. **先做最没把握的。**第一件事是蓝牙第二因素可行性实验。做不成就如实写下卡在哪一层，再和 Aaron 定替代，不要悄悄去掉这个因素。
4. **攻击测试决定说明怎么写。**照片、手机屏幕、录像、换人、换手机，每种都实测；风险说明只写测过的结果。
5. **系统永远是出路。**口罩、补光也不够、手机不在、3 次失败，都回到 Touch ID 或密码；刘海说清下一步，不挡系统密码框。
6. **耗电写进验收。**蓝牙扫描有占空比；空闲 CPU 和唤醒次数与 1.0.15 比不许变差，测法照 [performance.md](performance.md) 第七节。
7. **密码只在授权会话里解开。**钥匙由 Touch ID 保护，只在会话期间留在内存，空闲后重新上锁；日志里不出现密码、特征、图像、完整设备标识。
8. **每一步都能装上、能试、能撤回。**先给 Aaron 能装的构建再写下一步；附真机探针或攻击测试的实际结果，单元测试和模拟数据不冒充真机。
   真机探针会接管屏幕，只在 Aaron 离开或空闲时跑，只动临时窗口。

> 2026-10-03 补：F1 和 F6 的具体做法（学 Windows 动态锁、Near Lock、blue-lock-mac）见 [dynamic-lock.md](dynamic-lock.md)。锁只看手机断开，不看信号强弱；PhoneKey 已证明不装手机 App 也能连上 iPhone，F1 剩下要证明的是“连上的就是你那台”。

## 做的顺序

| 步 | 做什么 | 算完成 |
| --- | --- | --- |
| F1 | 蓝牙第二因素可行性实验：Mac 扮成蓝牙配件，和 iPhone 配对一次，之后靠加密重连证明“是那台手机”；Apple Watch 分开试 | 写清哪条路能走、走到哪一层；能走的有配对一次、之后加密重连的真机记录 |
| F2 | 把 Glance 的锁屏状态判断、锁屏上抬起面板、按显示器选摄像头，对照接进已有模块（`SessionLockState`、`LockSpaceBridge`） | 锁屏、唤醒、睡眠、换屏都撤得干净；和锁屏开合效果不打架 |
| F3 | 在刘海里录脸（九个方向、几种样子）；ArcFace 在 ANE 上；特征加密存本机 | 录、删、重录都在刘海里；图像不落盘；主线程不卡 |
| F4 | 锁屏认你：补光圈、严格活体、注视、手机因素、3 次上限、Touch ID 保护的密码会话 | 两样都对才输入；每种失败都交回系统；实测开盖到桌面的耗时 |
| F5 | 攻击测试与风险说明 | 五种攻击都有实测结果，说明只写测过的 |
| F6 | 离开就锁、偷看收私人窗口 | 倒数可取消；误锁率实测；私人窗口按 App 标、可改 |
| F7 | 回来时的“离开期间”摘要，接上窗口那条线 | 摘要每项都能点到对应窗口或设备 |
