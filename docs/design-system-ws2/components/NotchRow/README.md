展開那一排：收起的、最小化的、在別的桌面上的窗口排成一排，點一格回到原處。

**什麼時候用**：長按劉海（`hold-long-press` 0.5 秒），那一排有東西（收起的窗口也算）就展開；什麼都沒有時照舊打開啟動台「今天」（#33）。這是場景 3 的主表面。

**結構與令牌**
- 底 `notch-fill`；四周 `inset-island` 14；圓角 `radius-island-expanded`，格子 = 外半徑 − 14。
- 尺寸照灵動岛展開的上限：劉海屏寬 408、外接屏 371，高不超過 160（#29、#83），格子變少就左右滾動。取代舊的「劉海 + 142」。頂邊兩側畫肩（《两耳的岛》，代碼已做），受 S1、S2 約束。
- 格子 76×104、間距 8、圓角 14；格底 `notch-cell`，懸停 `notch-cell-hover`；格標題白 0.8、懸停 1.0。
- 保留緊湊時兩耳的位置：左耳符號、右耳個數仍在原處，格子排在劉海下方（不留額頭）。
- 格子：窗口縮略圖（內容層，不加材質）＋ App 名 `notch-cell`；別的桌面上的窗口標「去」，其餘「回到原處」（#15）。

**互動**：點一格回到原處；指針在格子上停 `dwell-peek` 看一眼（#32）；按住小圓展開並滾到那件（#84）；移開或 Esc 收回。

**動效**：開 `expand`，收 `calm`；格子內容在形狀走到四成後淡入。放回時窗口用 `flyOut` 從格子沿原路飛出。

**讀屏**：每格念整句，中文「回到原處 Safari」，英文「Put Safari back where it was」（#26）。

**主推**：#107 定場景 3 主推這一排，窗口浏覽不作旗艦。
