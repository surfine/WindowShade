首啟引導的一步：先演示一遍，再讓他在這扇窗口裡真的做成一次。

**什麼時候用**：第一次打開；菜單裡「歡迎使用 WindowShade…」可以再打開。WS2 的完成標準要求它依次走過三個場景：新裝的人不讀說明，第一分鐘裡做成一次收起、一次排窗、一次從劉海拿回。

**結構**（系統窗口，跟隨淺深色）：上半是迷你桌面舞台（`radius-card`，天圓地方：頂角圓、底角直），按這台 Mac 的真實比例畫劉海（Air 15″ 佔屏寬 10.8%、高寬比 0.18，帶肩）；下半是眉題、標題、導語、狀態行；底欄是頁碼點和按鈕。

**令牌**：底 `window-bg`；眉題 `mac-callout`（`label-secondary`）；標題 `mac-title1` 加粗 600；導語 `mac-title3`；狀態行 `mac-body`；做成時的 ✓ 用符號加字，不只靠綠色。按鈕只有「繼續 / 上一步 / 跳過 / 開始使用」，沒授權時「稍後再說」；主按鈕 `accent` 底、`on-accent` 字，做成之前「繼續」不是主按鈕。

**節奏**（HIG Onboarding）：頁碼點只數這三步；每頁演示兩輪就停在關鍵幀，輪到他；可略過，略過後不再自動彈出。權限頁只要沒有它就不能用的（輔助功能），屏幕錄制寫明可選、沒有它也能收起，只是沒有實時畫面。

**動效**：步與步之間內容交叉淡化；唯一的形變用 `calm`；示範裡窗口滑行 `settle` / `glide`；做成那一下 `pop`。減少動態效果時示範停在關鍵幀。

**現狀與目標**：代碼（`App/WelcomeFlow.swift`）是 A1 雙擊收起練習 → A2 權限 → T 再看四樣（劉海、窗口浏覽、手勢與卷軸、菜單欄）。Q2 已定：三頁各做成一件——① 雙擊收起、停在條上看一眼；② 標題欄一甩到半屏、捏合撤回；③ 長按劉海拿回。輔助功能在 ① 做成後才問，不算頁碼；屏幕錄制寫明可選。T 段的「點一下劉海，放回」隨之刪掉（C9）。
