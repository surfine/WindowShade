標題欄排窗代理：在標題欄上滑或甩，一個窗口形的影子先跑到它要去的位置，畫出排好後的樣子；捏合撤回剛才那一步。

**什麼時候用**：場景 2。兩指在標題欄上往左、往右滑，或甩一下（投影 r = 0.998 決定落點），到半屏、三分之一或角落；先做左右半屏和甩一下（#59）。滾輪與兩指滑同一扇窗冷卻 `cooldown-scroll`，往回撤銷不攔（#58）。

**結構與令牌**：代理 = 窗口形，圓角 `radius-window`（代碼起始寫死 10，要收成令牌）；落點框同圓角，邊 1.5 pt `accent`（0.75），填 `accent` 0.12，走滿時不透明度 0.25 → 0.7。描邊代理（沒有屏幕錄制時）邊 2 pt `accent`、填 0.08。畫結果，不畫參數（P9）；提示浮窗 `GestureHUD` 同時在窗旁說結果名。

**動效**：位置 `glide`（帶手勢速度，夾在 ±40）；尺寸與圓角 `settle`；落定 `settle`；減少動態效果原處淡出、目標處淡入。撤銷沿原路回到排之前的位置（P6），菜單項寫出那一步：「撤銷 左半屏」（#20）。
