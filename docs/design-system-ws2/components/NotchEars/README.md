緊湊兩耳：一件正在進行的事，分成劉海左右兩半，讀成一句話。

**什麼時候用**：場景 3。有收起的窗口時，左耳是符號（`macwindow.on.rectangle` 或最近那扇的 App 圖標），右耳是個數；實時活動（正在播放的封面與波形、計時器）和電量（只做短暫提醒，電量環只在大卡裡；未知時不顯示 0%）用同一副兩耳。同時有第二件事時，優先的那件佔兩耳，第二件在右邊分出一顆最小小圓（#30）。

**結構與令牌**
- 底 `notch-fill`，無陰影；細邊 `notch-stroke`（增強對比度 `notch-stroke-hc`），只描兩側和底邊。
- 耳高 = 劉海高（本機 33.5 pt），寬按內容、兩耳等寬（#83，《两耳的岛》）：主體 = 2 + 內容 + 外側留白，夾在 26 至 44.59；加肩（r 5.06、延伸 7.74）每耳最寬 `ear-max` 52.33（HIG 393 寬那一檔的緊湊寬）。唯一例外是音量與亮度兩耳，可到 HIG 最寬一檔 62.33。兩耳緊貼劉海 `gap-ear`。最小小圓直徑 = 耳高。
- 耳內文字 `notch-ear`（13 semibold，#86），符號 `notch-ear-symbol`（16）；代碼仍是 12 / 13 與 14，見 C15；個數 `notch-count`（SF Pro Rounded 等寬數字），顏色 `notch-text-count`。
- 底角 = `radius-hw-notch`（從 DisplayShape 取；代碼舊值寫死 12）。肩：S1 不佔新的菜單欄空位，S2 點擊穿透，做不到就不畫。
- 菜單欄空位不夠一隻耳（< 26 pt）時退成下巴；NotchWatch 每 60 秒重量一次（#87）。

**互動**：點耳朵打開那件事的 App；點劉海本體回到主屏幕（#31）；長按 `hold-long-press` 展開那一排；劉海上不再懸停展開（#32）。

**動效**：進場 `settle`，退場 `calm`；減少動態效果用 `reduced` 原處淡入淡出。

**不要**：在有系統灵動岛的觸控 MacBook Pro 上畫（讓位 #18、#38）；系統已顯示的同一件事再畫一次（#39）；攝像頭在用時長成提醒（#40，只亮點或緊湊）；兩耳之間留空黑條。

**讀屏**：左右兩耳念成一句：「收起了 3 扇窗口」。
