看一眼：指針停在卷帘條上，不展開就看見窗口裡的東西；移開就收回。

**什麼時候用**：場景 1。停在卷帘條上（意圖延遲 0.20 s，離開寬限 0.16 s）；也用在展開那一排的格子上（`dwell-peek`）。

**結構與令牌**：內容層，不加材質、不加底、不加邊——窗口畫面自帶邊緣，多一層會在角上露出月牙。圓角 = 源窗口實測圓角（量不到用 `radius-window`），`.continuous`；陰影 `shadow-glance` 沿卡片路徑畫。只有拿不到畫面時才畫 `window-bg` 底和 0.5 pt `separator` 邊，並用 `glance-note` 明說「收起時的畫面」或「不是實時畫面」。離屏幕邊 `margin-float`。

**動效**：從卷帘條往下長出 `calm`；收回 `pull`；長大 `settle`。看一眼一天上百次，不回彈、不表演（P8）。減少動態效果時只淡入淡出。

**權限**：沒有屏幕錄制也照常用，只是畫面是收起時的那一幀（WS2 完成標準）。

**讀屏**：「看一眼：<窗口標題>」，有快捷鍵可代替懸停。

**不要**：在卡片上加按鈕條或玻璃（P5）；讓它擋住鼠標要去的地方——移開即收。
