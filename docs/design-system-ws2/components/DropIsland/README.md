落點小島：拖著一扇窗靠近劉海時，劉海張開一個口子，告訴你「放進來就收好」。

**什麼時候用**：場景 3 的入口之一。拖著窗口在劉海上停 `arm-drop` 0.15 秒才武裝，划過去的不算；朝劉海甩一下仍按速度預測直接收進（#56）。

**結構與令牌**：340×84，`radius-island-drop` 22，底 `notch-fill`。未對準：1 pt `notch-stroke`；已對準：2 pt `accent`（0.9）。代碼裡已對準還加了白 0.12 的灰填充，按 P5 要去掉，只留邊線粗細與顏色兩重區別（不只靠顏色）。畫「放進來」的口子，不畫菜單（P9）。

**動效**：出現 `catch`（應帶拖動速度，代碼還沒帶）；越過門檻給 `.alignment`，松手確認 `.levelChange`；收進那一下截圖用 `settle` 飛進劉海中心，不回彈。

**讀屏**：「松手收進劉海」。鍵盤替代：菜單「收進劉海」（單扇，快捷鍵默認不佔）與 ⌃⌘H（全部）。

**不要**：在 macOS 15+「拖到菜單欄鋪滿」的位置和系統打架——真機核對（記在 #18 的調研裡）。
