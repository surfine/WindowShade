卷帘條：窗口在原處卷成只剩標題欄的一條，裡面的東西都還在。這是 WindowShade 的來歷，也是場景 1 的主角。

**什麼時候用**：雙擊標題欄收起，再雙擊放下（#17 默認收起；觸控 Mac 上手指雙擊讓給系統）。也是「收起後的樣子」三個住處裡的「原地」。

**結構與令牌**：高 = 系統標題欄高（代碼 28–34）；上兩角 `radius-window`，取 min(13, 高/2)，下邊直切（窗口剩下的部分被卷走，不是一顆膠囊）；標題 `strip-title`；懸停提示 `strip-hint`「雙擊展開」。紅綠燈照系統位置。陰影 (0, −2) blur 12、黑 0.18（深色 0.28）；邊 0.5 pt `separator`（增強對比度 1 pt）。

**材質**：它屬於窗口自己，不是控件層的玻璃，也不加自製材質（P5）。Q1 已定：底 `window-bg`、標題 `label`、提示 `label-secondary`、邊 `separator`，跟系統標題欄一樣。代碼現在的「紙面」（按 App 圖標主色相著色的 12 個灰階，`ShadeStrip.swift` `classicPalette`）退役。

**動效**：卷起 / 放下用 `fold`（0.25 / ζ 1.0，代碼令牌，文件補記）；沒有屏幕錄制時用描邊代理收成卷帘條（#19）；減少動態效果時原處淡出淡入。不回彈：一天上百次（P8）。

**讀屏**：「已收起：<窗口標題>，雙擊放下」。菜單「收起窗口」與快捷鍵可代替雙擊。

**不要**：把卷帘條挪離原處（那是「收進劉海」，另一個住處）；在條上疊玻璃或高光。
