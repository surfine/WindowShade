菜單欄膠囊：沒有劉海的屏幕上，劉海那一族表面的落腳處。

**什麼時候用**：外接屏、MacBook Neo、「避開劉海」縮放模式、合蓋只用外接屏（#42、#43）。新 MacBook Pro 接外接屏時，外接屏上畫膠囊，內建屏讓位。

**結構與令牌**：菜單欄正中，畫在菜單欄條內；寬 80、上下各縮 3，`radius-capsule`；放不下時退成 72×12 的下巴（`radius-control`）。底色 `notch-fill`（代碼已從黑 0.88 改成純黑）。不畫肩，不畫假劉海（P2）。槽位（瞄準、放回起點）190 寬、高 max(24, 菜單欄高)，是點擊目標不是外觀，保持不變。

**呈現**：五種呈現都從膠囊長出來，展開寬 371（#83），規則與 `NotchEars`、`NotchRow` 相同。

**讀屏**：名稱與真劉海一致。
