# 稿件審查

**2026-11-07 修訂進度**：17 份「衝突」稿已按本系統改好正文，勘誤框裡已落實的條目移除，`_spine.json` 狀態改為「按 WS2 设计系统修订 · 11-06」，導航頂頭改指本系統；19 份標「归档」、2 份標「作废」。仍留著的尾巴見文末「修訂後還剩的」。

`WindowShade-internal/docs/design-drafts/` 的 41 份 html（另有 7 份 md、7 個截圖目錄）按這套系統過一遍，2026-11-06。判定只有四種：

- **依據**：WS2 用到、和系統一致，畫新稿時照它。
- **衝突**：WS2 用到，但有一處或幾處和系統、決定或代碼對不上；括號裡是矛盾清單的編號，修稿時只改那幾處。
- **歸檔**：屬於已移出 WS2 的線（CarPlay、指揮模式，#105），或已被取代、已落地、只是調研。不改、不重發，在 `_spine.json` 標「歸檔」並移出導航的主列表。
- **作廢**：決定已推翻，留著會誤導。頂部加一行作廢說明並指向取代它的稿。

所有稿共有的兩件事不逐份重複：41 份的產品畫面示意都寫死了 hex（accent 有七種藍，還有番茄紅、指揮粉），新畫或重發時一律換成本系統的令牌；28 份用 Google Fonts 排文件版面，這可以留，但產品畫面示意裡的字必須是 SF Pro 棧。另外 `_errata.json` 的勘誤只貼在稿頂，正文仍是舊值，所以「衝突」稿重發時要把勘誤改進正文。
