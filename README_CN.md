## 开发中的实时活动

刘海和启动台负一屏共用最多三个实时活动：音乐、AirPods、由本工具发起的隔空投送与地图路线，以及语音备忘录的麦克风／可确认的录音状态。左右轻扫切换，长按展开；音乐首次点击连接并授权后可控制播放。系统三指拖移与已有标题栏手势继续沿用。[实际接口边界、手势与检查方法](docs/live-activities.md)。当前下载版尚未包含这些改动。

## 开发中的刘海 Touch ID

菜单里选“验证 Touch ID…”，刘海展开显示系统指纹提示；无刘海的屏幕使用菜单栏下方的独立胶囊。完成后收回，恢复原来的实时活动。这只确认本次 WindowShade 应用请求，不解锁 macOS。当前下载版尚未包含，实际指纹与多屏体验仍待现场验收。[设计与验收说明](docs/touch-id-island.md)。

## 开发中的启动台

按 ⌃⌘L 打开主屏幕，长按图标整理顺序、建文件夹。最后一页是 App 资料库，可按名字、拼音或首字母搜索所有 App。从主屏幕移除只拿掉入口，不卸载应用。非编辑状态下，把 App 图标直接拖到屏幕边，可以在侧拉中打开窗口。也可以拖住窗口标题栏，移到屏幕侧边中段，在“侧拉”箭头上停一下，出现“松手侧拉”后松手。退出时，拖住标题栏拉到屏幕中间，停下再松手，窗口留在放下的位置。

主屏幕是 macOS 15 启动台的样子：顶端一个平面搜索框，页码点单独摆在图标区下面，壁纸在后台解码并模糊。第一页往右划是负一屏，放实时活动与本机数据：实时时钟、当月日历与实时活动卡片。最后一页往左是 App 资料库；往上划、返回手势、捏合都逐步撤回；往下划收起启动台、按你在系统设置里给 Spotlight 设的快捷键把它叫出来；这个快捷键被关掉时，留在启动台里用它自己的搜索。把图标拖到刘海那一块，先恢复那个窗口原来的卷帘条或侧拉，否则才回主屏幕；左边是资料库，右边是负一屏。资料库按 iPadOS 26 的四列参考摆，不宣称与 iPad 逐像素相同。用户壁纸读不到时退到系统的 `DefaultDesktop.heic`，两条都失败才不铺图，全程不联网。

方向键和 Return 也能在 App 资料库里选择、打开应用。Page Up / Page Down 翻页，拖动整理时按 Esc 恢复原来的排列。

同样在开发中的还有几件：菜单栏里“暂时取消全部置顶”一下让开所有置顶的窗口，再点一下按原来的前后顺序放回（可以在设置里录一个快捷键）；窗口已经在上半或下半一行时，左右滑就在这一行里走梯子，得到三分之二和六分之一的格子，三分之一宽时一格一格走到中间；六分之一再左右滑一下拐向上或向下，就在这一列里上下走三行，得到九分之一的格子；在卷帘条上往下拉一点就是看一眼，拉满才展开；指针停在刘海里的一格上，看到的是那扇窗此刻的样子，不是收起时的截图。刘海现在也是 Mac 的主屏幕键：点一下回到主屏幕，点两下调度中心，点三下这个 App 的所有窗口；最小化的窗口和隐藏的 App 也收在刘海那一排里；把文件拖到刘海上停一下，主屏幕只亮能打开它的 App。标题栏上两指张开改成魔法平铺：这扇当主角，这块屏上别的窗口按各自要的地方排在旁边（比例在 5:5、6:4、7:3 里自己定，竖屏上下分），聊天放侧拉，捏合整批撤回；也可以按 ⌃⌘M。拖着标题栏晃一晃，别的窗口收进刘海，再晃一下放回来。魔法平铺放不下的窗口会接成一条卷轴（niri 的做法）：每扇按 App 要的宽度一列挨一列停在屏幕右边外，只露一条边；在卷轴里任何一扇的标题栏上两指左右滑，整条跟着走，上下滑是这一列宽一档、窄一档，⌃⌘←→ 走到左右那一列；新开的窗口接在当前这列右边，谁都不变窄。刘海上两指往上推，这块屏上的窗口全部收进刘海，往下拉整批回来（⌃⌘H 同样）；左右滑切到上一个、下一个 App；拖着标题栏到刘海，垂下的小岛有五格：左半屏、铺满、收进刘海、魔法平铺、右半屏。按住 ⌥ 连按 Tab 按窗口切换（收着的窗口也在里面，设置里可换成 ⌘Tab）；点 Dock 上最前面那个 App 的图标，它让开；⌃⌘N 把窗口移到另一块屏幕（上下摆的显示器也行）；设置里能让排好的窗口之间留一道缝。侧拉换成了 iPadOS 27 的样子：窗口外一圈玻璃边框，靠里的下角有一段弧，拖它改大小，拖玻璃边框挪位置。两扇窗口拼满一块屏时，中间出现一根小竖条（分屏把手），拖它两扇一起变，推到屏幕边那一扇进侧拉；四角、三分、网格排好的窗口，每条缝都能这样拖。从 Rectangle 换过来的，设置 → 快捷键 → 更多排法里点“换上”，就用回它的那一套快捷键。调度中心开着时，按 ⌘W 关掉指针指着的那扇窗，⌘Q 退出它的 App。任意窗口都能进画中画：把标题栏拖到屏幕角落停一下，窗口缩成一张实时画面浮在角落，原窗口让开；拖着它甩到别的角，推出屏幕边就藏起来；滚轮直接滚原窗口，上一页、下一页也发给它；还能只看窗口里的一块；双击回到原处。卷轴停在屏幕外的那一列会在屏幕边露出一条，指针停上去就能看一眼那扇窗；在卷轴里的标题栏上两指张开是卷轴概览。窗口浏览的预览里多了新建窗口（Mac 上是 ⌘N），把一张预览拖出面板、贴着屏幕边松手，那扇窗就排到那边；微信小程序的窗口也列在微信名下。

这些功能尚未发布；下载版仍以对应版本的发布说明为准。操作与验收入口见[启动台说明](docs/launchpad.md)和[标题栏手势](docs/gestures.md)。

## 让开的办法有三种，只有一种不用回头找

窗口挡住了后面的东西，你多半会关掉它，或者最小化。两种都管用，只是回来的时候要费点工夫。

| | 窗口去了哪儿 | 回来的时候 |
| --- | --- | --- |
| **关掉** | 没了 | 重新打开，再翻回刚才那一页 |
| **最小化** | 进了 Dock | 先在 Dock 里认出它 |
| **收起** | 收成一条卷帘条，还在原处 | 双击卷帘条，它就回来 |

收起和最小化不一样：窗口不离开这张桌面。把卷帘条拖到别处，窗口就在新位置展开。

## 老动作之外，它还帮你看住每扇窗口

收起，窗口留在原处；看一眼，不用展开就能看到它；带到每张桌面，换了桌面也看得到；置顶，窗口留在最前面；窗口浏览，从 Dock 里把它找出来。都是为了让你知道要的那扇窗口在哪儿，而且不用去了再回来。

**收起窗口。** 双击标题栏或按 `⌃⌘C`，窗口收成一条卷帘条；双击卷帘条展开。收起后的样子可以选“跟原来一样”，也可以选“统一标题栏”。卷帘条在最前面时按 `⌘W`、`⌘M`、`⌘H`、`⌘Q`、`⌘N`，作用在它背后的窗口和 App 上；按 `⌘Q` 会先把窗口放下来，要问“是否保存”时你看得见。

**在标题栏上滑一下。** 把指针放在标题栏上，用两根手指滑。窗口跟着手指走：往上推，它收成一条卷帘条；往下拉，它铺满菜单栏和 Dock 之间的屏幕，再往上推回到原来的大小。松手才算数，滑到一半往回拉，就当没发生过。滑动时，窗口旁边有一块和系统音量提示同样样式的小浮窗，写着松手会做什么。左右滑占半屏；朝同一边再滑，变成三分之二、三分之一；那边还有一块屏幕的话，再滑就移过去。左右滑到位后接着往下或往上拐，窗口占那个角。两指张开也是铺满，捏合撤销上次排布；轻点两下在铺满和原来之间切换。普通鼠标在标题栏上滚三格算一次；Magic Mouse 的支持还在真机上验证。

**甩一下标题栏。** 拖着标题栏快速甩出去再松手，窗口带着这股劲滑到甩的那一边：往上收起，往下铺满，左右走同一架梯子，明显朝着角落甩就占那一角。三指拖移也一样，手指一离开触控板就算。先慢下来再放下、贴着屏幕边松手，还是系统原来的拖动和平铺。键盘也走同一套：`⌃⌘←`、`⌃⌘→` 左右排，`⌃⌘↓` 变大一级，`⌃⌘↑` 变小一级；按完 `⌃⌘←` 马上按 `⌃⌘↓`，窗口占左下角。换显示器以后，用手势、快捷键或窗口浏览排过的窗口，会照原样排到新屏幕上。网页、列表里照常滚动，Safari 标签上的左右滑照样切换标签；Swish 在运行时，标题栏交给它。细节见 [标题栏手势说明](docs/gestures.md)。

**看一眼。** 指针在卷帘条上停一下，卷帘条下面就挂出一张卡片，按原来的大小显示窗口里的内容；移开，它自己收回去。单击卡片才真正展开；Force Touch 触控板上用力按卷帘条也能看一眼，松手收回。卷帘条留在原处，卡片和它隔着一道缝，一看就知道这是预览，不是窗口本身。它不会切换当前的 App，也不会动任何窗口。收起时被最小化的窗口拿不到实时画面，这时看到的是收起时的画面，右下角会写明。细节见 [看一眼说明](docs/glance.md)。

**带到每张桌面。** 一张桌面放一个 App 的话，按 `⌃⌘G` 把当前窗口带到每张桌面：窗口留在原处，别的桌面右上角会出现它的卷帘条。停在上面看一眼，显示实时画面；窗口被隐藏或最小化时，改显示带提示的截图。单击画面就回到它。再按一次 `⌃⌘G`，或者点卷帘条上的叉，就放下它。

**置顶。** 对着资料写报告、跟着教程一步步做的时候，按 `⌃⌘P` 把那扇窗口置顶，你切到别的窗口，它也不会被盖住。菜单栏里能看到所有置顶的窗口，也能一次全部取消。

**窗口浏览。** 把指针停在 Dock 里的应用图标上，这个应用开着的窗口会一起列出来，每扇都带画面和标题。

- 面板只用来看。按下卡片上的按钮，才会动那扇窗口。
- 选中一扇窗口按空格，打开大图预览。窗口不会被切到前面，也不会移动。
- 左半、右半、四角、居中、填满，或者移到另一块屏幕：先画出窗口要去的位置，你同意了才移动，移好了还能撤销。

也可以从菜单栏的“选择窗口…”打开，或者按你自己设的快捷键。Dock 入口默认关闭，在“设置 → 窗口浏览”里打开。面板是临时的：不替换系统 Dock，也不接管 Command-Tab。细节见 [窗口浏览说明](docs/window-browser.md)。

**彩蛋：合上盖子，桌面留在原处。**

<img src="assets/windowshade-lid.gif" alt="MacBook 合盖时，桌面像留在原处，越往上越暗、越模糊" width="620">

在带铰链传感器的 Apple Silicon MacBook 上，合盖时，屏幕合下来，桌面却像一页纸留在原处，越往上越暗、越模糊；开盖就复原。质感有轻柔、标准、磨砂三种。它只是个彩蛋，收起窗口和置顶都用不着它。

## 快捷键

1.0.16 新装的一项都不预设（⌃⌘ 那一组要自己在设置 → 快捷键里录，也可以一键换上 Rectangle 那一套）；从 1.0.15 及以前升级上来的，保留下面这几组。

| 快捷键（升级上来的） | 做什么 |
| --- | --- |
| `⌃⌘C` | 收起或展开当前窗口 |
| `⌃⌘P` | 置顶或取消置顶当前窗口 |
| `⌃⌘G` | 把当前窗口带到每张桌面，再按一次放下 |
| `⌃⌘1…9` | 按菜单里的顺序展开收起的窗口 |
| `⌃⌘0` | 排好卷帘条，或进入专注布局 |
| `⌃⌘←` `⌃⌘→` `⌃⌘↑` `⌃⌘↓` | 排布当前窗口：左右排布，变小一级，变大一级 |

双击标题栏收起，双击卷帘条展开。快捷键都能在设置里改键或关掉；某个组合被别的应用占用时，会提示你一次。

## 你的窗口，只留在你的 Mac 上

WindowShade 要两项权限。**辅助功能**：找到、移动、恢复窗口。**屏幕录制**：拍下窗口画面做预览。“屏幕录制”只是系统给这个权限起的名字，画面只在你的电脑上处理，不会传到别处。应用万一意外退出，窗口也会自动恢复原样。

普通窗口都能收起。便笺用系统自己的收起方式；Adobe 这类自己画标题栏的应用会单独处理。全屏、分屏、台前调度和多显示器还有少数情况没覆盖，建议先在你常用的应用里试一次。碰到问题欢迎[反馈](https://github.com/surfine/WindowShade/issues)，写上 macOS 版本、应用名和操作步骤。

## 构建与参与

需要 macOS 14+、包含 Metal 编译器的 Xcode command line tools，以及 Apple Development 签名证书。

```sh
git clone https://github.com/surfine/WindowShade.git
cd WindowShade/prototype
./build.sh --check   # Swift 类型检查与 Metal 编译
./build.sh           # 使用本机配置的身份构建、签名
open WindowShade.app
```

通过 `WINDOWSHADE_CODESIGN_IDENTITY` 或未跟踪的 `prototype/local-codesign.env` 配置签名。签名、隔离构建与发布步骤见 [DEVELOPMENT.md](DEVELOPMENT.md)；界面和官网文案按 [文案规则](docs/copy-guide.md) 写。
