# Changelog

One line per release. Full notes, downloads and checksums are on [GitHub Releases](https://github.com/surfine/WindowShade/releases); the source of each note is in [docs/releases/](docs/releases/). / 每版一句，完整说明见 Releases。

| Version | Date | Highlights |
| --- | --- | --- |
| [1.0.17](docs/releases/v1.0.17.md) | 2026-10-17 | Steadier, and notarized by Apple: Developer ID signing, on-device crash reports, macOS 15 or later. / 更稳，也终于通过了 Apple 公证。 |
| [1.0.16](docs/releases/v1.0.16.md) | 2026-10-12 | Every window you can't see lives in the notch: rolled up, slid over, minimized, hidden, or on another desktop. / 看不见的窗口，都在刘海里。 |
| [1.0.15](docs/releases/v1.0.15.md) | 2026-09-24 | Glance at a rolled-up window without unrolling it; title-bar swipes, throws and `⌃⌘` arrows for layouts. / 不用去了再回来。 |
| [1.0.14](docs/releases/v1.0.14.md) | 2026-09-18 | One appearance policy for every surface, fixed frozen colours, better accessibility. / 与系统浑然一体。 |
| [1.0.13](docs/releases/v1.0.13.md) | 2026-09-17 | Window browsing grown up: tighter panel, clearer states, previewable and undoable placement. / 窗口浏览的成熟版。 |
| [1.0.12](docs/releases/v1.0.12.md) | 2026-09-17 | Hover a Dock icon to see every window of that app, or open a searchable panel. / 悬停 Dock 图标，看清每个窗口。 |
| [1.0.11](docs/releases/v1.0.11.md) | 2026-09-12 | Make room, keep your place: a calmer everyday interface and batch roll-up. / 暂时让开，位置还在。 |
| [1.0.10](docs/releases/v1.0.10.md) | 2026-09-11 | Animated roll-up effects, device tilt, and a redone Settings window. / 动态卷帘效果、设备倾斜与设置重做。 |
| [1.0.9](docs/releases/v1.0.9.md) | — | Windows come back after a crash; previews use less power and memory (tag only). / 崩溃后能找回窗口，预览更省电。 |
| [1.0](docs/releases/v1.0.md) | 2026-07-03 | First release: roll a window up into its title bar, and pinned previews. / 第一版。 |
