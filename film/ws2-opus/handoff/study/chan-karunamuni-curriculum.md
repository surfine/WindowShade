# 必學：Chan Karunamuni 與靈動島／流體介面

審片前先系統讀完這一節，再看 WindowShade 成片。目標不是背口號，而是用同一套尺子量「像不像蘋果、動效是否廉價」。

## 必看原片（官方）

1. **Designing Fluid Interfaces** — WWDC18 session 803  
   https://developer.apple.com/videos/play/wwdc2018/803/  
   主講 Chan Karunamuni（與 Nathan de Vries、Marcos Alonso）。主題：iPhone X 手勢介面如何「跟行為合作，而不是貼動畫」。

2. **Design dynamic Live Activities** — WWDC23 session 10194  
   https://developer.apple.com/videos/play/wwdc2023/10194/  
   Chan 講 Dynamic Island：硬體切口變成活的系統層，如何形變、如何排內容、如何保持家族感。

3. Chan 本人對靈動島的設計意圖（原文可搜）：  
   「living, elastic bubble that can fluidly shape shift」——活的、有彈性、會形變的泡，不是貼在螢幕上的黑色膠囊貼紙。

## 從 WWDC18 帶走的審片尺子

看片子裡每一次島／窗口／鏡頭運動，問：

| 原則 | 成片裡該長什麼樣 | 廉價／山寨常見敗相 |
| --- | --- | --- |
| 跟行為合作，不貼動畫 | 形狀變化像物理系統在響應；可被下一個輸入打斷 | 時間軸關鍵幀「演完再停」、中途無法改道 |
| 響應／可改向／可打斷 | 收起、展開、確認之間可疊、可搶 | 一段動作播完才接下一段，像簡報轉場 |
| 動態運動對齊意圖 | 速度與力度對得上用戶剛做的事（點／畫／點頭／走開） | 一律同一套 ease，輕重不分 |
| 投射動量 | 不是只插值位置；進出帶方向與殘量 | 硬切透明度、硬停在終點 |
| 好玩建立在前幾條之上 | 俏皮只在嚴謹之後 | 先賣可愛／誇張形變，結構卻鬆 |

## 從 WWDC23／靈動島帶走的審片尺子

| 原則 | 成片裡該長什麼樣 | 廉價／山寨常見敗相 |
| --- | --- | --- |
| 硬體＋軟體同一系統層 | 島從真實洞長出來，黑與洞一體 | 洞上再浮一層「假劉海」、肩線／台階 |
| 生物感形變 | 形變同心、邊距均勻、像彈性體 | 直角台階、窄頸、外貼描邊、陰影當立體 |
| 內容與外形和諧 | 字與圖嵌在島形裡，留白均勻（concentric） | 字頂進洞、左右不對稱空隙、貼邊擠爆 |
| Compact 極窄、只留本質 | 一行內讀得出任務 | 空等候選、裝飾多於資訊 |
| Expanded 不過高、無「額頭」 | 洞下安全區排字，不強調感測區額頭 | 大額頭空白、標題進洞 |
| 活動有身分 | 顏色／圖示／動勢能分清是外賣、番茄鐘、指揮 | 所有狀態同一塊灰黑膠囊＋細字 |
| 家族感 | 各活動不同，但同屬一層系統 | 每段像不同 App 隨便貼 |

## 對 WindowShade 兩支片的強制對照題

審每一段刘海／島時寫明：

1. 這一刻是 compact / expanded / minimal 哪一種邏輯？  
2. 形變是「彈性系統」還是「關鍵幀表演」？  
3. 內容是否與島形同心？有沒有額頭、台階、窄頸？  
4. 若拿掉配樂，單看畫面還像不想像蘋果系統層？

不要用「弹簧名字對了」當通過條件；要以肉眼是否絲滑、是否嚴謹為準。
