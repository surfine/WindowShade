# 對照標杆：Mark View

Aaron 點名的動效標杆：https://www.markview.work/projects

## 怎麼用（審片，不是抄鏡頭）

看 Mark View 作品集時，記下他反覆做到、而本片常失敗的幾件事：

1. **入扣**：動作不是「播一段動畫」，而是物件從 A 到 B 的路徑、節奏、遮擋關係都服務同一意圖。  
2. **絲滑**：加速度連續；切鏡頭時運動能量不突然歸零。  
3. **克制**：華麗建立在清晰的主體上；不會同時搶戲（鏡頭／島／窗口／字幕同秒搶）。  
4. **材質可信**：光澤、模糊、層級像真系統，不像 UI Kit 默認控件拼貼。

## 對 WindowShade 的提問

- 收進刘海／放回／島展開：是「系統層在呼吸」，還是「演示片在表演」？  
- 指揮模式、點頭確認：因果是否一眼可讀，且中間沒有空等？  
- 全片節奏是否像行雲流水，還是一段段卡點簡報？
