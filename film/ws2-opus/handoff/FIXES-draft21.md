## 1. 你量到的那個成因是對的，而且它單獨就足以造成平面卡片

`PHONE_SCREEN_OUTLINE` 的 54 點 u、v 都跑滿 0→1，`planeGeometry` 又用整個
`PHONE_FACE.w × h` —— 貼圖從邊到邊蓋滿正面，**鈦邊框零空間**。打光只是第二個成因。

修法（`src/future/film/stage.tsx`）：

```ts
const PHONE_BEZEL = 0.021;                       // 真機 1.4–1.7 mm ÷ PHONE_FACE.w → 每邊 1.9%–2.3%，取中值
const PHONE_CARD_SCALE = 1 - 2 * PHONE_BEZEL;    // 0.958
<planeGeometry args={[PHONE_FACE.w * PHONE_CARD_SCALE, PHONE_FACE.h * PHONE_CARD_SCALE]} />
```

平面縮這一圈，等於貼圖與它的裁切輪廓一起每邊內縮 2.1%。

**量到的結果**（`out/future/symbols/v2/f1840.png`，1080p，正面寬約 300 px）：
卡片寬／正面寬 = **0.947–0.958**，和算式上的 0.958 相符。逐列掃過去，剖面是

```
底 18,20,26 │ 金屬緣 87,72,82 │ 玻璃黑圈 22,23,25（7–10 px）│ 卡片（藍漸層）│ 玻璃黑圈 │ 金屬緣 65,44,52 │ 底
```

## 2. 打光（改 `studioEnv` 的光板，沒有再動材質數字）

原本只有上方的柔光板。相機在機身上方俯看，機身正面反射出去的光是往**下前方**走的——
上方那塊的反射方向落進近黑底，所以機身讀成剪影。補了兩塊：

- `panel(9, 4.4, 0xdfe9f5, 1.7, [1.2, -0.6, 3.2], [0, Math.PI, 0])` —— 前方柔光幕，位置就是
  相機方向對正面法線取鏡射後往下壓。
- `panel(0.35, 3.0, 0xf2f7ff, 12, [1.85, 0.5, 1.6], [0, -Math.PI / 2, 0])` —— 窄高光條，
  在機身緣拉一道可讀的亮線。

**量到的結果**：左緣 3×3 帶內最大亮度 min 34／中位 72／max 136，背景 21 →
50 列裡 48 列 ≥ 2× 背景。全幀平均亮度只從 29.6/33.8/44.7 抬到 31.2/35.2/46.0，沒有爆掉。
