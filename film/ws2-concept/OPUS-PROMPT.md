## 發想

片子講的是官網已經在動的那幾件事，不是功能目錄。

劉海是唯一的銜接。形狀先長，內容後到；退場先收內容，再收形狀。黑色的島不要做透明度。沒有待機呼吸，沒有粒子、彩紙、碎屑。

不要畫假介面。做過的功能：沒有真機素材就放佔位塊，塊上寫「真機畫面：」加要錄的動作和大約幾秒。沒做過的只留抽象的劉海、幾何、線稿。不畫 CarPlay 的介面和標誌，不用 Face ID 圖形，不填密碼。開蓋只說明蓋子合上時桌面還在，不寫成已經刷臉解鎖。

橫版 1920×1080，豎版 1080×1920，同一條 60fps 時間線，7560 幀（126 秒）。豎版不是把橫版縮小貼上去：劉海仍貼著畫面裡那塊螢幕的上沿正中，主句在螢幕外面，佔位塊不被裁掉。

每一幀只取決於幀號。用 `useCurrentFrame()` 和彈簧。不用 CSS transition、不用 `Date.now()`、不用沒有種子的隨機。
